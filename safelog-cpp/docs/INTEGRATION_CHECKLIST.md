# Integration checklist

- [ ] Everyone builds from the same `main` commit before starting.
- [ ] Contract headers are identical on all branches.
- [ ] No feature module includes another feature module.
- [ ] All status changes go through `WorkflowService`.
- [ ] All writes go through `IRepository`.
- [ ] Before photo is mandatory at creation.
- [ ] After photo and action note are mandatory before review.
- [ ] Only the inspection owner can verify.
- [ ] App restart keeps sites, inspections, findings, photos, and logs.
- [ ] Korean text and both photos appear in the PDF.
- [ ] Android permissions denied/cancelled states show a recoverable message.
- [ ] Demo uses fictional names and images.
- [ ] Legal claims are omitted from the UI and presentation.
