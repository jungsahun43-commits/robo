# 전선 연결부 24장 구성 검수 사용법

역할3과 팀 내 검수자가 사용하는 자료다. 앱 연결용 AI 패키지는 기존 v13을 사용한다.

## 가장 쉬운 방법

1. `safelog-connector-relation-review-24-2026-10-15-v14.zip`을 **전체 압축 해제**한다.
2. 압축 해제한 폴더의 `index.html`을 Chrome 또는 Edge에서 연다. 별도 설치나 로그인은 필요 없다.
3. 검수자 이름을 입력한다. 사진의 윤곽을 확인하고 양쪽 클램프 수·전선 수·색을 입력한다.
4. 사진 위 ‘왼쪽 연결점 표시’와 ‘오른쪽 연결점 표시’를 눌러 전선이 연결부에 닿는 점을 각각 표시한다.
5. 각 묶음의 위에서 아래 순서로 연결된 클램프 번호를 입력한다. 이 순서를 확정하기 어려우면 판단 불가로 남긴다.
6. 윤곽·좌우 묶음 확인 체크 후 ‘관찰 내용 확인’을 누른다. 잘못된 윤곽·가림·모호한 색이나 연결 위치는 메모 후 ‘판단 불가·수정 필요’를 선택한다.
7. ‘JSON 저장’으로 파일을 남긴다. 일부만 확인해도 저장할 수 있고, 저장 파일을 ‘이어서 불러오기’로 불러올 수 있다.

사진의 파란 윤곽은 왼쪽 클램프 묶음, 보라색은 오른쪽 묶음, 초록색은 전선이다. 좌우 제안이 잘못됐으면 ‘클램프 좌우 변경’ 버튼을 누르고 해당 클램프 안을 클릭한다. 윤곽 자체가 틀리면 이 도구에서 새 윤곽을 그리지 않고 수정 필요로 남긴다.

## 검수 뒤 전달할 파일

저장한 `safelog-connector-review.json`을 역할3에게 전달한다. 이 파일은 검수 관찰이며 학습 정답으로 자동 승인되지 않는다. 검수 후 라벨 이용 범위·윤곽 수정·별도 검증 자료 확보가 이어진다.

역할3의 가져오기 명령은 저장소의 `safelog-cpp/ai-training`에서 실행한다. 원본 묶음의 `package.json`을 같이 사용하고, 출력 파일 이름은 기존 결과와 겹치지 않게 지정한다.

```powershell
.\.venv\Scripts\python.exe scripts\import_loco_relation_review.py `
  --review "검수 JSON의 실제 경로" `
  --package "압축 해제한 폴더\package.json" `
  --output "runs\industrial-relation-review-v14\review-import-01.json"
```

정상 publisher TRAIN의 clean FIT24장만 들어 있다. TEST는 포함하지 않았으며 모델 가중치는 이 ZIP에 없다. 원본 MVTec 사진의 비상업·동일조건변경허락 출처 문서와 저자 주석 출처를 동봉했다. 새 저자 주석의 별도 이용 범위는 아직 확인 중이다.

현재 모델은 v13이고 전선 연결부 미탐39.90%·오탐19.33%는 이미 사용한 공개 TEST 결과다. 이번 검수 자료를 만든 것만으로 성능이 개선되거나 추가 학습이 완료된 것은 아니다.
