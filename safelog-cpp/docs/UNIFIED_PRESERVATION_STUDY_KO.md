# 통합 메인 후속 대조 · 시설과 벨트 위치 보존

## 목적

기존 메인에 시설·벨트·이물질 출력을 합친 v1에서 벨트 사진 미탐은 줄었으나 손상 위치 IoU와 일부 시설 성능이 악화했다. 이번에는 같은 v1에서 시작해 시설 학습 비중을 높이고, 공통 분석부 업데이트 여부만 다르게 비교한다.

| 조건 | 공통 MobileNet 분석부 | 기능별 출력부 | 같은 출처 |
|---|---|---|---|
| joint · 대조 | 추가 학습 | 추가 학습 | DACL10k·DamSegment·CODEBRIM·BeltCrack·Mendeley 이물질 |
| frozen · 보존 | v1의 공통 가중치를 그대로 고정 | 추가 학습 | 동일 |

두 조건의 초기 모델, 사진, 정답, 표본 순서, 배치, 출력부 학습률과 손실은 같다. 다른 점검 항목의 정답이 없는 사진은 unknown으로 유지한다. 새 정답이나 외부 사진을 추가하는 회차는 아니다. 최종 앱에는 선택한 모델 파일 하나만 사용한다.

## 계획과 재개

후보마다10epoch·3,840회 업데이트, 합계20후보 epoch·7,680회 업데이트를 계획했다. 사전 실제 GPU 점검2회는 제외한다. 시설·벨트·이물질을 각각 epoch당1,024회 뽑는다. 시설은 이전20epoch의512회 표본을 두 회차씩 합쳐서 같은 총 표본 사용량을10epoch에 배분한다. 같은 사진을 반복 사용한 횟수를 새로운 사진 수로 세지 않는다.

학습 중64회 업데이트마다 가중치·옵티마이저·학습률·현재 순서·난수 상태를 저장한다. 완료된 업데이트를 journal에 남긴다. 중단되면 가장 최근 저장 상태에서 이어가고, 저장 전에 실행한 뒤 버린 업데이트도 journal에서 별도 집계한다. 완료된 모델은 다시 학습하거나 덮어쓰지 않는다.

```powershell
cd safelog-cpp/ai-training
./.venv/Scripts/python.exe scripts/study_unified_preservation_typed.py train
```

기존 데이터·출처·모델과 완료된 보고서는 SHA로 보호한다. 사전 등록된 [조건](../ai-training/reports/unified-preservation-typed-protocol.json)에 따라 최종10epoch만 평가한다. 중간 검증 결과로 학습 회차나 기준을 반복 바꾸지 않는다.

사전 처리 점검에서 `pixel_known`을 좌표 영역으로 잘못 해석한 수정은 철회했다. 실제 파일은 mask가7×80×80이고 known은7개 클래스의 공간 정답 사용 여부 벡터다. 사진과 mask만 반전하고 클래스 벡터의 순서는 보존하는 기존 v1 처리 방식이 올바르다. 실제3개 자료 출처의 파일 구조와 강제 반전 테스트로 이를 검증했다.

잘못된 수정으로 실행한 v2 부분 학습의2,179회 journal 업데이트와 중간 파일은 [중단·제외 기록](../ai-training/reports/unified-preservation-v2-aborted.json)으로 남겼다. 최종 연구 후보를 고르는 자료나 올바른 후속 모델의 초기 가중치로 사용하지 않는다. 새 `unified-preservation-typed-v3` 폴더에서 같은 완료 v1 모델을 다시 불러온다. 이전 `study_unified_preservation_aligned.py`는 중단한 실험의 기록이며 사용하지 않는다. [실제 정답 구조](../ai-training/reports/unified-preservation-known-scope.json)가 현재 적용 조건이다.

## 비교와 선택

시설은 같은 알려진 VAL1,745장, 벨트는 같은 VAL353장이다. 기존 시설 기준과 벨트0.5 기준을 유지한다. 균열·박락뿐 아니라7개 시설 항목의 오탐·미탐 분모를 모두 보고한다. 벨트는 사진 미탐과 위치 IoU를 함께 비교한다.

연구 후보는 시설 균열·박락 최댓값 오류가 v1보다 커지지 않고, 벨트 사진 미탐도 커지지 않으며, 위치 IoU도 낮아지지 않는 조건을 모두 통과해야 한다. 둘 다 통과하면 시설 최댓값 오류, 벨트 IoU 순으로 정한다. 동률이면 frozen을 택한다. 둘 다 실패하면 v1을 보존한다.

선택 기록을 먼저 저장하고 나서 알려진 이물질 TEST448장·783장을 평가한다. 이 시험 수치로 선택을 바꾸지 않는다. 이물질 경고 기준은 후보별로 같은 별도 CAL320장에서만 보정한다. CAL 재대입 수치는 성능 검증으로 발표하지 않는다.

모든 평가 사진은 이전에 사용한 자료이며 독립 산업현장 입증이 아니다. 정상 벨트 사진 정답이 없어 사진 오탐은 미측정이다. 연구 후보를 선택해도 기존 앱 기본 모델을 자동으로 교체하지 않는다. 전체 항목5% 미만이나 내부 고장 판정을 달성했다는 뜻이 아니다.
