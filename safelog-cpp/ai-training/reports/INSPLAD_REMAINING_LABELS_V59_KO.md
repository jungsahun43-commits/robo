# v59 현재 TEST와 분리된 실제 TRAIN 손상 라벨 감사

v57의 완료된 연결 기록 94건을 재사용했다. 바이트·프레임·기존 묶음을 동일한 순서로 연결하고 저장된 픽셀 연결을 다시 적용했으며, v57 최종 783행의 모든 canonical 묶음이 정확히 같음을 확인했다. 이미지 해독, pHash 거리 계산, 내용 열람, 새 모델 특징·점수·gradient·optimizer는 모두 0회다.

새 publisher TEST 6,481장, 기존 publisher VAL 6,417장, 기존 다른 TEST 8,995장과 연결된 묶음을 새 학습 후보에서 제외했다. 숫자 접미 변형은 별도 자연 사진으로 계산하지 않았다. 단일한 과거 개발 역할은 유지하고 역할 충돌도 제외했다. 기존 모델이나 과거 분리를 소급 변경하지 않았다.

## 다음 자료 확보

실제 산업 금속의 부식 위치 주석이 있는 [원배포자 Ostrava 자료](https://zenodo.org/records/11235637)를 확인했다. 원저자 저장소도 같은 DOI로 연결한다. 공식 API 메타데이터는 공개 CC BY 4.0, 원본 ZIP 384,363,293바이트, 배포자 MD5 `e30f1f62eb85018c2faee44909e69a06`을 명시한다. 이 내용은 다운로드 전 메타데이터 확인이며 아직 주석 좌표·원래 분리·중복·사진 내용을 검수한 것은 아니다.

[BeltCrack 원저자 저장소](https://github.com/UESTC-nnLab/BeltCrack)가 연결한 ScienceDB DOI 10.57760/sciencedb.31181도 확인했다. DataCite 공식 데이터 조건은 CC BY-SA 4.0이며 21파일/42,032,778,597바이트다. 코드의 Apache 2.0과 데이터 라이선스는 구별한다. 현재 저장공간으로 전체 42GB를 받지 않는다. CableInspect-AD는 실제 전문가 제작 손상을 포함하며 데이터 다운로드 페이지가 403으로 응답했다. 웹사이트 라이선스를 자료 라이선스로 간주하거나 접근을 우회하지 않는다.

우선 작은 Ostrava 원본만 고정된 다운로드 정책으로 확보하고, 안전 경로·배포자 MD5·전체 ZIP CRC·파일 목록을 확인한다. 이미지 열람 전에 저자의 TEST를 예약하고 실제 주석 형식·픽셀 중복·촬영 묶음·FIT/VAL/CAL 최소조건을 검토한다. 확보한 자료의 사진 오차율이나 기존 설비 성능이 개선됐다고 미리 주장하지 않는다.
