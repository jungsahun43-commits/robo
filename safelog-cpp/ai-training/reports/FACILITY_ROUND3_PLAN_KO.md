# 3차 보강 계획 — 합성 공동 자료

## 고정한 실험 조건

- 출처: [공식 synth-dacl 자료](https://doi.org/10.60776/9D6E4M), CC BY-NC 4.0.
- synthcavity 두 원본 ZIP의 발행처 MD5를 검사한 뒤 사용한다.
- 입력 사진은 render와 render_noise 두 렌더 변형, 공동 정답은 gt_cavity와 gt_render_cavities의 합집합이다. 같은 장면의 변형을 독립적인 현장 사진으로 계산하지 않는다.
- 합성 사진은 학습 전용이다. 실제 dacl 학습/검증/시험 사진의 원본 픽셀과 같은 자료를 제외하고 내부 중복을 제거한다.
- 합성 사진의 공동 존재 여부만 학습한다. 물기 등 주석이 없는 여섯 항목은 음성으로 간주하지 않고 손실에서 제외한다.
- 1차 모델에서 시작해 전체 사진 512px, 배치 12, 최대 16 epoch, patience 5로 학습한다.
- 기존 실제 학습 사진 6,225장은 모두 유지한다. 합성 사진의 손실 가중치는 0.2이며 합성 자료에는 양성 클래스 가중치를 적용하지 않는다.
- best.pt는 실제 검증 사진 710장의 macro AP로 고른다. 원본 라벨은 수정하지 않는다.

## 후보 선택 및 교체 기준

새 모델은 물기·공동 두 항목에 한해서 검증한다. 기존 다섯 항목은 1차 분류기를 사용한다.
검증에서 각 항목의 오탐률이 증가하지 않고 미탐률이 최소 2%p 줄어든 후보만 비교 대상으로 선택한다.
임계값은 0.05~0.99를 0.01 간격으로 탐색하고 같은 성능이면 높은 임계값을 사용한다.
후보 프로필은 기본 프로필과 별도 파일로 보관해 출시 판단 전에는 기본 서버에 적용하지 않는다.

검증에서 선택한 모델·임계값을 고정한 뒤 기존 시험 975장을 비교한다.
**모든 항목의 FP와 FN이 증가하지 않고, 전체 FP 또는 FN 중 하나가 감소해야 교체한다.**
통과하지 않으면 기존 1차 기본 모델을 유지하고 실패 결과도 기록한다.
시험을 확인한 뒤 임계값이나 항목을 다시 고르는 작업은 하지 않는다.

기존 검증·시험을 반복 사용하므로 이 결과는 독립적인 현장 성능 보증이 아니다.
합성 학습 자료의 사진 수는 실제 현장 사진 수와 구분한다.
새로운 현장/촬영 회차의 정상·손상 사진과 사람이 확인한 정답이 다음 외부 평가에 필요하다.

## 물기 자료 조사

기존 tunnel/wall 자료는 주석만 내려받았고 원본 사진은 별도 계정 접근이 필요해 학습에 넣지 않았다.
다른 연구의 모델 예측 그림을 사람의 정답으로 간주하지 않는다.
이번에 원본·정답·사용 조건을 확인한 신규 자료는 합성 공동 자료이며, 물기의 신규 현장 자료가 확보됐다고 기록하지 않는다.

## 연결 범위

앱의 기존 세 API를 유지한다. 사진 분류 의견은 box=null, evidence_scope=photo_presence이며
위치를 찾거나 구조 안전을 확정한 결과로 표시하지 않는다. Android 실기기 평가는 역할 4와 별도로 수행한다.
