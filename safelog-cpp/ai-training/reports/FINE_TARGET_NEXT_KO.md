# 다음 보강: 같은 공통 분석부의 세밀한 특징 활용

2026-10-15. v19는 학습·평가까지 완료했고 전부 제외했다. **v20은 FIT 조사만 완료, 새 학습0회이며 정식 학습 프로토콜은 미확정**이다.

## 학습 전 FIT 조사

작은 합성 표시에서 v19의 FIT/VAL 정상·합성 구분이 제한된 점을 조사했다. 배경 그룹을 고정SHA로 선택한 FIT12쌍(대상별6쌍, 총24입력)에서만 같은 backbone의 기존 stage3을 읽었다. CAL/TEST 사진이나 새 점수를 사용하지 않았다. 조사 코드·조건은3386269에 먼저 commit했다.

| 기존 공통 분석부의 출력 | 512입력에서 채널/격자 |
|---|---|
| 새로 읽은 기존 stage3 | 24 / 128×128 |
| 원래 low | 40 / 64×64 |
| 원래 high | 960 / 32×32 |

새 함수를 통한 low/high와 원래 forward의 low/high가24입력 모두 bit 단위로 같았다. 전체 parameter/buffer 해시도 전후 같았다. 기존 forward나 return_layers, 가중치에 변경을 가하거나 별도 encoder를 추가하지 않았다. 비교를 위해 실제 encoder 순회는48회였다. 향후 함수 한 번은 같은 encoder를 한 번 순회해 세 출력을 읽을 수 있다.

표시 영역에서의 상대 특징 변화 중앙값은 브래킷 fine0.7457/low0.3567/high0.1947, 튜브0.3741/0.1646/0.0552였다. 표현마다 특징 분포가 다르므로 이 수치를 검출 정확도로 비교하거나 향후 성능 개선을 보장하지 않는다. v19 사진 점수의 원본 대비 변화 중앙값은 브래킷0.01242, 튜브약-0.000000447로, 튜브는 표시가 생겨도 점수가 거의 달라지지 않았다. 이는 FIT12쌍의 조사이고 자연 결함 성능 지표가 아니다.

## 다음 한 후보의 구체화

1. 완료된v19나 합성 생성기를 재실행하지 않는다. `data/industrial-target-synthetic-v19-r1/manifest.json`과 고정 FIT609/VAL162사진(정상+절차 변형)을 그대로 재사용한다. 배경/모양 FIT·VAL 분리는 유지하고 합성 라벨을 자연 결함 정답으로 표시하지 않는다.
2. 새 모델 클래스는 기존v16-r1을 보존하고 `forward_with_fine`로 같은 backbone의 fine/low/high를 읽는다. 기존 모델 메서드의 이름·서명을 덮어쓰지 않는다. fine은 새 사전학습 모델이 아니라 현재 공통 분석부의 기존 중간 출력이다.
3. v19의73채널 decoder를 초기값으로 삼아 fine24→16 projection을 더한89채널 fusion 후보를 검토한다. 원래73입력 가중치는 복사하고 새16입력 가중치는0으로 초기화한다. fine projection과 새 fusion만 학습하고 기존 backbone/equipment 복원부/high projection/다른 분기는 고정하는 한 구성을 우선 정한다. 초기값은 `runs/industrial-target-conditioned-v19/trained/final.pt` SHA256 ae0654d54e4f465e1d3826eade7173fa82d3dfb46fab4287b0c27766afe75255다. TEST에 실패한 가중치의 재채택이 아니라 VAL이 고른 초기값으로만 사용한다.
4. fine 특징 정규화가 필요하면 원본 정상 FIT131장만의 고정 평균·표준편차 공식, 최소 표준편차와 clamp를 먼저 선언한다. 입력 좌표, FP16 경계, cache의 사진 순서/해시, 학습 대상·loss·회차·샘플링·VAL 선택·CAL·반영 guard를 정식 코드/프로토콜에 고정하고 commit한 뒤 새 학습용 feature/gradient를 실행한다. 여러 구조를 TEST 수치로 고르지 않는다.
5. FIT/VAL은 기존 사진과 조작 mask를 사용한다. 자연 결함 VAL이 없다는 한계를 유지한다. 새 fine cache와 기존 low/high cache를 결합한다면 동일 RGB·입력·encoder·순서인지 확인하고 수치 차이 검증 조건을 사전 선언한다. CAL/TEST의 새 특징은 각각 허용된 시점에 원본 RGB에서 추출하며, TEST 사진 점수는 CAL을 고정한 후 계산한다.
6. 새 점수 단독/현재v16 점수와의 max 결합, 기존 정상CAL85% 순서 통계량, 사진 라벨별 최소20장, 미탐5%p 감소/오탐 증가5%p 이내·오탐20% 이하/종류별 회귀 제한을 평가 전에 그대로 등록한다. TEST 임계값을 반복 조정하지 않는다. 위치 지도는 기존 출력이 기본이며 새 합성 학습 지도를 자연 결함 위치 검증 없이 승격하지 않는다.
7. 후보가 실제로 통과하면 패키지 CPU/GPU와 C++ 연동 검사를 새로 수행한 뒤 연구 전달물을 갱신한다. 실패는 보존하고v16-r1을 유지한다. 공개 TEST 반복 개발은 독립 현장 성능이 아니다.

v18의 실제 부품 균열 연구 가중치·135장 CPU/GPU 일치와18장 결함 표본 한계, v14의 전선 관계 사람 검수 대기는 그대로 유지한다. 다음 작업의 수치를 이 조사에서 이미 학습했거나 개선한 수치로 바꾸지 않는다.
