# 검정 브래킷·튜브 주변 특징 예측 학습 결과

2026-10-15 · `industrial-neighbor-surfaces-v15` · **후보 제외, 현재 연구 기준 v13 유지**.

## 실제 학습

같은 공통 분석부를 고정하고 중심을 제외한 주변8개 특징으로 정상 중심 특징을 예측하는 작은 분기를 설비별로 학습했다. RGB에서 완전한 맹점이 생기는 것은 아니다. 기존 분석부의 수용 영역이 서로 겹친다.

검정 브래킷 정상 FIT70·VAL18·CAL30장, 튜브 FIT61·VAL15·CAL23장으로 분리했다. v12의 정확 RGB·회전/반전 pHash 근접 묶음 제외를 이어받고 정상 FIT의20%를 VAL로 먼저 고정했다. 전경 마스킹은 쓰지 않았다. 실제 부품·촬영 그룹이 검증됐다는 뜻은 아니며 부모 모델의 과거 근접 TRAIN 노출은 되돌리지 않았다.

설비별30epoch×48step, **실제 optimizer1,440회씩 합계2,880회**를 완료했다. 브래킷은 VAL로30epoch, 튜브는29epoch를 선택했다. 이 회차는 정상 사진으로 특징 예측을 학습했으며 실제 결함 마스크·구성 관계 라벨 지도학습은 아니다. 미검수 v14 주석은 사용하지 않았다.

## 고정 조건 평가

정상 CAL15% 예산의 순위 기준을 새 TEST 점수 계산 전에 저장했다. 새 분기 단독과 기존 점수의 max 결합 두 후보만 비교했다. TEST를 본 뒤 임계값을 바꾸지 않았다.

## 보존·검증

optimizer journal2,880개를 확인했고 기존 모델의 모든 가중치·버퍼·기준이 정확히 유지됐다. 기존 Python 소스571개 SHA를 검사했다. 보호 파일85,420개의 크기·mtime이 같았으며 이번에는 그 전체 파일의 SHA를 다시 읽는 전수 검사를 반복하지 않았다. 새 단위 검사3개가 통과했다.

채택 후보가 없어 새 앱 ZIP이나 C++ 검사를 만들지 않았다. 예전 C++ 검사를 이번 검사로 세지 않는다. 실패 가중치·정상 특징 캐시·VAL·CAL·TEST 점수·최초 프로토콜과 학습 전 코드 정리 기록을 보존했다. 추가설비12유형 중 사진 오탐·미탐20% 이내8개 상태는 같다.

공개 TEST를 반복 사용한 개발 비교이며 독립 현장 성능이 아니다. 현재 v13 모델·역할4 ZIP은 그대로다. 다음은 실제 결함 위치 라벨이 있는 산업 부품 자료를 출처·이용 조건·중복·그룹 분리 확인 후 보강하는 것이다.
