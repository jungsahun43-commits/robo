# 다음 v68: 저자의 JSON 이미지·다각형 쌍을 검증

## 이 후보를 조사하는 근거

v66의 원본 JPEG/native PNG 직접 대응은 실패로 보존한다. 원저자 고정 `Pre-processing/labelme2voc_.py`는 `LabelFile.imageData`에서 이미지를 읽고, 같은 JSON의 `shapes`를 `shapes_to_label`에 전달한다. 따라서 **JSON에 실제 포함된 이미지와 원래 다각형**을 사용하는 별도 정답 계약은 원저자 변환 경로에서 근거를 찾을 수 있다. 소스 텍스트는 `data/industrial-corrosion-condition-v64-source/author-labelme2voc-static.py.txt`에 보존되어 있다. 다운받은 코드는 실행하지 않는다.

아직 imageData base64를 해독하거나 이 계약의 픽셀/그룹/최종 학습 적격성을 검사하지 않았다. 이것이 JPEG/native PNG 불일치의 원인을 해결했다고 미리 주장하지 않는다. 원저자 JSON 버전 4.5.2와 공식 LabelMe의 해당 버전 정적 로직을 먼저 확인한다. v67의 3.16.7 참조는 실제 생산 버전의 증명이 아니다.

## 먼저 고정할 자료 코드·JSON

1. 새로운 **v68 정책과 코드**를 commit/push한 뒤에만 imageData를 해독한다. v66 manifest와 원래 TEST 예약 SHA를 묶는다. 원래 TEST 44항목과 220파일은 그대로 두며, 예약된 JSON의 SHA는 그 안의 imageData도 포함한다. embedded 보기는 같은 원본 항목의 추가 사본이고 새 자연 사진이 아니다.
2. JSON imageData는 untrusted 데이터다. 허용 ASCII 공백 제거와 strict base64, 문자열/해독 바이트 상한, 단일 프레임 형식·40MP·EXIF 방향·PNG/JPEG 허용 범위·에러 중단 정책을 먼저 선언한다. imagePath는 파일 접근에 사용하지 않고 외부 코드/노트북을 실행하지 않는다. 누락된 이미지나 좌표를 추정하지 않는다.
3. **원래 JSON 좌표와 embedded 이미지 크기**의 실제 대응을 검사한다. 원저자 라벨 목록과 원래 shape 순서를 보존한다. 다각형을 원저자의 확인된 방식으로 rasterize하는 것은 제공된 다각형 주석의 표현 변환이며, 제공된 native PNG를 임의로 수정한 결과로 설명하지 않는다. 원저자 로직의 캔버스 밖 polygon 처리도 먼저 확인한다. 다각형 이외의 도형·알 수 없는 라벨·비유한 점·불명확한 크기는 미리 정한 조건대로 중단한다.
4. Good/배경은 미미한 부식을 포함한다. 미래 학습은 원래 **4상태 라벨**을 유지하는 한 후보를 우선 검토한다. 이 자료의 Good을 이진 무부식 정답으로 바꾸지 않는다. Fair/Poor/Severe를 실제 깊이·구조 안전 측정으로 확대하지 않는다. bbox를 pixel 정답으로 만들지 않는다.
5. 새 embedded RGB 지문만 추가한다. v66의 기존 882보기/그래프와 v57의 기존 94연결, Ostrava 및 모든 보존 TEST 지문을 재사용한다. 오래된 전체 해독/거리 감사를 다시 돌리지 않는다. 같은 원본 항목의 모든 사본과 MPO 프레임을 연결한다. 원래 TEST와 외부 TEST 연결 TRAIN은 제외한다.
6. **v66의 FIT/검증/CAL 역할 하나를 잠근다.** 새 근접 연결이 여러 역할을 합치면 해당 새 개발 그룹을 제외하고, 다른 역할로 옮기거나 다시 배정하지 않는다. 원TEST는 삭제하지 않는다. 새로운 TEST 연결을 기존 학습 가중치에서 소급 제거했다고 주장하지 않는다.
7. 사진·그룹·각 상태별 픽셀/사진 최소 조건을 새 계산 전에 정한다. 미달이면 학습 전에 중단하고 어려운 상태를 빼거나 최소를 낮추지 않는다. 데이터 계약의 지원 범위가 제한되면 그대로 보고한다. 통과한 고정 첫 FIT만 시각 QA하고 내부 검증/CAL/TEST 예시를 골라보지 않는다.

## 자료가 준비된 뒤

한 공통 encoder에서 새로운 4상태 분기 **하나**를 검토한다. 기존 v16·승인 3작업·연구 v62의 tensor/buffer/metadata/기준/기본 지도는 보존한다. 구조·초기값·학습 대상·실제 정답/ignore·입력 좌표·학습률·회차·손실·샘플링·VAL 선택·CAL·채택 조건·장치 오차·delta 검증을 코드/JSON에 확정하고 사전 push한 뒤에만 특징/gradient를 계산한다. 현재 **정식 학습 프로토콜은 미확정, 새 optimizer 0회**다.

다른 자료의 부식 mask에는 원래 severity 정답이 없으므로 임의 4상태를 부여하지 않는다. 이진 마스크와 함께 쓰는 다중 과제를 자동으로 추가하지 않는다. 공통 encoder나 가짜 출처·날짜 embedding을 새로 만들지 않는다. TEST 모델 점수를 보고 구조/조건/임계값을 바꾸지 않는다.

현재 디스크 여유는 약 3.8GB다. 1GiB reserve를 유지하고 새 dense 전체 캐시·435MB parent 복제를 만들지 않는다. 이후 특징은 bounded RAM/online/streaming 방식을 사전 설계한다. 원본 ZIP·JSON·PNG·실패 모델·로그·캐시는 모두 보존한다. 새 정책을 통과하기 전까지 v66은 계속 실패 상태이며 기존 앱과 전달물은 유지한다.
