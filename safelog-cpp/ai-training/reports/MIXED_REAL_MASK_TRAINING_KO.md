# v17 실제 마스크 혼합 학습

2026-10-15. 다음 조건을 코드·JSON 프로토콜과 함께 commit한 뒤 학습한다. 이 문서는 성능 개선 완료 보고가 아니다.

## 목적과 자료

v16의 FIT loss는 감소했지만 VAL loss가 증가해1epoch가 선택됐다. 이 과적합 관찰을 바탕으로 학습률을1e-3에서1e-4로 낮추고, 새 분기의 고수준 투영을 고정하며 두 출처의 실제 마스크 손실을 균등하게 혼합한다. 한 후보만 실행한다.

| 출처 | FIT 정상/결함 | VAL 정상/결함 | 좌표 |
|---|---:|---:|---|
| 자기 타일 | 499 / 217 | 201 / 63 | 512×512 비율 유지 letterbox |
| KSDD2 | 1,254 / 146 | 389 / 52 | 폭256×높이704 비율 유지 letterbox |

새 사진 수는 FIT2,116장·VAL705장이다. 기존에 확보한 자료를 재사용하는 것이며 추가 촬영이나 새 데이터 다운로드를 뜻하지 않는다. 자기 타일은 원저자가 허용한 학술 연구 범위로 사용하고 비상업·논문 인용 조건을 유지한다.

기존 고정 캐시의 체크섬, 사진 순서, FP16 경계, 마스크와 valid 영역을 확인한다. KSDD2의 현재 FIT/VAL1,841장과 기존 TEST5,435장, 자기 타일1,327장 사이의 정확 RGB/8방향 pHash거리2 이내 후보는0개였다. 자기 타일과 기존 TEST는 v16의 선행 감사도 유지한다. 이 검사는 동일 물리 부품·촬영 그룹의 독립성을 증명하지 않는다.

## 실제 학습

- 현재 v16-r1 모델의 모든 기존 가중치·기준은 보존한다. 기존 KSDD 마스크 헤드를 새 `mixed_surface_head`로 복제하고, 복제본의 fusion 층만 학습한다. 복제본의 high projection도 고정한다.
- 한 optimizer step마다 두 출처를 각각4장(정상2/결함2)씩 처리한다. 출처별 손실에0.5를 곱해 역전파하고 optimizer는 한 번만 갱신한다. 자기 타일은 결함 종류를 균등 선택하며 사진은 그룹 크기의 역수로 추출한다. KSDD도 라벨별 그룹 크기 역수로 추출한다.
- 기존 valid BCE+Dice+사진 BCE 손실을 사용한다. 각 출처의 원래 좌표에서 학습하며 마스크를 임의의 공통 크기로 찌그러뜨리지 않는다. 캐시 특징·마스크·valid를 함께 좌우/상하 반전한다. 새 RGB 증강 추론을 했다고 세지 않는다.
- AdamW, lr1e-4, wd1e-4, cosine30epoch 최소1e-6, clip5, FP32, TF32off. 30epoch×64step=예정1,920회 실제 optimizer 갱신이다.
- 초기0epoch와 각 완료 epoch의 VAL을 비교한다. 출처를 균등하게, 출처 안에서는 정상/결함 종류를 균등하게 가중한 loss가 최소인 가중치를 선택한다. 동률이면 이른 epoch를 유지한다.
- epoch별 optimizer·scheduler·RNG 상태와 step별 실제 갱신 장부를 남긴다. 오류가 나면 부분 상태와 로그를 보존하고, 부분 epoch 재실행이 생기면 실제 작업 횟수에 포함한다.

## 평가와 반영

선택된 가중치의 CAL 보정을 저장한 뒤 고정 TEST를 평가한다. 자기 타일은 CAL minimax, 검정 브래킷·튜브는 기존 정상 CAL의85% 순서 통계량을 쓴다. 새 점수 단독과 현재 모델 점수와의 최대값 결합 두 방법을 미리 등록한다.

브래킷·튜브 후보는 현재 v16 대비 미탐이5%p 이상 감소하고 오탐 증가는5%p 이내이며 오탐20% 이하인 경우에만 부분 개선 후보로 채택한다. 결함 종류별 회귀 제한과 최소 표본 수도 확인한다. 자기 타일 자체는 오탐·미탐 각각20% 이내와 종류별 기준을 만족해야 새 연구 유형 후보가 된다. 실패 후보도 삭제하지 않는다.

현재 공개 TEST를 반복 사용한 연구 개발 결과다. 독립 산업현장 성능으로 설명하지 않는다. 대상 설비의 기존 위치 지도와 pixel 기준은 바꾸지 않는다. KSDD·볼스크루·전선 연결부 등 기존 채택 분기도 보존한다. 후보가 통과하면 새 ZIP의 실제 CPU/GPU·C++ 연결 검사를 마친 뒤 전달한다.

전선 연결부 관계 라벨24장의 사람 검수는 별도로 남아 있다. 자동 제안이나 QA 시뮬레이션을 정답으로 넣지 않는다.
