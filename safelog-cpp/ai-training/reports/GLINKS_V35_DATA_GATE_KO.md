# v35 G-Links 자료 분리 검사 결과: 학습 전 중단

원저자 v1 원본 ZIP306,973,826bytes를 받아 배포 MD5 `7faf736f2da8e3fb98b12f73bbf35889`, 전체 ZIP CRC, 안전 경로·중복 멤버·symlink 조건을 검사했다. 로컬 SHA256은 `f838533cf779a20af519f61f56b5bfd2f4df0c951c79f36f95d230d0b884793a`이며 저자 제공 SHA256이 아니다. 원래 파일과 초기 감사 원문을 보존하고 다운로드/CRC를 반복하지 않았다.

실제 원본은 JPEG3,992장으로 TRAIN good3,424 / TEST good403 / TEST defect165다. 웹 설명의 TEST good464와61장 차이가 있으며 로컬 원본 수를 사용한다. **마스크 파일은 원본 ZIP에0개**이므로 설명에 있는 마스크를 이미 확보했다고 기록하지 않는다. 자동 전경/중앙배치 버전은 받지 않았고 새 사진으로 세지 않았다. 개별 JPEG를 재압축하지 않고 고정 숫자 파일명으로 보존했으며 원본 bytes/RGB SHA/8방향 pHash/해상도를 기록했다. 모든 사진은1280×960이다.

266225d에 원저자 TEST 보존과 그룹·중복·분리·최소조건을 먼저 commit/push한 뒤 CPU 픽셀 감사를 수행했다. 파일명 UUID는 TRAIN25 / TEST50개이고 서로 겹치지 않지만 검증된 물리 부품 ID라고 단정하지 않는다.

같은 UUID 또는 정확RGB 또는 회전·반전 pHash거리2 이하의 후보를 연결하니 **202,666쌍·연결묶음1개**가 됐다. 따라서 원저자 TEST568장은 모두 보존했고, TEST연결 TRAIN3,424장을 전부 제외했다. FIT/VAL/CAL이0장이라 사전 최소조건을 통과하지 못했다. **새 encoder특징·모델점수·sourcegradient·optimizer0회**에서 중단했다. 사진 수 최소조건이나 pHash거리를 낮춰 통과시키지 않는다. 이전 보존 TEST8,855장도 비교했다.

pHash는 낮은 해상도의 외형 유사성 후보이며 물리 동일성이나 정확한 중복의 증명이 아니다. 촬영 배경·외곽선의 공통성이 과도한 연결에 영향을 주었을 가능성이 있으나, 실제 장면 확인이나 RGB 대응 검증 없이 원인을 확정하지 않는다. 실패 manifest와 모든 제외·연결 목록을 유지한다. 현재 앱 모델 v16-r1, 원래 위치 지도와 다른 유형은 그대로이며 새 전달 ZIP/CPU/C++검사는0이다.

다음 v36은 **publisher TRAIN만**의 고정된 두 UUID/근접8쌍을 대상으로 하는 자료 진단이다. 미리 선택한 두 UUID는 향후 VAL/CAL/TEST로 쓰지 않는다. 기존 TEST 그림이나 모델 점수로 사례를 고르지 않고 원본색의 방향별 차이와 알려진 동일사진 변형 대조를 확인한다. 새 중복 통과 임계값·FIT 분리를 여기서 만들지 않는다. 원자료·원저자 라벨·v35 실패조건은 유지하며 새 실제 학습은 별도 검증과 사전 프로토콜을 통과한 뒤에만 가능하다.
