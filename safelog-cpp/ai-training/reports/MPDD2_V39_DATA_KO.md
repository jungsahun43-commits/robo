# MPDD2 흰색 브래킷 원본 다운로드·분리 감사

사전 조건 commit `590122c` 이후 공개 Drive의 원본 PNG 335장을 받았다. 총 11,406,201바이트이며 모든 파일의 PNG 형식·해독·개별 수신 SHA256·RGB 해시·해상도(256×256)를 검사했다. 로그인·쿠키·개인정보 제출을 사용하지 않았다. SHA256은 저자가 제공한 체크섬이 아닌 로컬 무결성 기록이다. 자료 DOI `10.1109/ICUMT57764.2022.9943437`, 원저자 CC BY-NC-SA 4.0의 비상업 연구·인용·동일조건을 유지한다.

| 분리 | 정상 사진 | 이상 사진 | 보수적 연결 그룹 |
|---|---:|---:|---:|
| FIT | 113 | 0 | 110 |
| 검증 | 26 | 0 | 24 |
| 보정 | 25 | 0 | 24 |
| 원래 TEST | 49 | 91 | 122 |
| TEST 근접 제외 TRAIN | 31 | 0 | 학습 제외 |

정확 RGB 또는 회전·반전 8방향 pHash 거리 2 이하를 연결해 63개 근접 쌍, 총 280개 그룹을 만들었다. 원래 TEST 140장은 보존했고 이와 연결된 TRAIN 31장을 제외했다. 기존 보존 TEST 8,855장과 새 사진 사이의 직접 정확·근접 후보는 0이었다. 나머지 TRAIN 그룹은 사전에 고정한 SHA 순서와 비율로 한 번만 배정했고 FIT·검증·보정·TEST 간 그룹 중복은 없다. 사진 수와 연결 그룹 수의 최소조건을 통과했다.

물리 부품/촬영 ID는 확인되지 않았다. 숫자 파일명과 근접 그룹이 실제 물리 부품 수나 독립 촬영을 증명하지 않는다. 직접 근접 0도 독립 현장 자료라는 증거는 아니다. 기존 모델의 과거 근접 노출을 해소했다고 주장하지 않는다.

분리 완료 후 FIT ID 정렬 첫 3장(001/002/003)만 AI로 시각 확인했다. 어두운 배경의 길고 밝은 금속 부품이며 자세와 끝부분의 잘림이 다르다. 이 확인은 전체 라벨에 대한 사람 전문가 검수가 아니다. VAL/CAL/TEST 사진 내용은 선택해 열람하지 않았다. 실제 손상 FIT 라벨·물체 관계 정답·pixel mask는 없다. 정상 라벨은 배포자의 가시적 외관 정상이며 설비 전체의 기계·전기 작동 정상 정답이 아니다.

최종 manifest SHA256: `c4c99f21bfd3decb2c05e7d2b2dc87a0831052bf5d0f884069751805d12a3560`. 데이터 감사 단계의 encoder 특징·학습·모델 사진 점수는 0회다. 다음 v40은 이 분리만 사용한 정상 복원 학습 후보 하나이며, 다른 설비나 기존 검정 브래킷·튜브의 성능 개선으로 합산하지 않는다.
