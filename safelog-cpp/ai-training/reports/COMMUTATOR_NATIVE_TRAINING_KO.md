# v18 정류자 부품 표면의 실제 균열 마스크 학습

2026-10-15. `industrial-commutator-v18-protocol.json`과 코드를 commit한 뒤 한 후보를 학습한다. 결과 보고서가 아니다.

## 후보와 실제 자료

원저자 fine mask 자료의 고정 `manifest-r1.json`을 사용한다. FIT147정상/21결함, VAL35/5, CAL35/5, TEST117/18이다. 부품 단위와 정확·회전반전 근접 묶음을 분리하고, 원저자 fold0 TEST를 고정한 자료다. 정상 표면사진은 부품 전체의 정상 작동 정답이 아니다. CC BY-NC-SA4.0 및 DOI10.1007/s10845-019-01476-x 인용 조건을 유지한다.

기존 모델의 모든 분기와 기준을 보존하고 KSDD 마스크 헤드를 `commutator_surface_head`에 복제한다. 복제본의 high projection도 고정하며 fusion 층만 갱신한다. 같은 공통 backbone에서 얻은 low40/high960 특징을 사용한다. 새 함수 이름을 구별해 기존 갈색/흰색 브래킷용 메서드 서명을 가리지 않는다.

## 고정 학습 조건

- 세부 균열을 보존하기 위해 폭512×높이1408의 비율 유지 letterbox127을 사용한다. 이미지는 bicubic, 실제 마스크는 nearest로 처리한다. 원본 영역만 valid다.
- FIT의 유효 음성/양성 pixel 비율에서 `clamp(sqrt(negative/positive),10,100)`으로 BCE 양성 가중치40.99472694487793을 정했다. CAL/TEST에서 고른 값이 아니다. BCE+softDice+0.5사진 BCE 손실을 사용한다.
- 한 step에 정상2/결함2장을 라벨별 그룹 크기의 역수로 추출한다. 캐시 특징·마스크·valid를 함께 반전하고 batch 전체를0/90/180/270도로 회전한다. 회전 뒤 바뀐 높이/너비를 유지한다. 원본 RGB를 새로 통과한 증강 사진으로 세지 않는다.
- AdamW lr1e-4, wd1e-4, cosine30 최소1e-6, clip5, FP32, TF32off. 30반복 epoch×64step=예정1,920회 실제 optimizer 갱신이다. 반복 추출 횟수를 실제 결함21장의 수와 혼동하지 않는다.
- 초기 epoch0와 각 완료 epoch 중 정상·결함의 균등 VAL loss가 가장 작은 가중치를 고른다. 동률이면 이른 epoch를 쓴다. VAL 양성은5장으로 불확실성이 크다.
- 초기값·optimizer·scheduler·RNG와 실제 step 장부를 보존한다. 부분 재실행 작업도 실제 갱신 수에 포함한다. 새 특징 캐시는 파일 SHA와 사진 순서·좌표를 기록한다.

## 보정과 평가

선택된 후보와 미적응 기존 KSDD 헤드를 같은 새 소스 입력에서 각각 CAL minimax로 보정한다. 미적응 헤드는 새 앱 유형의 과거 운영 성능을 뜻하지 않는다. 두 보정을 저장한 뒤 원저자 TEST를 처음 점수화해 사진 오탐/미탐과 Wilson95% 구간, 원본 좌표 pixel 지표(@0.5)를 기록한다. TEST 결함18장은 최소20장에 못 미치므로 이 소스를 앱 유형이나20% 목표 통과로 등록하지 않는다.

브래킷·튜브는 새 점수 단독과 기존 v16 점수와의 max 결합만 평가한다. 기존 정상 CAL의85% 순서 통계량으로 보정한다. 현재v16 대비 미탐5%p 이상 감소, 오탐 증가5%p 이하, 오탐20% 이하, 표본과 결함 종류별 회귀 제한을 모두 만족해야 부분 개선 후보가 된다. 기존 위치 지도·pixel 기준은 바꾸지 않는다. 실패 후보는 보존하고 기존v16-r1을 유지한다.

공개 MPDD TEST 반복 개발 결과는 독립 현장 성능이 아니다. 채택 후보가 생기면 새 패키지의 실제 CPU/GPU와 C++ 검증을 완료한 뒤 연구 전달물을 교체한다.
