## 한 후보와 사전 자료 조건

현재 분기는 새 source 안의 실제 결함·주석상 음성 영역만 학습했고 target 정상 전체 사진을 학습하지 않았다. 이번에는 원래 중복 감사를 통과한 **정상 튜브48장**을 함께 학습해 target 정상에 대한 과도한 활성화를 줄이는 가설을 검증한다. source 실제 mask35장과 같은 사진의 주석상 음성 영역도 함께 유지한다. 가짜 category embedding을 넣지 않는다.

v22의 고정9영역·실제 mask 좌표·원본 그룹 근접 제외를 그대로 상속한다. source35FIT/10VAL, Scratch6장 제외와 정상튜브48FIT/15VAL을 바꾸지 않는다. FIT는 source312crop+튜브432crop=744, VAL은 source88+튜브135=223crop 예상이며 감사 후 SHA를 고정한다. source35/10·정상튜브48/15를 실제 사진 수로 구분하고 crop 수를 새 사진으로 세지 않는다.

FIT 실제 양성 원본20장 이상·SDI/SPDI 각각5장 이상·각 source 음성crop, 정상튜브FIT30장 이상, VAL 실제 양성8장 이상·주석상 음성 원본8장 이상·정상튜브10장 이상이 필요하다. 브래킷 정상29장으로 중단한v22의 요건은 그대로 실패 상태로 남긴다. 이번 후보의 새 학습·새 TEST 평가는 튜브에 한정하며 브래킷과 나머지 분기는 현재v16 그대로다.

## 학습·평가

- 같은 공통 encoder의 fine/low/high를 쓰는 상세 판별부를 v23 VAL선택 가중치로 초기화한다. 새 fine projection/fusion만 학습하며 high projection·모든 부모 tensor/buffer/메타데이터는 고정한다. 입력 잔차는 모든 source/target/추론에서0이다.
- seed2424,30epoch×64=예정1920optimizer. 배치8은 SDI양성2/SPDI양성2/각 source 주석상 음성1개씩/정상튜브2다. 원본 사진별 균등 추출 후 해당 라벨crop을 균등 복원 추출한다.
- 같은 pixel class-mean BCE+softDice+0.5top32사진BCE, AdamW lr1e-4/wd1e-4,cosine최소1e-6,clip5,FP32/TF32off,paired cached H/V 반전을 사용한다.
- VAL은 실제양성/주석상음성/정상튜브 세 집단을 동일 가중한다. 집단 안에서 원본 사진의 crop loss를 먼저 평균하고 사진들을 평균한다. epoch0 포함 가장 이른 최솟값을 선택한다.
- 모든 원본 사진에 고정9영역을 적용하고 crop 점수 최댓값을 원본 사진 점수로 쓴다. GT 위치로 추론 crop을 고르지 않는다. 정상튜브 CAL23장의85% 순서통계량을 먼저 저장하고 새 점수 단독/max결합 두 방식만 TEST101장에 적용한다.
- 기존 조건인 사진 라벨별20장 이상·미탐5%p 이상 감소·오탐 증가5%p 이내/오탐20% 이하·종류별 표본10장 이상이면 미탐 회귀5%p 이내·선택epoch>0를 유지한다. TEST 임계값·통과 조건을 반복 변경하지 않는다.

통과할 때만 새 패키지 CPU/GPU·모든 alias·실제 C++·기본 위치 PNG 보존을 새로 검사한 뒤 반영한다. 원래 위치 지도·pixel 기준은 유지한다. 실패는 보존하고v16-r1을 유지한다. source의 음성crop이 전체 기계 정상 정답은 아니다. 물리 촬영 그룹·부모 과거 근접 노출·독립 현장 미검증과 raw 이용조건을 유지한다. source는 학술 연구 전용/상업 금지·원 제공자/주석 추가 배포자를 인용하며 raw/가중치/ZIP은 Git에서 제외한다.
