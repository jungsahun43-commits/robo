# 다음 대상 설비 보강: FIT 기반 합성 표면 표시 검토

2026-10-15. **가능성 검토10예시 완료, 새 모델 학습0회.** v19 정식 학습 프로토콜은 아직 고정하지 않았다.

## 이번에 확인한 점

v18은 새 정류자 표면에서 사진 오탐11.11%/미탐0/18장으로 학습됐지만 브래킷·튜브 전이는 모두 실패했다. 이 결과를 바탕으로 다음에는 대상 설비의 실제 정상 FIT 배경/재질에서 학습하는 후보를 검토한다. 기존 TEST 임계값만 바꾸지 않는다.

새 실제 결함 수집을 한 것으로 표시하지 않기 위해, 이미 허용된 MPDD 정상FIT 사진과 KSDD1 FIT 실제 마스크 모양에서 **절차적으로 합성한 표시**를 따로 구분한다. 이 표시는 자연 결함의 사람 검수 정답이 아니다. 검수 대기 중인 전선 관계24장이나 TEST 주석을 사용하지 않는다.

## FIT 예시와 관찰

MPDD 정상FIT4장(브래킷2/튜브2), KSDD1 실제 마스크FIT3장을 고정SHA로 선택했다. 원래 마스크 주변을 inpaint한 배경과의 밝기 잔차를 추정해, 모양을 작게 회전/배치하고 밝기를 가감했다. inpaint 결과는 실제 촬영한 결함 없는 정답이 아니다. 입력 색 기반 전경 후보는 **배치 위치를 잡는 휴리스틱**이고 부품/결함 분할 정답이 아니다. v12의 전경 점수/TEST 보정 실험을 다시 수행하지 않았다.

예정12예시 중10개를 만들었고, 모양이 너무 작거나 전경 후보 안에 배치하지 못한2개를 제외했다. 실패를 정상 라벨로 바꾸지 않았다. 실제 변경 pixel과 저장 mask가 정확히 같은지 검사했다. 원래 FIT·마스크와 고정 예시, 소스 코드 사본, 두 접촉 시트와 해시를 `data/industrial-target-synthetic-v19`에 보존했다. VAL/CAL/TEST 사진·마스크를 읽거나 모델을 새로 점수화하지 않았다.

AI가 FIT 접촉 시트10개를 확인했다. 대부분 색 전경 안에 표시가 놓였지만 일부는 작거나 정상 반사광처럼 보인다. 한 예시는21pixel 변경으로 약하고, 튜브 가장자리에서 배경/부품 구분도 불확실하다. 실제 고장 사진의 물리적 타당성을 검증했다는 뜻은 아니다.

## 다음 후보를 고정하기 위한 구체안

1. 현재 예시와 소스는 그대로 보존하고 별도r1 생성기를 만든다. 실제 변경32pixel 이상과 더 분명한 contrast 조건을 FIT 관찰로 미리 선언한다. 실패 위치/작은 모양/변경 없는 사진을 제외하고 원인을 기록한다. 전경 후보를 실제 자연 결함 정답으로 승격하지 않는다.
2. 정상 배경은 기존v15의 FIT브래킷70/튜브61장만 학습에 사용한다. 검증은 기존VAL18/15장으로 분리한다. 모양 자산도 KSDD1 FIT결함21장과 VAL결함5장을 서로 나눠 쓴다. 각 원본당 고정4예시 정도를 검토하되 생성 횟수·최대 실패 횟수를 정식 프로토콜에서 확정한다. 반복 변형 수를 새 원본 사진 수로 세지 않는다.
3. 단순 합성 표시 외형만 외우는 것을 줄이기 위해, **같은 공통 backbone의 low/high 특징과 고정된 기존 category-conditioned equipment 재구성 잔차**를 함께 새 decoder에 넣는 한 후보를 검토한다. 기존 backbone/equipment head/점수·위치 기준은 그대로 둔다. v18 헤드를 초기값으로 쓴다면 연구 checkpoint의SHA를 명시하고 기존v16 전체는 보존한다. 새 class는 기존 메서드 이름·서명을 가리지 않는다.
4. 예를 들면 high960→32와 low40의72채널에 재구성 cosine잔차1채널을 추가한73채널 decoder를 만들 수 있다. 새 입력 채널은0으로 초기화하고 기존 fusion72채널 가중치는 v18에서 복사하는 구성을 먼저 코드로 검증한다. 구조·학습 대상·학습률/회차/샘플링·VAL 선택·CAL·반영 기준은 **학습 전에** 고정하고 commit한다. 이 문서는 확정 프로토콜이 아니며 임의의 여러 조합을 돌리라는 지시가 아니다.
5. 검증은 정상/합성 라벨을 구분해 보고한다. 자연 결함 VAL이 없다는 한계를 남긴다. CAL은 기존 정상CAL브래킷30/튜브23장을 유지하고, 전체 사진 점수에85% 순서 통계량을 적용한다. 대상 TEST나 근접 사진은 학습·합성 자산으로 넣지 않는다.
6. 고정 TEST에서 새 점수 단독과 기존v16 점수와의 max 결합만 평가한다면, 미탐5%p 이상 감소/오탐 증가5%p 이내/오탐20% 이하/최소 표본/종류별 회귀 제한을 그대로 사전 등록한다. 새 target 위치 지도는 실제 결함 검증 없이 기본 지도로 교체하지 않는다. 통과 후보만 패키지 CPU/GPU·C++ 연결 검사를 거쳐 반영한다.
