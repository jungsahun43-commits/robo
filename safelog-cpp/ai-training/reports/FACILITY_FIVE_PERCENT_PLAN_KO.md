# 시설 항목별 5% 미만 목표

## 정의와 범위

사용자의 5% 목표를 우선 **균열·박락 각각의 사진 존재 여부 미탐률과 오탐률이 모두 0.05 미만**으로 해석한다.
다른 항목의 정확도나 현장 전체 오차율을 이 두 항목 성적으로 대체하지 않는다.
단순 평균 오차는 손상이 드문 자료에서 미탐을 숨길 수 있으므로 별도로 보고한다.
율은 FN/(TP+FN), FP/(FP+TN)으로 계산하고 분모가 0이면 미정이다. 목표 판정은 엄격한 <5%이다.

현재 4차 실험은 5% 미달이다. 기존 OR 결합은 검출기 오탐을 제거할 수 없으므로
새 분류기의 단독 존재 판정/검출 의견 재확인을 별도 후보로 평가한다. 위치 정확도와 구조 안전 판정은 대상이 아니다.

## 분리

- DACL 원래 train6,225/val710/test975를 유지한다.
- DamSegment 원래 보류 test491개는 그대로 보류한다. 원래 train2,009개만 다시 그룹별 train/val 약80/20으로 나눈다.
- 원래 test491개 및 DACL test975개는 optimizer, 임계값 탐색, 반복 학습의 체크포인트 선택에 사용하지 않는다.
- DamSegment 새 val은 4차 모델에 이미 학습되었으므로 4차 가중치로 시작하지 않는다. 공식 ImageNet 초기화 또는 DamSegment에 학습되지 않은 1차 가중치로 시작한다.
- 같은 패치 ID/유사 사진 그룹을 통째로 나눈다. 단일 댐의 원본 장면 ID가 없다는 한계는 유지한다.

## 학습·반복

첫 시도는 ImageNet 초기화 EfficientNetV2-S, 전체사진384, batch8, 최대24epoch, patience6, seed43.
기존 DACL 일곱 정답 및 추가 자료 두 정답만 학습한다. 미확인 정답은 손실에서 제외한다.
정답 불균형에 맞춘 양성 가중 BCE와 gamma1.5 focal 강조, 두 손상 중 하나가 있는 학습 사진의 제한된 oversampling을 사용한다.
추가 실제 자료는 가중치1.0으로 사용한다. 시험 오답 사진을 추가 샘플로 넣지 않는다.
기존 검증과 새 댐 검증 각각에서 두 항목의 최악 미탐·오탐을 최소화하도록 임계값과 체크포인트를 고른다.
임계값은 두 검증 자료 모두의 최악 오류를 최소화하며, 동률은 오탐이 작은 것을 선택한다.
검증을 보고 다음 시도를 정하되 시험은 반복 시도의 순위 선택에 사용하지 않는다.
각 시도의 조건·분리·가중치 해시·실패 결과를 남기고 기존 실험/기본 모델을 덮어쓰지 않는다.
개선이 멈추면 학습 횟수만 무한 반복하지 않고 데이터·라벨·작은 손상 해상도 등의 원인을 조사한다.

## 최종 확인

검증에서 목표에 도달하면 설정을 고정한 후 보류 시험을 확인한다. 요청에 따른 추가 학습도
별도 실험으로 기록하며 시험 결과로 임계값을 조정하지 않는다.
시험에서 5% 이상이면 목표 미달로 기록한다. 반복해서 확인한 시험 또는 같은 시설 패치는 독립적인 현장 성능 증거가 아니다.
점 추정 <5%와 표본 불확실성을 구분한다. 공개 자료 점수만으로 현장 오차율을 보장하지 않는다.
앱 기본 교체는 검증된 가중치·설정·CPU 실행·기존 항목 회귀 확인까지 완료한 경우에만 수행한다.

## 첫 시도의 검증을 근거로 추가한 후속 조건

첫 시도의 검증에서 댐 균열은 5% 아래인 구간이 나타났으나 기존 전체 사진과 박락이 목표에 미달했다.
후속 시도는 두 자료의 학습 노출량을 맞추고 실제 가중 표본 분포로 자료별 양성 손실 가중치를 계산한다.
기존 학습 부모 사진의 공개 폴리곤/마스크만 사용해 작은 손상 상세 패치 12,041개를 준비했다.
이는 학습 증강이며 새 현장 사진 수가 아니다. 같은 부모의 자식은 전부 학습에만 속한다.
픽셀이 1~15개만 걸친 클래스는 미확인으로 두어 거의 보이지 않는 조각을 강제로 양성/음성으로 만들지 않는다.
두 목표 항목 손실 강조3.0, gamma1.0, 이전 시도의 검증 선택 가중치에서 시작,
동일한 새 검증/보류 시험을 유지하며 seed44, 최대18epoch, patience6을 사용한다.
모델 입력384 전체사진 외에 검증에서 전체+2×2(5뷰), 전체+3×3(10뷰)의 max-score 결합도 고른다.
뷰 조건·공통 임계값의 선택은 두 검증 자료만 사용한다. 보류 시험 결과는 이 선택에 사용하지 않는다.
추가 공개 CODEBRIM 파일은 다운로드·공식 MD5·정답 매핑·그룹 분리를 확인한 후에만 다음 학습에 사용한다.

## 고해상도 및 새 실제 자료 후속 조건

첫 모델 검증의 균열 면적 <1% 양성 93개 중 34개, 면적 ≥1% 양성 118개 중 15개가 미탐이다.
사진 전체와 작은 조각의 훈련 노출 차이를 줄이는 고해상도 시도는 기존 첫 V2-S 체크포인트에서 시작한다.
입력640/batch8, 상세 증강 노출 목표0.35, 자료 노출 DACL0.85/Dam0.15, gamma1.0,
두 목표 손실 강조2.0, seed45, 최대16epoch, patience5로 기록한다.
후속 데이터 추가와 혼동 원인 판단은 검증 사진으로만 진행하며 원래 정답을 바꾸지 않는다.

CODEBRIM은 공식 비균형 ZIP(MD5 c1612d9674e2e628e72e7f5817c40130)만 사용한다.
ZIP 목록상 train6,481/val616/test632 패치, 원본 image ID1,524개이며 부모 ID의 공식 분리 교차는0이다.
이는 원본 현장1,524곳이라는 의미가 아니다. 실제 파일 전체 픽셀 검증·중복/기존자료 검사 후 수량을 확정한다.
각 XML의 다섯 결함만 알려진 정답이고 물기/공동은 항상 미확인이다.
원본 사진 ID 및 픽셀 중복이 검증/시험과 겹치면 해당 부모 그룹을 제외한다.
원본/가공 자료는 Git이나 전달 ZIP에 넣지 않는다. 연구용 모델에도 CODEBRIM 비상업 교육/연구 조건을 적용한다.

새 실제 자료 시도는 검증에서 가장 좋았던 동일 clean split V2-S로 시작하고,
입력640/batch8, 상세 노출0.25, DACL0.70/Dam0.10/CODEBRIM0.20, gamma1.0,
두 목표 손실 강조2.0, seed46, 최대18epoch, patience5를 사용한다.
CODEBRIM 공식 val을 추가해 세 검증 자료 모두의 항목별 미탐/오탐 <5%를 목표로 평가한다.
새 자료 test 역시 optimizer·임계값/뷰/모델 선택에는 넣지 않는다.
CODEBRIM test와 기존 보류 시험은 세 검증 자료가 모두 통과했을 때만 고정 설정으로 확인한다.
모델/임계값을 선택한 검증 수치는 독립 시험 성능으로 제시하지 않는다.

실제 XML 사전 검사에서 모든 여섯 태그가0인 미확정 항목52개(train43/val5/test4)를 발견했다.
정상 Background=1과 구분하여 이52개는 모델 점수를 보기 전에 학습·평가에서 제외한다.
XML에만 있고 파일이 없는 Background5개도 사진 수로 세지 않는다.
이 제외 및 변환 때문에 원본 CODEBRIM 공식 벤치마크 수치와 직접 비교하지 않는다.
95% Wilson 구간은 고정 모델과 독립 표본을 가정한 참고 값이며, 반복 선택한 검증 및 같은 장면 패치의 현장 보장 구간이 아니다.

## 전체 사진 방식이 정체될 때의 위치 감독 학습

기존 세 시도가 전체 사진 최악 오류 약24~26%에서 정체되었다.
실제 CODEBRIM 보강도 목표에 미달하면 새 사진 추가만 반복하지 않고 학습 신호를 바꾼다.
공식 COCO/VOC 사전 학습 LRASPP MobileNetV3의 특징과, 새 일곱 시설 픽셀·사진 헤드를 사용한다.
DACL의 학습 폴리곤과 새 Dam 학습 마스크 및 같은 TRAIN 부모의 상세 조각만 위치 감독에 쓴다.
CODEBRIM 양성의 위치는 미확인이다. 알려진 사진 음성 클래스만 픽셀 음성으로 쓴다.
기존 사진 정답과 픽셀 존재가 충돌하면 사진 정답을 그대로 두고 해당 픽셀 감독만 미확인으로 기록한다.
입력640의 8×8영역에 정답 픽셀이 있는지 나타낸 80×80 지도이며 정밀한 분할 정답/성능으로 주장하지 않는다.
전역 특징 분류와 위치 지도 상위32개 logit의 평균을 학습 가능한 항목별 비율로 섞어 사진 logit7개를 반환한다.
사진 focal + 픽셀 focal + 양성 Dice0.5, 사진 두 목표 강조2, 픽셀 양성 가중치 최대20,
자료 노출0.7/0.1/0.2, 상세 노출 계수0.25, seed47, batch8, 최대18epoch, patience5.
첫 epoch만 backbone을 고정하며 학습률 backbone0.00008/헤드0.0005, cosine최소0.000005를 사용한다.
선택은 세 검증 자료의 사진 항목별 미탐/오탐으로만 한다. 시험 사진과 픽셀 정답은 학습 신호로 넣지 않는다.
앞선 CODEBRIM 시도가 목표를 통과하면 이 시도를 학습하지 않고 요청한 추가 한 회(별도1epoch)만 수행한다.

## 두 방식의 사전 지정 결합 검증

위치 감독 모델도 통과하지 못하면 CODEBRIM 사진 모델과 위치 감독 모델의 전체 사진 확률을 1:1로 평균하는 한 가지 조합을 확인한다.
위치 감독 모델의 점수를 보기 전에 이 규칙을 지정한다. 가중치를 맞추거나 검증별 다른 모델을 선택하지 않는다.
두 모델의 가중치·원본 분리·검증 이미지 순서 SHA를 확인하고 세 검증 자료 모두에 공통인 항목별 임계값을 선택한다.
선택 규칙과 두 체크포인트를 고정한 검증 결과가 통과한 경우에만 별도의 시험 명령을 허용한다.
온라인 API에 결합을 자동 적용하지 않는다. 두 모델 결합 결과는 추가 학습 epoch로 세지 않는다.
