# v58 하부 금속 연결고리 정상 외관 분포 학습

## 자료와 범위

v57에서 전체 새 자료 27,620행의 바이트·프레임·픽셀 근접 연결을 확인했다. 기존 바이트 일치 8,990행의 검증된 특징 지문을 재사용하고 나머지 18,630개 파일을 새로 해독했다. 기존 모든 사진의 SHA를 다시 계산한 검사는 아니다. 서로 다른 연결 묶음 사이의 pHash 비교 153,938회와 연결 94건을 기록했으며 이를 모든 근접 사진 쌍의 수로 설명하지 않는다.

최초 정상 TRAIN 후보 143장 중 TEST와 연결된 2장을 제외했다. 고정된 분리는 정상 FIT 87장/84묶음, 내부 VAL 26장/25묶음, CAL 28장/24묶음이다. 원래 TEST는 정상 327장·부식 315장 그대로다. 원본 783개/8,312,632바이트만 변경 없이 내보냈다. 실제 부식 학습 정답은 0장이다.

분리 뒤 고정된 첫 정상 FIT 3장만 확인했다. 2장은 해상도가 작으며 인접 프레임에서 같은 조립체처럼 보인다. 프레임·pHash 묶음은 물리 부품의 독립성을 증명하지 않는다. 원래 라벨은 바꾸지 않았고 VAL/CAL/TEST 사진 내용을 골라 보지 않았다.

## 하나의 학습 가설

공통 인코더의 기존 3,072차원 통계 특징을 정상 FIT만으로 표준화하고 고정된 32차원 PCA 공간으로 투영한다. 이 공간에서 6개 affine coupling 블록의 분포 변환을 학습한다. 학습 파라미터는 새 분기의 43,968개뿐이다. 기본 v16과 승인된 상부 연결고리 부식·유리 애자 캡 누락·현수 연결구 부식 분기의 모든 가중치, 버퍼, 메타데이터를 보존한다.

음의 로그 밀도는 `0.5 * sum(z² + log(2π)) - sum(log_scale)`이다. 이 값은 PCA 공간의 외관 이상 점수이며 전체 RGB 밀도나 고장 확률이 아니다. 정상 복원을 사용했던 이전 후보를 다시 실행하는 실험도 아니다.

[Real NVP 원논문](https://arxiv.org/abs/1605.08803)의 가역 변환·Jacobian 식과 [DifferNet 원논문](https://openaccess.thecvf.com/content/WACV2021/html/Rudolph_Same_Same_but_DifferNet_Semi-Supervised_Defect_Detection_With_Normalizing_Flows_WACV_2021_paper.html)의 특징 분포 접근을 참고했다. 논문의 구조나 성능을 재현한 것으로 주장하지 않는다.

## 사전 고정 조건

- 입력: 원본 RGB를 bicubic 256×256으로 변환, ImageNet 정규화. 증강·별도 인코더·날짜/자료 출처 입력 없음.
- 정규화/PCA: 정상 FIT 87장만 사용. 평균·모표준편차 하한 0.001, 표준화 후 [-8,8] 제한. CPU float64 SVD의 첫 32축, 최대 절댓값 원소의 부호 고정, FP32 저장. 저장된 투영의 FIT 잠재값 평균·모표준편차 고정.
- 학습: 고정된 묶음 균형 복원 추출, 배치 32, 30 epoch×64=1,920 optimizer 업데이트. AdamW 0.0003, cosine 최소 0.000001, weight decay 0.01, gradient clip 5, seed 5858.
- 선택: 정상 VAL의 묶음별 평균 NLL을 매 epoch와 초기 epoch 0에서 비교해 최초 엄격 최소값 선택. 초기 모델이 선택되면 CAL/TEST 점수를 새로 계산하지 않고 제외한다.
- 점수: 선택 모델의 FIT NLL 평균·모표준편차로 고정 sigmoid 변환. 확률 보정이라고 설명하지 않는다.
- 보정: 정상 CAL 28장의 85% 순서 통계량, 순위 25. 임계값 저장 후에만 TEST 특징과 점수를 계산한다.
- 채택: 학습 epoch>0, TEST 각 라벨 20장 이상·연결 묶음 3개 이상, 사진 오탐과 미탐 각각 20% 이하. 통과 시에만 새 패키지 CPU/GPU·C++·기존 모든 alias/위치 PNG 보존 검사를 진행한다.

상세 JSON과 코드 SHA를 commit/push한 뒤 새 특징·PCA·gradient·optimizer를 실행한다. TEST에 맞춘 임계값 변경이나 조건 완화, 여러 구조 비교는 하지 않는다.

## 해석과 보존

정상 VAL만으로 모델을 선택하므로 부식 검출력이 개선된다는 보장은 없다. 기존 브래킷·튜브 성능 개선과도 별도 과제다. 위치 정답이 없어 새 출력을 검증된 손상 위치로 사용하지 않는다. 공개 출처 반복 개발 결과이며 독립 현장 성능이 아니다.
