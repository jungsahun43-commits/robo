## 새 실제 라벨 자료

[원저자 자기 타일 데이터](https://github.com/abin24/Magnetic-tile-defect-datasets.)의 리비전 `cc4eb530b57b9cb7225bf76023873043ffd50655`에서 원본1,344장과 위치 마스크를 받았다. 모든 파일의 Git blob 체크섬을 대조했다. [동일 저자의 자료 모음](https://github.com/abin24/Surface-Inspection-defect-detection-dataset)은 이 자료를 직접 연결하며 학술 연구만 허용·상업 이용 금지·해당 논문 인용을 명시한다. 표준 SPDX 라이선스를 임의로 붙이지 않는다.

인용: Huang, Y., Qiu, C. and Yuan, K., *Surface defect saliency of magnetic tile*, The Visual Computer, DOI10.1007/s00371-018-1588-5.

## 실제 학습

현재 v13의 KSDD 마스크 분기를 새 분기에 복사하고, 새 자기 타일의 정상499장·실제 결함217장으로 **30epoch×64step=실제 optimizer1,920회** 학습했다. 기존 분석부와 모든 기존 분기를 고정했다. 같은 모델 파일·같은 공통 분석부를 사용한다.

VAL의 정상·각 결함 유형별 loss를 같은 비중으로 평균해 epoch를 선택했다. 선택은 **1epoch·64회 가중치**였다. 이후 학습 loss는 줄었지만 검증 loss가 크게 늘어 과적합 징후가 나타났다. 실제 완료1,920회와 최종 보관 가중치64회를 구분한다. 최종 epoch30 가중치가 더 좋다고 설명하지 않는다.

새 자료는 라벨이 있는 CAL로 사진 오탐·미탐 중 큰 값을 최소화하도록 기준을 정했고, TEST 전 저장했다. 기존 브래킷·튜브는 정상 CAL만 사용해 새 점수 단독과 기존 점수의 max 결합을 고정했다. TEST를 보고 기준을 반복 조정하지 않았다.

브래킷 결합은 미탐19.15%p 감소·오탐3.12%p 증가다. 고정 조건인 오탐20% 이하·오탐 증가5%p 이하·미탐5%p 이상 개선과 손상별 악화 제한을 충족했다. 구멍 미탐5/12, 흠집25/35로 여전히 부족하다. **사진 오탐·미탐 모두20% 이하인 완료 상태가 아니며 기존 추가설비12유형 중8개라는 수는 같다.**

새 자기 타일 원본 좌표의 위치 성능은 IoU13.21%·pixel 미탐83.93%·pixel 오탐0.77%로 좋지 않았다. 이 새 지도를 브래킷의 기본 위치 출력으로 교체하지 않는다. 브래킷의 기존 위치 지도·pixel 기준, KSDD·볼스크루·전선 연결부와 나머지 설비 분기는 보존한다. 새 분기는 브래킷의 사진 후보 판정에만 사용한다.

## 검증과 다음 단계

학습 journal1,920개와 기존 가중치·버퍼·운영 기준의 완전 일치를 확인했다. 기존 Python575개 SHA, 보호 파일85,455개의 크기·mtime을 검사했다. 전체 보호 파일의 SHA 재검사를 반복한 것은 아니다. 새 단위 검사3개를 통과했다. CPU/GPU와 실제 C++ 검사는 별도 릴리스 기록을 따른다.

브래킷 결과는 이미 사용한 공개 TEST에서 선택한 연구 비교다. 산업현장 전체 오차율이나 설비 내부 고장 판정으로 일반화하지 않는다. 새 자기 타일 마스크는 추가 학습 자료로 확보됐지만 그 유형 자체의 성능은 아직 기준 미달이다.

다음 학습은 TEST 기준 재조정 대신 FIT/VAL의 과적합 원인을 확인하고, 작은 학습률·기존 분기 정규화·별도 실제 TRAIN 마스크 자료 혼합을 먼저 사전 등록하는 방향이다. 미검수 전선 관계 주석은 계속 정답에서 제외한다.
