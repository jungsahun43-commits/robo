# v42 MSDD 원본 주석 감사 — 위치 학습 전 제외

## 전체 9.78GB를 받지 않고 확인한 범위

원저자 공개 페이지가 사용하는 읽기 전용 파일 목록과 미리보기 API를 정적으로 확인했다. 배포 원본은 `MSDD.rar` 9,785,811,363바이트이고 저자 배포 MD5는 `26607e725c30f926945061e1bd442efa`다. **전체 RAR은 받지 않았으므로 이 전체 MD5를 검증했다고 주장하지 않는다.**

공개 다운로드는 정확한 HTTP 206 범위를 지원했다. [RARLab 공식 구조](https://www.rarlab.com/technote.htm)에 따라 원본 헤더의 CRC와 non-solid 상태를 검사하고, 헤더가 실제로 가리킨 Quick Open 색인 12,573,991바이트를 읽었다. 색인 내 142,672개 캐시 헤더의 CRC를 검사했다. 이 색인은 모든 작은 파일의 헤더를 담고 있지 않으므로 전체 원본 목록으로 설명하지 않는다.

공개 압축 미리보기 JSON은 파일 157,061개를 보여 줬지만 **원래 `ImageSets/test.txt`와 첫 XML/JPEG/원본 조명 파일 등을 누락**했다. 목록만 믿고 새 TEST를 만들지 않았다. 원본 헤더와 직접 비교해 TRAIN/TEST 두 목록을 복구했고, 각 원본 헤더 일치·압축 해제 크기·payload CRC32를 검사했다. 최초 public API의 인덱스 형식 오류, 잘못된 루트의 빈 응답, 16MB에서 중단한 미리보기와 strict XML 감사 실패도 보존했다. 어떤 모델 학습에도 사용하지 않았다.

## 원래 분리와 주석 무결성

- 원저자 TRAIN 6,289개와 TEST 2,950개의 ID가 서로 겹치지 않는다.
- 9,239개 ID 모두 XML과 혼합색 JPEG의 이름 대응을 확인했다. 여러 조명·카메라·크롭을 새 독립 부품으로 세지 않는다.
- TEST의 촬영 시각 proxy 482개 중 TRAIN과 327개가 겹친다. 같은 촬영의 TRAIN 1,443개를 제외하고 남은 4,846개/1,029촬영 proxy만 미배정 후보로 남겼다. 실제 물리 부품 독립성은 미확인이다.
- 사진을 추출·해독·시각 열람하기 전에 원래 TEST와 모든 대응 조명 변형을 예약했다. FIT/VAL/CAL과 학습 조건은 확정하지 않았다.
- 원본 RAR의 앞부분 2,914,869바이트에 있는 XML 9,239개의 헤더 CRC를 검사했다. 원본 헤더·압축 payload를 그대로 넣은 작은 non-solid RAR에서 Windows bsdtar 3.8.9로 XML만 풀었고, 전부 원본 크기와 CRC32에 맞았다. 원저자 코드를 실행하지 않았다.

| 원저자 사진 라벨 | 정상(상자 없음) | 이상(상자 있음) |
|---|---:|---:|
| TEST와 촬영이 겹치지 않는 TRAIN 후보 | 2,668 | 2,178 |
| 같은 촬영으로 제외한 TRAIN | 829 | 614 |
| 보존 TEST | 2,250 | 700 |

이 라벨은 한 표면 크롭의 저자 주석 존재 여부다. 부품 전체 작동 정상·고장이나 신뢰할 수 있는 손상 위치를 입증하지 않는다.

## 확인된 원본 오류

주석 상자 **4,208개 모두 `xmax == ymax`**다. 이 중 좌표 범위 조건을 위반하는 상자가 2,273개, 해당 사진이 2,031개다. TRAIN 후보에서 1,263장, 같은 촬영 제외 TRAIN에서 356장, 보존 TEST에서 412장이다. 원본 XML의 선언 크기도 350~640 등의 여러 값이므로 실제 영상과의 좌표 대응을 검증했다고 말하지 않는다.

좌표상 범위를 통과하는 TRAIN 이상 915장도, 전체 상자에서 같은 값이 반복되는 문제 때문에 **위치가 올바르다고 승인하지 않는다**. 절댓값·좌표 교환·복사 값 추정으로 자동 수정하지 않았고, 잘못된 상자를 정상으로 바꾸거나 TEST에서 빼지 않았다.

원저자 [이슈 2](https://github.com/Destinyia/Metal-Surface-Defect-Detection/issues/2)에도 같은 값 반복 문제가 보고되어 있다. 확인 시 공개 상태는 open/댓글 0이었다. [이슈 1](https://github.com/Destinyia/Metal-Surface-Defect-Detection/issues/1)은 좌표/크기 문제도 보고하지만 그 글의 수정 코드를 실행하거나 적용하지 않았다. 확인한 원저자 revision은 `c9aa21a8c4fce196152be4f0a734b3d17f8354bd`이며, 확인한 자료에서 검증 가능한 수정본을 확보하지 못했다. 문의·댓글은 보내지 않았다.

## 결정과 재개 조건

**MSDD 위치 학습은 0회에서 보류한다.** 작은 범위 접근과 원본 주석 무결성 확인은 성공했지만, 정확한 위치 정답을 확보하지 못했다. 원저자 수정본 또는 독립 검수된 원래 위치 정답이 없으면 이 XML을 실제 결함 위치 정답으로 학습하지 않는다. 사진을 추가로 받거나 이 자료로 임의 분류 실험을 돌려 이번 문제를 우회하지 않는다.

원본·색인·기존 실패 후보·현재 v16-r1은 보존한다. 이번 GPU 특징/모델 점수/optimizer/새 API·C++·ZIP 검사는 모두 0이다. 데이터 이용조건은 공식 DataCite의 CC BY 4.0이며 논문/코드 조건과 구별한다. 원자료 출처는 DOI `10.57760/sciencedb.10794`, 논문 DOI `10.1038/s41597-025-04454-6`다.

핵심 기록: 주석 메타데이터 SHA256 `bc463bdc8957ae9aa37fd6e16cb4c5da62b0a6b64e76f436e38d3e4eaea9b12d`, 원래 분리 예약 SHA256 `c1cde15ad3017ad24bba91186f19ad9d346c4947a8f3f8da0f5ba9fd0956ab0e`, 주석 원본 prefix SHA256 `940b5239967c3ede551aeddafa3916d15749e05e94c889530a93a8e47afa590e`다. 모두 로컬 수신 무결성 값이며 전체 배포 MD5의 대체 검증이 아니다.
