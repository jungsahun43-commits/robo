# head 초기 학습률 후속 비교 계획

## 이번에 확인할 질문

원본 BN 통계를 유지한 직전 후보는 노출 철근 AP를 0.7075로 회복했지만 균열·박락의 자료별 최대 미탐/오탐은 22.41%였다. 공동(cavity) AP 하락은 0.020277로 기존 허용값 0.02를 넘었다. 과거 체크포인트 상태 감사에서 non-backbone head의 변화량이 backbone보다 컸다는 관측을 근거로, 초기 head 학습률을 낮추면 기존 항목을 보존하면서 주요 오류를 줄이는지 확인한다. 상태 변화량은 원인 증명이나 개선 보장이 아니다.

## 학습 전에 고정하는 조건

| 조건 | 재사용 대조군 | 신규 후보 |
|---|---|---|
| 실행 이름 | facility-presence-target-batchnorm-frozen | facility-presence-target-head-lr-low |
| 초기 체크포인트 | 원본 0773 모델 | 같은 원본 0773 모델에서 새로 시작 |
| non-backbone 그룹 초기 LR | 0.00025 | 0.0001 |
| backbone 초기 LR | 0.00004 | 같음 |
| 일정 | CosineAnnealingLR, T_max=6, eta_min=0.000005 | 같음 |
| 학생 BN | 원본 통계로 정규화, affine 학습 | 같음 |
| 보존 손실 | 알려진 다른 5항목, 교사 고정, 가중치4·T2 | 같음 |
| 추가 학습 | 기존 완료6epoch를 재사용 | 신규6epoch |

head는 backbone을 제외한 모든 기존 매개변수 그룹이다. 균열·박락 전용 출력층만을 뜻하지 않는다. 최저 학습률은 고정되어 있으므로 전체 LR 곡선이 정확히 0.4배인 실험으로 표현하지 않는다. 각 epoch에서 실제 optimizer LR과 scheduler 진행을 기록한다.

기존 640 입력·7항목·19종 보조 태그·80×80 위치 지도, seed56, batch8, epoch당14,248 draw, 원본 control 추출 배열, 출처별 비중, 손실·원래 정답·미확인 mask·교사 추론을 유지한다. 신규 사진, 새로운 정답, 출력 항목, 모델 매개변수는 추가하지 않는다. 이전 86개 실행 소스와 완료 실행의 원본 파일을 보존하고, 새 코드·프로토콜을 고정한 뒤 학습한다.

## 검증 순서와 판단

1. 고정 프로토콜·소스·Git 바이트 및 집중 테스트를 확인한다.
2. 원래 TRAIN 8개 위치에서 폐기할 GPU 업데이트1회를 실행해 LR·BN·교사·출력·CPU 재로드 계약을 확인한다. 이 업데이트는 본 학습에 이어 붙이지 않는다.
3. 동일 원본 초기 모델에서 신규 후보6epoch를 학습한다. 대조군을 다시 학습하거나 중복 합산하지 않는다.
4. 기존 세 출처의 전체 사진 VAL, grid1에서 점수·임계값을 선택하고 작은 DACL 손상과 알려진 나머지 항목 AP를 확인한다.
5. 실제 입력 파일 SHA·크기·수정 시각, 추출 순서, 교사 및 BN 버퍼, 학습률, 체크포인트와 기존 실행의 보존을 검증한다.
6. 원본 모델과 재사용 대조군 모두에 대한 결과를 보고한다. 이전 유지·연구·엄격한5% 기준을 변경하지 않는다.

다른5항목의 알려진 출처별 AP 하락 허용값0.02, 대조군 대비 노출 철근 AP 회복0.02, 주요 오류 회귀2%p 조건을 그대로 유지한다. 직전 대조군의 철근 AP가 이미 원본보다 높으므로 회복 조건은 이번에도 엄격하다. 연구 후보의 최대 오류0.5%p 개선·작은 손상 FN 최소2건 개선 등 원래 기준과 모든 자료별 균열·박락 FNR/FPR가 각각5% 미만이어야 하는 목표를 별도로 보고한다.

## 결과 해석 범위

이 실험은 이전 결과를 보고 선택한 추가 탐색이다. 같은 VAL을 반복 사용하므로 독립 시험·현장 성능으로 표현할 수 없다. DACL·Dam·CODEBRIM은 주로 교량·댐 콘크리트 자료이며 공장 시설 전체를 대표하지 않는다. 미확인 라벨과 교사 예측을 정답으로 바꾸지 않는다. 새 후보는 기준과 검증을 통과하기 전 앱 기본 모델로 교체하지 않는다.
