# 시설 사진 정답 경계의 전문가 검수 준비

## 준비한 범위

**최근 0773 모델의 TRAIN 130사례 검수 준비가 완료됐다. 전문가 정답 확정·원본 라벨 수정·학습 적용은 0건이다.** 이전 140사례의 검수 순서와 AI 관찰 기록도 보존했다. 아래 기존 기록과 뒤의 최신 완료 기록을 구분해 사용한다. 사진과 출판자 주석을 연결한 로컬 화면을 사용하며, 이번 준비·집계 검증에서는 사진을 새로 육안 판정하지 않았다. 공개 문서에는 출처·태그·검수 이유별 집계와 파일 SHA만 기록한다.

이 140사례는 이전 auxiliary 모델 `71ea5d75011e4662954c18e7cb0af88d6558266eef3c6fde7a5f00003c503323`로 만든 묶음이다. 최근 비교 실험의 초기 모델 `0773b64f85bde27c256580be2fe36fabc0956c8b0bc3c087fc49716ba61d6c6a`와 다르다. **현재 0773 모델의 TRAIN 오답 검수가 완료됐다는 기록으로 사용하지 않는다.**

| 출처 | 기존 목록 | 기존 AI 시각 관찰 기록 | 그 23장 기록에 미포함 |
|---|---:|---:|---:|
| DACL | 59 | 8 | 51 |
| DamSegment | 21 | 7 | 14 |
| CODEBRIM | 60 | 8 | 52 |
| 합계 | 140 | 23 | 117 |

실제 저장된 브라우저 의견 JSON도 140행이며, 사유·메모가 입력된 행은 0개다. AI 관찰 23장 기록은 이 의견 JSON과 별개다. **AI 관찰에 미포함인 117장과 전문가 검수가 남은 범위를 혼동하지 않는다.** 이 준비 묶음에서 전문가 확정으로 인정한 사례는 140장 중 0장이다.

기존 목록은 원래 TRAIN의 균열·박락 FN/FP/TP/TN 집단에서 강한 오답과 고정 난수 사례를 고른 것이다. 사진 단위 중복을 제거했지만 한 사진이 여러 항목의 선택 사유를 가질 수 있다. 대표 표본·독립 현장·오류율 측정으로 해석하지 않는다. CODEBRIM에는 출판자 patch가 포함되며 모두 독립된 현장 전체 사진이라는 뜻은 아니다.

## 전문가가 보는 순서

순서는 기존 140사례 안에서만 정했다. 기존 AI 질문과 native 태그는 검수할 대상을 찾는 단서이며, 오류 원인이나 잘못된 원본 정답을 확정한 증거가 아니다. 우선순위 안에서는 기존 AI 관찰 기록이 없는 사례부터 출처·고정 사례 번호 순으로 배치한다.

| 순서 | 대상 조건 | 사진 수 | 기존 AI 관찰 기록에 미포함 | 확인할 내용 |
|---|---|---:|---:|---|
| P0 | 기존 AI가 원본 손상명·주석 기준에 질문을 남긴 사례 | 3 | 0 | 균열/박락/철근 노출/Hollowareas 등의 정의와 기록 범위. 사진만으로 판단 불가하면 그대로 미확인 의견 |
| P1 | 기존 선택 사유에 FP/FN이 있고 다른 native 태그 맥락, 철근 양성·박락 음성 또는 위치 주석 없는 사진 분류 조건이 있는 사례 | 43 | 42 | 다른 손상·부품·표면 맥락과 목표 손상의 구분. 동반 태그만으로 목표 라벨을 추가하지 않음 |
| P2 | 나머지 기존 FP/FN 또는 AI의 작은 손상·질감·촬영 정보 질문 | 58 | 51 | 실제 손상이 작거나 경계에 있는지, 사진 정보가 부족한지, 모델 오류인지 각각 기록 |
| P3 | 나머지 기존 정답 일치 비교 사례 | 36 | 24 | 비슷한 질감·그림자·부품이 있어도 해당 항목이 음성/양성인 비교 기준 확인 |

먼저 P0의 3사례로 정의 질문을 정리하고 P1의 43사례를 본다. P2를 검수할 때에도 P3의 비교 사례를 함께 확인해 오답만 보고 정의를 넓히는 일을 피한다. P3에서 선택된 항목이 맞았다는 것은 그 사진의 다른 모든 항목이나 시설 안전성이 맞다는 뜻이 아니다.

DACL의 native 19종에는 별도 `paint`·`plaster` 정답이 없다. Graffiti를 일반 도장, Hollowareas를 미장, Weathering을 정상 콘크리트로 바꾸지 않는다. 철근이 보인다는 이유로 박락을 추가하거나, 가는 선이 보인다는 이유로 균열 음성을 양성으로 교정하지 않는다. 내부 `concrete_crack` 키도 사진의 모든 재질이 확인됐다는 뜻은 아니다.

기존 140사례의 주석 종류는 DACL polygon 59, CODEBRIM 사진 XML 태그 60, Dam native mask 15, Dam 사진 분류만 있는 사례 6이다. 사진 태그·분류만 있는 자료에서 위치 mask를 만들어 넣지 않는다. Dam Non-Crack 음성은 저자 원논문 4.4의 intact 정의에 근거한 변환이며 별도 Spalling=0 native mask가 있다는 뜻은 아니다. 범위와 공식 근거는 [기존 라벨 범위 문서](FACILITY_LABEL_SCOPE_KO.md)를 따른다.

기존 AI 23장 관찰의 주 가설은 정의 질문 3, 작은/가장자리 손상 3, 비슷한 질감·다른 손상 2, 패치/촬영 정보 한계 2, 정보 부족 1, 선택 항목의 정답 일치 비교 12다. 이는 AI의 관찰·가설이며 전문가 판정 수가 아니다. [기존 시각 관찰 기록](FACILITY_TRAIN_VISUAL_REVIEW_KO.md)을 전문가 정답으로 승격하지 않는다.

## 기존 로컬 화면으로 검수하는 방법

로컬 `runs/facility-context-review/index.html`은 우선순위 링크 목록이다. 링크를 누르면 기존 검수 화면의 같은 사례로 이동한다. 기존 화면·원본 사진·주석·의견 JSON은 수정하지 않았다. `REVIEW-PRIORITY.json`에는 기존 사례 번호와 순서·이유만 두며 사진·주석을 복제하지 않는다. 이 로컬 파일들은 Git/공개 배포에서 제외된다.

1. 목표 항목과 출판자 정의를 먼저 읽고, 사진 전체와 원본 위치 주석이 있는 부위를 확인한다. 모델 확률을 정답의 근거로 사용하지 않는다.
2. **보이는 사실 / 출판자 정의 질문 / 추가로 필요한 정보**를 구분해 메모한다. 사진에서 깊이·재질·경계를 확정할 수 없으면 추가 현장 확인이나 다른 각도 자료가 필요하다고 기록한다.
3. 원본 기준 질문은 화면의 `정답 기준 불명확 / 추가 검토` 사유로 남긴다. 메모에 검수한 항목, 확인 가능/불명확, 근거, 검수자의 관련 전문 범위, 날짜를 적는다. 원본 targets를 직접 바꾸지 않는다.
4. `검수 의견 JSON 저장`으로 별도 의견 파일을 저장한다. 기존 빈 의견·AI 관찰 파일을 덮어쓰지 않고 로컬에서 보관한다. 이 기능은 의견 저장이며 학습 적용 기능이 아니다.
5. 전문가가 확보되지 않거나 의견이 충돌하면 `미확정`을 유지한다. 향후 전문가 승인 의견이 확보되면 원본과 분리한 새 TRAIN 버전·근거·해시·클래스별 변경 제안을 별도로 검토한다. 현재 작업에서 정답, threshold, sampler, 모델을 변경하지 않는다.

`targets=-1`은 미확인이고 0은 해당 항목에 근거 있는 음성이다. 두 항목 모두 0인 자료를 일반 정상·안전으로 간주하지 않는다. [TRAIN 음성·unknown 감사](facility-target-negative-data-audit.json)와 라벨 범위를 함께 확인한다. 검수 대기 사진을 정답으로 세어 5% 목표를 맞추거나, 어려운 VAL/TEST 사례를 제외하지 않는다.

## 최근 0773 모델의 130사례: 실제 준비 완료

학습 작업을 마친 뒤 0773 고정 모델로 원본 TRAIN base 14,248행을 실제 추론했다. `score_facility_train.py`의 캐시와 `build_facility_train_review.py`의 새 묶음을 별도로 저장했으며 기존 140/23 기록과 원본 targets는 유지했다. 준비된 자료는 **130장**이다. 추론·묶음 생성은 완료했지만 전문가 검수는 완료하지 않았다. 이 문서의 집계 검증 자체는 모델 추론을 추가로 실행하지 않았다.

| 출처 | 최신 선택 사진 | 제공된 주석 | 이 준비에서 새 AI 육안 판정 | 전문가 확정 |
|---|---:|---|---:|---:|
| DACL | 53 | 원본 polygon·19종 태그 | 0 | 0 |
| DamSegment | 17 | native mask 11 + 사진 분류만 6 | 0 | 0 |
| CODEBRIM | 60 | 사진 XML 태그 | 0 | 0 |
| 합계 | 130 | 사진 태그와 위치 주석의 범위를 구분 | 0 | 0 |

기존 고정 grid1 threshold를 재사용했고 threshold를 새로 맞추지 않았다. seed 49, 항목·출처별 FP/FN 최대 12개와 TP/TN 최대 3개 조건으로 선택을 다시 계산했으며 실제 묶음과 일치한다. 사진 수를 기존 140장에 맞춰 강제하지 않았다.

| 선택 사유·항목 집계 | 균열 | 박락 |
|---|---:|---:|
| FN | 18 | 24 |
| FP | 27 | 25 |
| TP 비교 | 9 | 9 |

이는 학습에 이미 사용된 사진의 검수 선택 이유다. 검증·시험·현장 오류율이나 전문가가 확인한 오답 수가 아니다. 이번 묶음의 모든 `proposed_review` 130행은 `unreviewed`이고 메모가 비어 있다. 새 화면에서 사람이 의견을 저장한 JSON을 확인했다는 뜻은 아니다.

기존 140목록과 같은 사진은 32장, 기존 AI 관찰 23장과 같은 사진은 8장이다. 이를 새 모델의 AI 오류 검수 완료 수로 세지 않는다. 기존 AI 의견을 새 모델 출력에 자동 적용하지 않았다. 사례 번호는 묶음 안의 번호이므로 의견을 연결할 때 모델 SHA와 `source_package_sha256`를 함께 확인해야 한다.

최근 모델을 검수할 때는 로컬 `runs/facility-train-review-roi-0773/index.html`을 연다. 이전 140장의 우선순위 화면은 이전 묶음에 대한 정의 질문·비교 참고로 유지한다. 새 의견은 최신 묶음의 화면에서 별도 저장하고, 이전 빈 의견 파일과 구분해 보관한다.

### 최신 묶음에서 확인한 근거

- 캐시 14,248행의 순서·7종 targets가 고정 core TRAIN full/base와 완전히 일치하고 모든 확률이 유한한 7차원 값이다. 파생 crop을 새 검수 사진에 넣지 않았다.
- 130개 고유 사진 모두 허용된 TRAIN 멤버다. 원본 targets·출처·고정 모델·split·scorer/builder 코드 SHA·캐시·threshold provenance와 package content SHA를 대조했다.
- DACL 53개 원본 polygon·19종 태그·파생 사진 태그를 확인했다. Dam native mask 11개의 실제 빨강 균열/파랑 박락 색상과 사진 정답·크기를 대조했다. 사진 분류만 있는 6개는 저자 intact 정의의 두 항목 음성이며 native 위치 mask로 표시하지 않았다.
- CODEBRIM 60개는 저장된 native TRAIN 태그의 5종 known/2종 unknown 매핑과 원본 XML 파일 SHA를 확인했다. shared XML 전체 태그를 이 감사에서 새로 파싱한 것은 아니다.
- 선택 사진 130개의 모델 입력·출판자 원본 파일 SHA를 대조했다. HTML 사례 anchor 130개와 로컬 상대 참조 448개가 실제 파일에 연결되며 삽입된 사진 payload는 없다. 새 브라우저 렌더링·의견 내보내기를 실제로 클릭해 확인한 기록은 아니다.
- 원래 라벨·기존 묶음·기존 AI 관찰·고정 코드·모델 파일을 변경하지 않았다. [최신 묶음의 공개 집계 감사](facility-roi-0773-train-review-verification.json)에 사진별 경로·ID·주석을 복사하지 않았다.

현재 두 도구의 멤버십 helper는 heldout JSON의 split/group 정보도 대조한다. 같은 JSON 안에 클래스 요약이 함께 있으므로 `VAL/TEST JSON을 전혀 로드하지 않는다`고 표현하지 않는다. 이는 TRAIN과 holdout의 멤버십 겹침을 막는 metadata 검사이며 heldout 정답·예측을 표본 선별이나 모델 선택에 사용하는 단계가 아니다. 이번 독립 집계는 이 helper를 실행하지 않았으며 TRAIN manifest·TRAIN auxiliary·기존 TRAIN 검수 subset만 대조했다. Native VAL/TEST 사진·주석·정답·예측 cache를 열어 사례를 고르지 않았다.

기존 공개 오류 진단의 확인 대기 정책은 별도 validation 분석이다. 그 조건부 오류율은 전체 사진 FNR/FPR과 다르며, 해당 진단의 개별 VAL/TEST 결과를 이 TRAIN 검수 표본 선별에 사용하지 않았다. 반복 학습이나 구조 변경의 결과도 전문가 라벨 검증을 대신하지 못한다.

## 데이터 이용과 해석

기존 출판자의 이용·재배포 조건을 유지한다. 특히 CODEBRIM은 비상업 연구·교육 및 원본·변형 데이터 재배포 제한을 따른다. 사진·가공 사진·개별 경로·원본 주석·개별 관찰 내용은 공개 문서나 GitHub에 복사하지 않는다. 출판자 조건은 기존 라벨 범위 문서의 공식 출처와 로컬 라이선스 기록을 따른다.

교량·댐 자료는 공통 시각 손상 특징의 학습 자료이며 공장 벽·바닥·기둥의 현장 정확도나 구조적 안전을 검증한 자료가 아니다. 이번 결과는 전문가가 검수할 준비와 자료 일관성 확인이다. 성능 향상·5% 미만 오차·전문가 확정을 주장하지 않는다.
