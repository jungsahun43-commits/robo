# 다음 보강: FIT/VAL 과적합을 줄이는 실제 마스크 혼합 학습

2026-10-15. v17 **준비 메모**이며 새 학습이 완료됐다는 보고나 확정 프로토콜이 아니다.

v16은 학습 loss가 줄어도 VAL loss가 커져1epoch가 선택됐다. 이 FIT/VAL 관찰을 근거로 다음 후보는 작은 학습률과 실제 마스크 자료 혼합으로 설계한다. 이미 본 TEST의 임계값을 반복 바꾸는 실험으로 진행하지 않는다.

1. 현재 통과한 v16-r1 ZIP·CPU/GPU·C++ 검증과 Git 반영을 먼저 마친다. 초기 함수 이름 충돌은 보존된 기존 `forward_surface` 서명을 되살리고 새 분기를 `forward_real_mask`로 연결해 복구했다. 다음 구현도 기존 함수 이름·서명을 덮어쓰지 않는다.
2. 새 자기 타일 FIT217결함/499정상에 기존 KSDD2의 실제 FIT 마스크 후보를 혼합한다. KSDD의 CAL·TEST를 FIT로 옮기지 않는다. `industrial-real-mask-v17-cross-source-audit.json`에서 새 자기 타일 TEST와 KSDD FIT/VAL의 정확 RGB·회전/반전 근접을 먼저 확인하고 근접 그룹은 제외한다.
3. 초기 가설은 작은 학습률1e-4, 고수준 투영의 고정 또는 초기 가중치 정규화, 두 출처의 손실 균형이다. 양성·정상·손상 종류 샘플링, 학습 단계 수와 VAL 선택 규칙을 코드·프로토콜로 먼저 확정하고 commit한 뒤 실행한다. 이 메모만으로 임의의 여러 조합을 실행하지 않는다.
4. 각 자료의 기존 입력 좌표·마스크를 보존한다. KSDD의 이미 검증한256×704 특징 캐시를 사용할 때는 새 프로토콜에 원래 체크섬·FP16 경계·valid mask와 목표 크기를 명시하고 재학습 완료 회차로 중복 계산하지 않는다.
5. 기존 v16을 포함한 모든 채택 분기는 보존하고 새 후보의 실제 optimizer 횟수를 따로 기록한다. 기존 TEST 또는 근접 사진은 혼합 학습에서도 제외한다. 새 후보의 VAL 선택·CAL 보정을 끝낸 후 한 번 고정 TEST 평가하고, 실패·성능 회귀는 보존해 제외한다.

자기 타일 유형의 자체 사진 성능과 브래킷·튜브 전이 성능을 구분한다. 새 데이터 자체 성능이 좋다는 이유로 타 설비 성능을 추정하지 않는다. 전선 관계 라벨 검수는 계속 별개로 필요하며, 자동 제안이나 QA 시뮬레이션은 정답으로 사용하지 않는다.
