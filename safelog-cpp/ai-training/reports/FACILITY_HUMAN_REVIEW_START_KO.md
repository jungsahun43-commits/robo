# 사람 검수 200장으로 재학습 준비

2026-10-09. 사용자가 사진별 균열·박락을 직접 입력하는 방식으로 진행하도록 요청했고, 첫 묶음은200장으로 선택했다.

## 지금 사용하기

1. [이 PC의 검수 화면](http://127.0.0.1:8770/)을 연다.
2. 검수자 표시명을 적고 각 사진의 균열·박락에 **있음 / 없음 / 판단 불가**를 선택한다.
3. **다음**으로 이동한다. 메모는 선택 사항이며 입력은 이 PC에 자동 저장된다.
4. 검수 후 **검수 결과 제출**을 누른다. 대화창에 **검수 제출했어, 학습해줘**라고 알려준다.

사진의 실제 크기는 **크게 보기**로 확인할 수 있다. AI 제안·원래 정답은 기본적으로 접어 두어 먼저 사진을 관찰하도록 했다. 애매한 상태를 억지로 정상이나 손상으로 선택하지 않는다.

현재 준비 단계의 실제 사람 판단은0개이고 새 모델 학습은0epoch다. 코드 테스트와 별도 UI 테스트 선택은 사람 정답으로 계산하지 않는다. 실제 입력이 있어야 해당 방식의 학습을 시작할 수 있다.

## 200장 구성과 선택 근거

완료된 저학습률 대조군의 고정된 모델과 기존 VAL 임계값으로 원본 전체 TRAIN14,248개만 새로 추론했다. 검증·시험 사진을 오류 선별용으로 추론하거나 가져오지 않았다.

| 출처 | 오류 의심 | 정답 일치 비교 | 합계 |
|---|---:|---:|---:|
| DACL | 92 | 28 | 120 |
| DamSegment | 4 | 36 | 40 |
| CODEBRIM | 24 | 16 | 40 |
| 합계 | 120 | 80 | 200 |

오류 의심은 원래 배포자 정답과 모델 판단이 다르다는 뜻이다. 사람 검수로 확정된 오류가 아니다. 해당 Dam 학습 자료에는 오류 후보가4개만 있어 이를 모두 사용하고 비교 사례를36개 선택했다. 빈 자리를 검증·시험 사진으로 채우지 않았다.

오류 의심 집단의 절반은 큰 차이를 보이는 사례, 나머지는 고정 난수로 선택한다. 비교 집단은 고정 난수로 선택한다. 같은 사진은 중복하지 않았고 출처에 부모 그룹ID가 있는 경우 같은 부모도 중복 선택하지 않았다. 현장 독립성이나 전체 오류율을 입증하는 표본은 아니다.

## 입력을 학습에 연결하는 방식

- **있음 / 없음**: 해당 전체 학습 사진의 균열·박락 태그로 별도 저장한다.
- **판단 불가**: 해당 사진·항목은 미확인으로 처리한다.
- **검수 전**: 기존 정답을 유지하며 사람이 검수했다고 계산하지 않는다.
- 원래 태그와 다른 판단 또는 불확실한 판단은 해당 원본 위치 정답과 관련 보조 태그 감독을 비활성화한다. 기존 주석을 새 정답처럼 계속 학습하는 충돌을 방지한다.
- 그 부모에서 만든 부분 사진의 영향받는 항목도 미확인으로 처리한다. 전체 사진에 손상이 보인다는 판단을 모든 부분 사진의 양성으로 복사하지 않는다.
- 실제 사람이 명확히 판단한 전체 사진은 epoch당 최대2회의 추가 추출 대상으로 사용할 수 있도록 구현했다. 같은 출처·전체 사진 위치의 기존 추출 슬롯만 바꾸고 부분 사진 슬롯을 유지한다. 정답 검수와 추출 보강을 함께 적용하는 실험이므로 각 요소만의 효과로 해석하지 않는다.

사진 판단은 사용자 작성의 학습 주석이다. 표시명이나 작성자 구분이 전문가 자격 또는 구조 안전 판정을 인증하지 않는다. 손상 위치 마스크를 새로 그린 것으로도 계산하지 않는다.

실제 제출 후 입력 개수·수정 개수·미확인 개수와 원본 파일 보존을 확인하고, 실험 조건을 고정한 다음 GPU 재학습 및 동일 검증 자료 비교를 진행한다. 기존5%·다른 항목 보존 기준은 유지한다. 현재 학습 자료 변환과 데이터 로더·추출 도구가 준비됐으며, 실제 입력에 따른 재학습 실행과 성능 결과는 아직 없다.

## 개발 파일

- `scripts/prepare_facility_human_review.py`: 고정 모델의 TRAIN 추론과200장 선별.
- `scripts/serve_facility_human_review.py`, `review-ui/human-review.*`: 로컬 화면·자동 저장·제출.
- `safelog_ai/human_training_feedback.py`: 실제 제출 검증과 원본을 보존하는 정답 오버레이.
- `scripts/prepare_facility_human_training.py`: 제출된 파일에서 별도 학습 명세 생성.
- `scripts/facility_human_training_dataset.py`: 충돌한 위치·보조 감독 제외, 제한된 표본 보강.
- `tests/test_human_training_feedback.py`: 실제 집중 테스트9개 통과.

실제 데이터는 무시된 `runs/facility-human-review-20261009/`에 있다. 제출 파일은 `submissions/HUMAN-TRAINING-*.json`, 자동 저장은 `human-draft.json`이다. 사진·개별 입력·검수자 정보는GitHub에 올리지 않는다.

서버가 종료됐을 때 저장된 입력을 유지하며 다시 시작하는 명령:

```powershell
cd safelog-cpp/ai-training
./.venv/Scripts/python.exe scripts/serve_facility_human_review.py --package runs/facility-human-review-20261009/TRAIN-REVIEW.json --port 8770
```

## 검증 범위

집중 테스트9개에서 원본 불변·태그 변경·미확인·파생 부분 사진·보조 감독 제외·200장 구성·제한 추출·잘못된 제출 거부를 확인했다. 별도2장 테스트 화면에서 선택·자동 저장·새로고침 복원·제출을 실제 브라우저로 확인했다. 테스트 제출은명시적으로 `test_fixture=true`이고 재학습 자료로 받아들여지지 않는다. 실제200장 화면에는 테스트 판단을 입력하지 않았다.

화면은 `127.0.0.1`에만 연결되며 선택한200장 사진과 지정된 UI/API만 제공한다. 다른 데이터 파일이나 디렉터리를 열람하는 경로는 제공하지 않는다. 서버는 새 모델 학습을 자동으로 실행하지 않는다.
