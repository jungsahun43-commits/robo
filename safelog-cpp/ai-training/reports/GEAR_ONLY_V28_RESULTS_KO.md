# v28 기어 표면 패치 실제 학습 결과

실제 **1,920 optimizer회/30epoch**를 완료했다. VAL의 라벨·묶음 균등 BCE는 초기0.693147→**0.587897**, epoch **1**/실제64회 가중치를 선택했다.

고정 CAL 임계값 `0.6203120946884155`를 예약 기어 TEST2,179패치에 적용했다. 오탐 **17.93% (168/937)**, 미탐 **37.84% (470/1242)**, AUROC **0.81232**다. 오탐·미탐 모두20% 이하 조건에 못 미쳐 **채택하지 않았다.** 오탐만 골라 반영하거나 TEST 임계값을 바꾸지 않았다.

물리·기능·촬영ID 및 근접 연결 TEST묶음은4개다. 묶음 bootstrap1,000회의 참고 구간은 오탐7.43~38.52%, 미탐3.70~81.82%로 넓다. 패치2,179개를 독립 부품2,179개로 설명하지 않는다.

자료는 FIT5,466/VAL1,440/CAL1,116과 원래 저자S3fold0의 기어 TEST2,179패치다. 이전 FIT/VAL/CAL 합집합에서 원래 TRAIN의 기어 묶음만 재분리했고, 이미 본 FIT예시 묶음1·19는 FIT로 보존했다. TEST·근접 제외 TRAIN·미주석 사진을 학습으로 가져오지 않았다.

이것은 자료 종류별 라벨 수 감사에 따라 먼저 선언한 **기어 표면만의 별도 과제**다. 전체 부품 v26/v27의 실패와 원래 TEST3,109개를 그대로 남기며, 이번 수치를 전체 기어박스 개선으로 합치지 않는다. v26/v27은 각1,920회를 실제 학습했지만 모든 학습 가중치의 VAL이 초기 기준을 개선하지 못해 epoch0 초기 새 head를 선택한 실패 연구다. 해당 평가를 학습으로 개선한 성능으로 표시하지 않는다.

기존 encoder 하나·고정3,072특징을 재사용하고 새0초기화 Linear head만 학습했다. 새 FIT만으로 정규화하고 모든 기존 부모 tensor/buffer/metadata가 정확히 같음을 확인했다. 보호 104113파일 stat·기존Python 655파일 SHA·실제 optimizer 장부·원래 특징 캐시 SHA를 검사했다. 보호 전체SHA를 재계산한 것은 아니다. 새unit2개가 통과했고 새RGB encoder특징 추출은0이다. 이 단계의 새 패키지 API/C++/ZIP 검사도0이다.

기존 앱용 v16-r1과 검정브래킷FP12.50/FN63.83,튜브FP3.12/FN68.12%,기존8/12유형 목표 상태는 그대로다. KS2·볼스크루·LOCO·원래 위치 지도·임계값도 유지한다. 원본·실패 모델·최종 학습 progress·매epoch 장부를 보존했다.

이 회차 v26/v27/v28 실제 optimizer합은 **5,760회**이며 같은 원본 재사용을 새 자연 사진 수로 더하지 않는다. 추적 일부연구합32,080회는 실패 포함이며 전체 역사 학습 총량은 아니다.
