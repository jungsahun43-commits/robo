# 전선 연결부 전체 문맥 실제 학습 결과

기준일: 2026-10-15. 같은 공개 TEST를 재사용한 개발 비교이며 독립 현장 검증이 아니다.

## 사진 판정 결과

| 후보 | 정상119장 오탐 | 결함193장 미탐 | 선택 |
|---|---:|---:|---|
| 기존 v11 | 23/119 = 19.33% | 129/193 = 66.84% | 비교 기준 |
| 새 전체 문맥만 사용 | 17/119 = 14.29% | 80/193 = 41.45% | 비교 후보로 보존 |
| 새 전체 문맥 + 기존 표면 점수 | 23/119 = 19.33% | 77/193 = 39.90% | 연구용 후보 채택 |

사전에 정한 선택 순서인 최대 오탐·미탐의 최솟값에 따라 두 점수를 결합한 후보를 골랐다. 전체 문맥만 쓰는 후보보다 미탐은 낮고 오탐은 높다. **선택 후보도 미탐39.90%로 20% 목표에는 미달**한다. 추가 설비12유형 중 사진 오탐·미탐20% 이내는 기존8개 그대로다.

| 결함 묶음 | 기존 미탐 | 선택 후보 미탐 |
|---|---:|---:|
| 논리 결함108장 | 72/108 = 66.67% | 36/108 = 33.33% |
| 표면·구조 결함85장 | 57/85 = 67.06% | 41/85 = 48.24% |

개별 결함 종류나 다른 공장 성능을 위 두 묶음 수치로 대신하지 않는다. 기존 위치 지도·위치 경고 기준과 나머지 설비의 가중치를 보존했다. 새 문맥 점수는 검증된 결함 위치 지도나 실제 고장 확률이 아니다.

## 실제 학습한 내용

- 동일한 공통 분석부의 low40/high960 특징을 원본 비율을 보존한512×256 입력에서 추출하고4×8 공간 격자로 모았다. 특징 캐시와 실행부 모두 FP16 반올림 후 FP32 계산을 적용한다.
- 전체 격자를128차원으로 압축해 복원하는 새 작은 분기만 학습했다. 기존 공통 분석부·사진 판별기·마스크 판별기·참조 특징·임계값은 고정했다.
- 정상 FIT199장으로 **30epoch, 실제 optimizer1,920회**를 실행했다. 원본·좌우·상하·양방향 반전 입력을 정상 자료의 증강으로 사용하며 추가 사진이나 손상 정답으로 세지 않는다.
- 정상 검증55장에서 복원 MSE가 가장 낮은29epoch·1,856회 시점을 골랐다. 검증 MSE는0.107629다. 복원 손실 감소가 곧 미탐 감소를 뜻하지 않으므로 별도 사진 평가 결과를 사용한다.
- 정상 보정44장으로 두 후보의 기준을 고정한 뒤 TEST312장을 평가했다. 신경망 회차 선택에 CAL/TEST를 사용하지 않았다. 두 후보의 비교·채택은 이미 알려진 TEST를 사용한 개발 선택이다.
- 결함 사진이나 물체 상자·클램프 수·전선 끝점의 지도 정답으로 학습한 것이 아니다. `semanticClampWireRelationsVerified=false`다. 사진 전체의 구성을 복원하는 가설을 학습했으며 실제 의미 관계를 인식한다고 보장하지 않는다.

## 자료 분리와 남은 한계

원본 SHA·RGB·마스크 SHA 및 회전/반전8방향 pHash거리≤2의 연결 묶음을 다시 확인했다. TEST와 근접한 정상 자료62장, CAL과 근접한 TRAIN8장 등은 새 학습에서 제외했다. FIT199장·검증55장·CAL44장·TEST312장은 근접 묶음이 서로 분리돼 있다.

pHash유사는 같은 물리 부품의 증명이 아니다. 부모 모델의 과거 정상 FIT 노출을 되돌린 실험도 아니다. 자료는 고정 리비전 미러이며 원 배포본의 동등성과 로컬 촬영 이력은 별도 검증되지 않았다. 새 현장 사진은 추가하지 않았다.

[MVTec 공식 소개](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad)와 [저자 논문](https://link.springer.com/content/pdf/10.1007/s11263-022-01578-9.pdf)의 자료 정의를 참고했다. 논문의 네트워크를 그대로 재현하거나, 해당 배선 구성 규칙을 모든 산업현장에 일반화한 것이 아니다. 연구용 CC BY-NC-SA4.0 조건을 유지한다.

## 실행·검증
