# v25 기어박스 부품 자료: 확보와 다음 실험 준비

2026-10-15. **자료 확보·저자 메타데이터 검사까지 완료했으며, 새 학습은 아직 0회다.** 이미지 내용 검수, RGB 중복 검사, 최종 FIT/VAL/CAL 분리와 학습 조건은 다음 단계다.

## 1. 자료를 바꾸는 이유

v23 실제 표면 mask 단독 학습과 v24 정상 튜브 적응은 각각 optimizer 1,920회를 완료했지만 기존 채택 기준을 만족하지 못했다. 기존 v16과 역할4 전달 ZIP을 유지한다. 작은 다른 표면 자료의 전이 및 TEST 임계값 변형을 반복하는 대신, 설비 부품 자체에 정상·결함 라벨과 부품 식별 정보가 있는 자료를 검토한다.

## 2. 원출처와 이용조건

- 논문: [A Dataset and Baseline for Deep Learning-Based Visual Quality Inspection in Remanufacturing](https://arxiv.org/abs/2511.15440), DOI [10.1109/ETFA65518.2025.11205777](https://doi.org/10.1109/ETFA65518.2025.11205777).
- 저자가 논문에서 연결한 배포본: [Re-GBC / Gearbox Components Remanufacturing Inspection](https://www.kaggle.com/datasets/jhnnsbr/gearbox-components-remanufacturing-inspection), 공개 version 1.
- [배포자 메타데이터](https://www.kaggle.com/api/v1/datasets/view/jhnnsbr/gearbox-components-remanufacturing-inspection)의 이용조건은 **CC BY 4.0**이다. 저자·논문·출처·버전·변경 내용을 표시한다. 다른 학습 자료의 이용조건까지 CC BY 4.0으로 바꾸지 않는다.

이 자료는 기어·스플라인·동기화 부품의 표면을 잘라 만든 128×128 패치다. OK/nOK는 보이는 마모의 허용 여부를 나타내며, 작은 긁힘·일부 피팅이 있어도 OK일 수 있다. 모든 흔적을 고장으로 분류하거나 기어박스 전체의 정상 작동 정답으로 설명하지 않는다. 클래스 라벨을 결함 위치 mask로 바꾸지 않는다.

## 3. 실제로 확보·검사한 범위

| 항목 | 결과 |
|---|---:|
| ZIP 다운로드 | 414,277,443 bytes |
| ZIP 안 PNG | 15,691개 |
| 저자 라벨이 있는 고유 패치 | 15,588개 |
| OK / nOK | 8,334 / 7,254개 |
| 미주석 PNG — 학습 후보 제외 | 103개 |
| 저자 물리 부품 / 기능 부품 / 촬영 ID | 46 / 44 / 97개 |
| 저자 분리 JSON | 4개, 모든 fold의 사진·라벨·메타데이터 일치 |

ZIP 전체 CRC, 경로·심볼릭 링크 조건, 로컬 SHA256을 검사했다. 로컬 SHA256은 `4c01475a48a8b2fa28a9bd8e0f11ccacf14cc8dc2651b5b72df21f072a241775`이며 저자가 제공한 체크섬은 아니다. JSON만 데이터로 읽었고 배포 코드와 이미지 내용은 실행·열람하지 않았다. 저자 경로의 `../data/patched/`는 검증된 ZIP 멤버에만 대응시켰으며 파일 시스템 상위 경로로 사용하지 않았다.

## 4. 평가 예약과 부품 중복 발견

이미지 열람·점수 계산 전에 **저자 functional_component_id 분리의 fold 0(S3)**을 주 평가용으로 예약했다. 결과가 좋아 보이는 다른 fold나 무작위 사진 분리로 바꾸지 않는다.

- 원래 TEST: **3,109패치 = OK 1,674 + nOK 1,435**. 목록을 그대로 보존한다.
- 원래 TRAIN: 12,479패치. 기능 부품·촬영 ID는 TEST와 겹치지 않지만 **물리 부품 ID 16·18·21·23은 겹친다.**
- 물리 부품·기능 부품·촬영 ID를 연결한 35개 묶음에서 TEST가 포함된 묶음의 TRAIN **813패치를 제외 후보로 고정**했다.
- 픽셀 중복 검사 전 남은 TRAIN 후보는 **28묶음, 11,666패치**다. 아직 FIT/VAL/CAL로 확정한 수가 아니다.

이 메타데이터 검사는 이미지의 정확·회전/반전 근접 중복 검사를 대신하지 않는다. 패치 수를 독립 물리 부품 수나 새 현장 수로 세지 않는다.

## 5. 다음 진행 순서

1. 다운로드 영수증·저자 JSON·예약 목록의 SHA를 확인한다. 라벨이 있는 PNG만 안전하게 해독하고 파일별 무결성을 기록한다. 미주석 103개를 정상으로 바꾸지 않는다.
2. 새 자료 내부 및 기존 보존 TEST 5,746장과 정확 RGB·8방향 pHash 거리 2 이하 후보를 검사한다. 저자 부품 묶음과 중복 연결을 합친다. TEST가 포함된 묶음의 다른 사진을 학습에 넣지 않는다. 원래 TEST 목록과 제외 사유를 보존한다.
3. TRAIN 쪽 묶음만 사용해 FIT/VAL/CAL 배정 규칙을 모델 점수 전에 고정한다. 같은 묶음을 나누지 않는다. 각 분리의 라벨·부품·촬영 수와 최소 표본 조건을 확인한다. 데이터가 부족하면 학습 전에 중단한다.
4. 분리 후 FIT 예시만 시각 확인한다. 저자 라벨의 표면 마모 기준과 앱의 설명 범위를 맞춘다.
5. **기존 공통 encoder 하나를 유지하는 후보 하나**의 구조·초기값·학습 대상·입력·회차·손실·샘플링·VAL 선택·CAL·채택 기준을 코드/JSON으로 확정하고 commit한 뒤 특징·gradient·optimizer를 실행한다. 패치 특징 pooling을 검토할 수 있으나 아직 확정된 구조가 아니다. 무작위 category embedding이나 새 별도 encoder를 넣지 않는다.
6. 이 자료의 패치 판별 성능과 기존 검정 브래킷·튜브 전이 성능을 구분한다. 새 기어 자료의 결과를 기존 설비의 개선으로 설명하지 않는다. 위치 정답이 없으므로 검증된 결함 위치 검출로 주장하지 않는다.
7. 채택 후보만 새 패키지 CPU/GPU·실제 C++·기존 alias 및 기본 위치 출력 보존 검사를 거친다. 실패 후보는 보존하고 v16-r1을 유지한다.
