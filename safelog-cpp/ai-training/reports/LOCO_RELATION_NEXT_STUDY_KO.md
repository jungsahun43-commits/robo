# 전선 연결부의 다음 학습 방향

기준일: 2026-10-15. 이 문서는 공식 규칙과 다음 실험의 설계를 위한 메모이며 새 모델의 성능 결과가 아니다.

## 공식 자료에서 확인한 정상 구성

LOCO AD는 흠집·오염 같은 표면 결함과 구성·관계가 어긋나는 논리 결함을 구분한다. [MVTec 공식 데이터 소개](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad)

전선 연결부의 정상 조건은 다음과 같다. 특정 정상 사진 한 장에서 추정한 규칙이 아니다. [저자 논문 3.1절·표14](https://link.springer.com/content/pdf/10.1007/s11263-022-01578-9.pdf)

| 대상 | 정상 구성 조건 |
|---|---|
| 연결부 | 두 개이며 양쪽 클램프 수가 같음 |
| 전선 | 두 연결부 사이를 하나의 전선이 연결 |
| 색과 종류 | 클램프 수와 전선 색 사이의 대응 관계가 있음 |
| 연결 위치 | 양쪽 끝의 상대 위치가 같아 구성에 좌우 대칭 관계가 있음 |

논리 결함에는 부품 종류 불일치·누락·추가 전선·색 불일치·연결 위치 차이가 포함된다. 색과 클램프 수의 구체적 대응표를 위 논문의 문장만으로 확정하지 않는다. 모든 산업현장 배선에 이 데이터셋의 구성 규칙을 적용하지 않는다.

## 현재 자료와 한계

현재 원본 분리 기록에는 정상 FIT330장, 정상 CAL54장, 정상 TEST119장과 결함 TEST193장이 있다. CAL은 배포 자료의 정상 validation을 기반으로 한다. 학습용 실제 결함 사진이나 연결부별 물체 상자·클램프 수·전선 끝점의 지도 라벨은 준비돼 있지 않다. 기존 평가 미탐은 66.84%다.

정상 자료를 학습하면서 TEST의 결함 마스크를 학습 라벨로 가져오지 않는다. 현재 로컬 자료는 고정 리비전 미러에서 받았으므로 원 배포본과의 동등성 및 촬영 이력은 별도 확인되지 않았다. 논문의 분리 설명을 로컬 자료에서 직접 검증한 것으로 쓰지 않는다.

## 우선 수행할 실험

1. 정상 FIT/CAL/TEST의 바이트·RGB·회전/반전 근접 묶음을 다시 확인하고 학습과 보정을 분리한다.
2. 같은 공통 분석부에서 사진 전체의 공간 특징을 추출해, 전역 문맥을 보는 작은 복원 분기를 정상 FIT로 실제 학습한다. 기존 1×1 지역 복원만으로 표현하기 어려운 관계를 보강한다는 가설이다.
3. 학습 횟수·구조·검증용 정상 FIT 하위 분리·보정·선택 조건을 먼저 고정한다. CAL은 임계값 보정에만 사용하고 TEST는 반복해서 맞추지 않는다.
4. 전체 사진 지표와 논리/표면 결함의 미탐을 따로 평가한다. 기존 위치 출력과 다른 설비의 가중치·기준을 보존한다.
5. 그래도 구성 관계를 충분히 표현하지 못하면 정상 TRAIN에 연결부 상자·클램프 수·전선 끝점의 명시적 라벨을 확보해 지도학습 후보를 만든다. 자동 라벨은 사람의 검증 없이 정답으로 취급하지 않는다.

이 분기는 아직 구현·학습되지 않았다. 논문의 방법을 그대로 재현했다거나 배선 관계를 이미 인식한다고 발표하지 않는다. 독립 현장 성능은 미검증이며 자료 라이선스는 CC BY-NC-SA4.0이다.
