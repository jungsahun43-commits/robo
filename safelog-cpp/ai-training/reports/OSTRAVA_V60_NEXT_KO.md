# v60 실제 산업 부식 위치 주석 자료 확보 이후 순서

원저자 Matěj Frič의 [Zenodo record 11235637](https://zenodo.org/records/11235637), DOI 10.5281/zenodo.11235637, v2를 선택했다. 공식 API의 데이터 라이선스는 CC BY 4.0이다. 저자·자료 출처·버전·변경 사항을 표시하며 기존 InsPLAD/다른 자료 조건은 바꾸지 않는다.

## 현재 작업 범위

`scripts/fetch_ostrava_corrosion.py`는 고정된 원배포 URL 한 개의 ZIP만 받는다. 기대 크기 384,363,293바이트와 배포자 MD5를 비교하고 로컬 SHA256, 전체 inner CRC, 안전 경로, 각 파일의 encoded SHA를 남긴다. 원저자의 코드를 실행하거나 전체 ZIP을 확장하지 않는다. 부분 다운로드와 오류도 보존한다.

다운로드 완료 여부는 `data/industrial-new-rust-belt-v60-source/ostrava-archive-audit.json`과 호스트 프로세스·stdout/stderr로 확인한다. 완료 전 중복 다운로드를 시작하지 않는다. 원배포자가 설명한 105장·2048×2048·75:15:15 분리는 아직 실제 파일·사진·주석으로 확인한 값이 아니다. 받은 파일 목록과 대조한다.

## 다음 자료 감사: v61

1. 사진 픽셀이나 내용을 열기 전에 ZIP 파일 목록에서 원래 TRAIN/VAL/TEST, 이미지와 주석의 대응을 확인하고 원래 TEST의 명시적 ID 목록·SHA를 예약한다. 파일명의 경로 정보 외에 촬영/물리 부품 ID가 있는지 확인한다. 알 수 없는 부품 ID를 만든 것으로 설명하지 않는다.
2. 실제 주석 포맷과 좌표 의미를 데이터로만 확인한다. 분류/상자 정답을 pixel mask로 바꾸거나 색 팔레트의 의미를 추측하지 않는다. 코드·노트북을 실행해 원저자 결과를 재현했다고 주장하지 않는다.
3. 새 해독/중복/분리 절차, 고정 최소 표본, 오류 시 중단 조건을 별도 코드·JSON으로 먼저 정하고 commit/push한다. PNG/JPEG 안전 해독·원본 SHA·크기·EXIF·마스크 대응을 검증하고 원본을 고치지 않는다.
4. 새 자료의 정확 RGB와 회전/반전 pHash≤2 및 명시 촬영/부품 묶음을 연결한다. 기존 보존 TEST 8,995장, InsPLAD 원래 평가 6,417장, 새 publisher TEST 6,481장의 검증 지문을 재사용한다. 새 자료와 가까운 현재 TEST는 새 학습에 넣지 않는다. 기존 자료의 전체 해독·근접 감사를 다시 돌리지 않는다.
5. 원래 TEST는 보존하고 해당 연결 묶음의 나머지 개발 사진은 제외한다. 남은 저자 TRAIN에서만 한 가지 FIT/검증/보정 역할을 고정한다. 저자 VAL 역할을 사용할지는 실제 폴더 의미를 확인한 뒤 사전에 선언한다. 이미 본 FIT 예시를 VAL/TEST로 돌리지 않는다.
6. 분리와 최소조건이 통과한 뒤 고정된 첫 FIT 이미지/주석만 시각 QA한다. 정상 전체 사진이 없으면 사진 전체 오탐률을 산출했다고 말하지 않는다. 주석 밖 정상 patch는 주석상 음성이지 설비 전체 정상 작동 정답이 아니다.

## 이후 한 가지 실제 학습 후보

실제 자료 감사가 끝난 뒤에만 기존 공통 인코더에 추가하는 부식 위치 판별부 **하나**의 구조, 입력 좌표, 초기값, 실제 손상 정답 범위, 학습 대상, 추출/캐시 수치 경계, 손실, 회차, VAL 선택, CAL, 채택 기준을 코드와 JSON에 고정한다. 기존 v16과 승인 3개 분기의 모든 가중치·버퍼·메타데이터·점수·기본 위치를 보존한다. 별도 인코더나 가짜 자료/날짜 입력을 추가하지 않는다.

v58의 정상 분포 학습 실패와 달리 실제 부식 정답을 이용할 가능성을 조사하는 단계다. 아직 주석을 학습했거나 성능이 개선된 단계가 아니다. 원래 TEST가 15장 수준이고 전체 정상 사진이 없다면 새 앱 유형의 사진 오탐·미탐 20% 통과를 선언할 수 없다. 위치 지표와 기존 설비 전이를 구별해 사전 조건을 세운다. TEST에 맞춰 임계값이나 기준을 반복 바꾸지 않는다.

원본·실패 모델·캐시·보고서·ZIP을 삭제하지 않고 1GiB 이상 여유를 유지한다. 부모가 필요한 작은 검증된 delta만 저장하며 새 full parent와 불필요한 dense cache를 만들지 않는다. 채택 조건을 충족한 후보에만 새 CPU/GPU·C++·기존 alias/위치 PNG 보존 검사를 수행한다.

## 다른 후보

BeltCrack 공식 데이터 V1은 CC BY-SA 4.0, 21파일/42.03GB로 확인했다. 전체 다운로드는 하지 않는다. 실제 파일 URL·부분 접근·해독·분리·무결성과 저장 여유가 확인된 경우에만 별도 절차를 세운다. 원저자 공개 압축 비밀번호는 접근 허가·자료 라이선스와 구별한다. 현재 확보한 학습 사진 수에 넣지 않는다.
