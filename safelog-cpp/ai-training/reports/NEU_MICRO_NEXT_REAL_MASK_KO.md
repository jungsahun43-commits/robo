2026-10-15. v20과v21은 각각 실제1,920 optimizer 후 전부 제외됐다. 현재 앱용 연구 모델·역할4 전달물은v16-r1 그대로다. 이 자료에 대한 **새 학습·encoder 특징·모델 점수는0회**이며 정식 학습 프로토콜은 아직 없다.

## 출처와 확인한 이용 범위

[원 배포자의 표면 자료 모음](https://github.com/abin24/Surface-Inspection-defect-detection-dataset/tree/ebb19cce70109d0fde06a9220469bfb4de7212ac)은 학술 연구 전용·상업 이용 금지·원 제공자 인용을 명시한다. 이 저장소의 배포자는 NEU Kechen Song의 micro/oil 표면 이미지에 자신들이 픽셀 주석을 추가했다고 설명한다. 따라서 원저자 이미지와 주석 추가 배포자를 각각 인용하고, 존재하지 않는 CC/MIT 등의 SPDX를 붙이지 않는다. 신규 이용 범위는 이 배포본의 학술 연구 범위로 유지한다.

고정 배포 revision은 `ebb19cce70109d0fde06a9220469bfb4de7212ac`이다. ZIP은9,715,414bytes, 로컬 SHA256 `be62df34591a59aa57a67c8c220de516ad7cac1867c9c9c8206767603c0d70a6`이다. GitHub tree의 Git blob SHA1와 파일 내용이 일치하고 전체 ZIP CRC가 통과했다. 이 SHA256은 로컬 측정이며 원저자가 제공한 체크섬이라고 설명하지 않는다. archive의 코드는 실행하지 않았고 이미지·mask만 안전한 경로로 추출했다.

자료는1800장의 NEU-CLS나 SD-saliency-900이 아니다. 이 작은 별도 micro/oil 배포본은 사진51장과 대응하는0/255 PNG mask51장이다.

정상 전체 사진은 없다. 이 자료 자체의 전체 사진 오탐률이나 새 앱 유형20% 통과를 계산할 수 없다. 표면의 주석은 기계 내부·전기 기능 고장 정답이 아니다. 기존에 사용한 데이터인 것처럼 세거나51개를 즉시 학습한 것으로 표시하지 않는다.

## 중복과 분리·검수 상태

기존 equipment/KS2/볼스크루/자기타일 TEST5611장에 KSDD1 고정 TEST135장을 더한 **5746장**의 원본을 검사했다. 새51장과 정확 RGB 또는8방향 pHash거리2 이하 후보는0개다. 새 자료 내부에서도 같은 기준 근접 링크는0개다. 이는 동일한 물리 부품이나 촬영 세션의 독립성 증명이 아니다.

사진 내용을 보기 전에 파일 이름 계열을 보수적으로 예약했다. Scratch/SDI/SPDI 계열41장은 향후 FIT 전용, 나머지Oil Small_defect/Wipe_crack10장은 미열람 VAL 후보로 뒀다. 세 계열의 첫 사진3장만 FIT 검수용 contact sheet로 확인했다. `QA-reservation.json`은 원래대로 보존한다.

**FIT 검수에서 추가 제외가 필요했다.** Oil Scratch_1 원본에는 주석 대상의 어두운 선 옆에 큰 흰색 표시가 들어 있다. 실제 분필 표시인지 이미지에 추가한 그래픽인지 확인하지 못했다. 이 단서가 일반 현장 사진과 다른 편향을 만들 수 있어 **Oil Scratch6장을 후보 학습에서 제외**한다. 흰 표시를 새 결함 라벨로 바꾸거나 inpaint 결과를 실제 clean GT로 쓰지 않는다. 이미 본 계열을 VAL/TEST로 돌리지도 않는다.

SDI_1과SPDI_1에서는 작은 어두운 표시와 밝은 mask의 위치가 대체로 맞아 보였다. 원래 픽셀 전체의 정확성이나 나머지48장 전체 품질을 검수했다고 주장하지 않는다. SDI 표시는 특히 작아512전체 축소 입력에서 얼마나 보존되는지 FIT에서 확인할 필요가 있다.

현재 남은 후보는 **FIT35쌍(SDI20+SPDI15), 미열람 VAL10쌍, 제외6쌍**이다. 파일 계열은 물리 부품 식별자가 아니며, 이 예약은 완성된 학습 프로토콜·독립 평가 분리를 대신하지 않는다. 새 자료의 CAL·독립 TEST는 없다.

## 다음 작업

1. 완료된v20/v21과 합성 생성기를 다시 돌리거나 현재 TEST 임계값을 맞추지 않는다. 기존 실패 가중치·기록을 보존한다.
2. 위 파일 계열 예약·제외와 실제 mask 좌표를 지키는 정식 FIT/VAL manifest를 만든다. 학습용 정상 자료와 위치·사진 label 범위, 촬영 그룹 미검증 한계를 명시한다. 주석 바깥 patch를 사용할 경우 ‘주석상 결함이 없는 patch’이지 부품 전체 정상 작동 정답이 아님을 기록한다.
3. 작은 실제 표시의 해상도를 FIT만으로 조사한다. 필요하면 실제 RGB patch/고정 tiled inference 가설 하나를 먼저 정한다. mask로 고른 학습 crop을 TEST에서 정답 위치로 crop하는 데 사용하지 않는다. 원래 전체 사진으로 계산하는 CAL/TEST 정책을 미리 고정한다.
4. 기존 한 공통 encoder를 유지하는 한 후보의 구조·초기값·학습 대상·회차·샘플링·손실·VAL 선택·CAL·반영 guard를 코드/JSON에 고정하고 commit한 뒤 새 특징·gradient·optimizer를 실행한다. 정상 복원 잔차를 새 자료의 가짜 설비 category에 임의로 넣거나 source 식별 shortcut을 만들지 않는다.
5. 기존 보호 가중치·점수·위치 기준을 보존한다. 미탐5%p 이상 감소, 오탐 증가5%p 이내이면서20% 이하, 라벨별 최소20장·종류별 회귀 제한 등 기존 target guard는 그대로다. 통과 후에만 새 전달물 CPU/GPU·실제 C++·원래 위치 PNG를 새로 검사한다.

새 자료는 실제 금속 표면 주석을 보강하는 연구 후보다. 컨베이어의 모든 기계 고장이나 전선 조립 규칙을 학습한 것으로 설명하지 않는다. 공개 benchmark 반복 개발과 독립 현장 성능을 구별한다.
