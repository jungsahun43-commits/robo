# MPDD2 전체 공개 목록 확인과 흰색 브래킷 후보

공식 배포 폴더의 공개 embeddedfolderview에서 26개 폴더와 PNG 745개 링크를 확인했다. 이전 224개 링크가 모두 같은 경로로 포함되어 있고 추가 521개는 **새로 확인한 목록**이다. 아직 새로운 비중복 사진 521장을 확보했다는 뜻은 아니다. 공개 링크만 HTML 데이터로 읽었으며 브라우저 계정·쿠키·API 키·개인정보를 사용하거나 JavaScript를 실행하지 않았다.

| 종류 | 정상 TRAIN | 정상 TEST | 이상 TEST |
|---|---:|---:|---:|
| 갈색 브래킷 | 44 | 15 | 81 |
| 회색 브래킷 | 64 | 19 | 65 |
| 흰색 브래킷 | 195 | 49 | 91 |
| 로제트 | 82 | 13 | 27 |

흰색만 공개 TEST의 정상·이상 사진 수가 각각 20장 이상이다. 다음 v39 자료 감사는 흰색 335장으로 제한한다. 다른 종류를 합치거나 TRAIN을 TEST로 이동해 부족한 평가 수를 채우지 않는다. 기존 MPDD와 같은 명칭이어도 비중복·동일 부품·같은 분포라는 증거가 아니므로 RGB 정확 및 회전·반전 근접 검사를 먼저 한다.

전체 목록 inventory SHA256: `e3beff9e6e3615c973d4f8a3073856e1485ab106f5479d80c70d392a5365492b`. HTML 목록은 숨겨진 모든 배포 자산의 존재까지 보증하지 않는다. v38 사진 다운로드·특징·optimizer는 0회다. GLinks v35의 실패한 분리와 v36의 촬영 ID 미확인 상태는 유지한다.
