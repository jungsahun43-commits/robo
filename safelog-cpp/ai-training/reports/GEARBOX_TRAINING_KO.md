# v26 기어박스 표면 패치의 실제 라벨 학습 조건

2026-10-15. 아직 모델 특징·점수를 계산하기 전에 고정한 단일 후보다. Re-GBC version1, CC BY4.0, [저자 논문](https://arxiv.org/abs/2511.15440), DOI10.1109/ETFA65518.2025.11205777을 인용한다. 원래 자료와 v25 준비안은 보존한다.

## 자료 분리와 v25 준비 중단

v25는 이미지 15,588개의 RGB·8방향 pHash 거리2 이하 중복을 검사했다. 기존 TEST5,746장과의 후보는0, 새 자료 내부 연결쌍은2,691개다. 저자 물리·기능·촬영ID와 연결하면35묶음이32묶음으로 합쳐진다. 예약 TEST3,109패치를 유지하고 TEST와 연결된 TRAIN1,317패치를 제외한다. 미주석103개도 제외한다.

v25의 고정 SHA 분리는 CAL 정상10<사전 최소20으로 새 특징·점수·학습0회에서 중단했다. 최소조건·원래 분리를 고치지 않고 별도 v26을 만들었다. v26은 저자의 TRAIN 라벨만 사용해, 큰 묶음부터 고정 순서로 각 클래스 목표70/15/15 비율의 오차 증가가 가장 작은 분리에 배정한다. 묶음 개수의17/4/4 용량을 먼저 고정했으며 seed·분리 재시도를 하지 않았다. TEST 라벨은 배정 목적함수에 사용하지 않았다. 같은 묶음은 여러 분리에 들어가지 않는다.

| 분리 | OK | nOK | 패치 합계 | 연결 묶음 |
|---|---:|---:|---:|---:|
| FIT | 4,024 | 4,196 | 8,220 | 17 |
| VAL | 787 | 617 | 1,404 | 4 |
| CAL | 845 | 693 | 1,538 | 4 |
| 저자 S3 fold0 TEST 유지 | 1,674 | 1,435 | 3,109 | 7 |

이 숫자는 128×128 표면 패치 수이며 독립 부품·현장 수가 아니다. 아직 원래 TEST 목록을 바꾼 적이 없으며 학습에 가져오지 않는다.

## 단일 후보

- 입력은 라벨에 관계없이 원본128패치를 RGB bicubic256 정사각형으로 확대하고 ImageNet 정규화한다. GT에 따른 crop이나 증강은 사용하지 않는다.
- 기존 공통 encoder 하나의 fine24/low40/high960을 사용한다. 각 맵 FP16 왕복 후 채널별 평균·모표준편차·최댓값을 FP32로 구해3,072차원으로 합치고, descriptor도 FP16 왕복한다. 작은 pooling 캐시를 사용하며 별도 encoder를 추가하지 않는다.
- FIT만의 채널 평균·모표준편차(하한1e-3)로 정규화하고[-8,8]로 제한한다. 새로운 Linear3072→256/GELU/Dropout.1/Linear256→1 분류부만 학습한다. 기존 모든 tensor/buffer/metadata는 유지한다.
- seed2626, batch64에서 OK/nOK32개씩 추출한다. 각 라벨 안에서 묶음을 균등하게 뽑는 효과가 되도록 묶음 패치 수의 역수로 가중한다. 반복 추출은 새 사진 수가 아니다.
- BCE, AdamW lr1e-3/wd1e-4, cosine30epoch/min1e-5, clip5, FP32/TF32off. **30epoch×64=1,920 optimizer회**를 계획한다.
- epoch0 및 매epoch의 VAL에서 각 라벨·묶음별 평균 BCE를 먼저 구한 뒤 라벨을 균등 평균한다. 가장 이른 엄격한 최솟값을 선택한다. epoch0 선택은 배포하지 않는다.
- 선택 후에만 CAL 라벨로 max(FPR,FNR) 최소 임계값을 고른다. 동률은 합계·0.5까지 거리·낮은 임계값 순으로 결정한다. strict `>`를 사용하고 CAL 결과를 저장한 뒤에만 TEST 특징·점수를 계산한다.

## 평가와 채택 조건

TEST 라벨별20개 이상, 사진 조각 FPR/FNR 모두20% 이하, 라벨별20개 이상인 기능 부품 종류 각각 FPR/FNR25% 이하, 선택epoch>0을 요구한다. 종류별·물리부품별 결과와 묶음 단위 bootstrap 구간을 남긴다. TEST묶음이7개뿐인 불확실성도 표시한다. 임계값·분리·조건을 TEST에 맞춰 반복 수정하지 않는다.

채택 후보만 새 패키지 CPU/GPU·실제 C++·기존 alias·원래 기본 위치 출력 보존을 확인한 뒤 전달물에 반영한다. 이번 학습 자체는 검정 브래킷·튜브 전이 실험이 아니며 그 수치를 개선했다고 설명하지 않는다. 기존 앱 모델 v16-r1은 배포 검증이 끝날 때까지 유지한다.

## 해석 범위

OK/nOK는 저자의 보이는 마모 허용 기준이다. 작은 긁힘·일부 피팅도 OK일 수 있다. 전체 기어박스의 작동 건강, 내부 고장, 임의 현장 전체사진의 정확도 또는 검증된 결함 위치 정답으로 쓰지 않는다. mask/bbox가 없으므로 분류 라벨로 위치 정답을 만들지 않는다. 독립 새 현장 검증은 없고, 기존 부모의 과거 근접 노출·촬영 그룹 한계도 보존한다.
