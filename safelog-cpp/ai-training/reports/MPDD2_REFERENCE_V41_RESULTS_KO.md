# v41 세밀한 정상 참조 결과 — 반영 제외

사전 commit `4fc0294` 이후, v39의 정상 FIT 113장에서 같은 공통 encoder의 fine24/low40 공간 특징을 추출했다. 고정된 공간 위치에서 정상 참조 벡터 28,928개를 등록했다. 이것은 **정상 참조 자료 등록**이며 실제 optimizer는 **0회**다. v40의 실제 1,920회 학습과 합쳐서 추가 신경망 학습을 한 것처럼 표시하지 않는다.

검증 26장은 정상 점수 진단에만 사용했다. 정상 CAL 25장의 사전 순서통계량(rank23)으로 기준 0.153780을 저장한 뒤 원래 TEST를 한 번 평가했다. 임계값·pooling 비율·참조 위치를 TEST 결과에 맞춰 다시 조정하지 않았다.

| 지표 | 결과 |
|---|---:|
| 사진 오탐 | 6/49 = 12.24% |
| 사진 미탐 | 69/91 = 75.82% |
| AUROC | 0.59991 |
| 새 API/C++/ZIP 검사·출시 | 0 |

오탐·미탐 모두 20% 이하 조건에 실패해 제외했다. 기존 v16-r1과 이전 위치 출력은 유지했다. 원래 위치 주석이 없으므로 이 참조 거리를 검증된 손상 위치로 설명하지 않는다. v40에서 이미 본 공개 TEST를 사용한 개발 결과이며 새로운 독립 현장 검증이 아니다. 검정 브래킷·튜브 전이는 평가하지 않았다.

원본 RGB 304장(FIT113+VAL26+CAL25+TEST140)을 새로 공통 encoder에서 읽었다. 첫 FIT의 기존 low/high는 일반 forward와 정확히 일치했다. 부모 전체 tensor/buffer/metadata 보존, 새 차이본의 디스크 저장 후 전체 상태 복원 정확 일치, 기존 Python 704개 SHA와 보호 315,334개 파일의 크기·수정시각을 검증했다. 보호 원본 전체의 내용 SHA를 모두 재계산한 것은 아니다. 런타임 오류는 없었다.

연구 차이본 SHA256 `4c8e01b05463173530f3daf537931f012a8bd9a1a8fba1fd804ad700e0e168d0`, 3,763,049바이트다. 부모 가중치가 필요하며 앱 전달물로 출시하지 않았다. 기존 실패 후보·원본·캐시는 보존한다.

이번 두 방식의 결과는 **정상 사진만 학습/등록한 현재 표현으로 목표 미탐률에 도달하지 못했다**는 근거다. 정확한 실패 원인을 인과적으로 증명하지는 않는다. 다음은 실제 TRAIN 손상 위치 정답을 가진 원저자 자료의 이용조건·입력 도메인·자료 분리·중복·용량을 먼저 확인한다. 같은 정상 복원/참조 방법과 TEST 기준을 반복 조정하지 않는다.
