# v74: 고정 VAL만의 예측 영역 진단

`b0e0f46`에 조건을 사전 push한 뒤 기존 VAL 75장에 공통 encoder를 75회 실행하고 고정 v62/v73 두 head를 150회 평가했다. CAL·TEST 새 특징/점수, 새 optimizer, 사진 내용 열람, 마지막 가중치 승격은 모두 0이다. v73 입력 RGB·정답 SHA와 선택 모델 전체 tensor/buffer 상태 전후가 정확히 같았다.

| VAL 원본 좌표 영역의 양성 예측 비율 | v62 고정 cut .20 | v73 고정 CAL cut .30 |
|---|---:|---:|
| Ostrava 주석 양성 | 95.87% | 91.72% |
| Ostrava 알려진 음성 | 7.79% | 8.49% |
| VT 주석 양성 | 53.02% | 99.99% |
| VT unknown | 5.98% | 91.90% |

**VT unknown의 91.90%는 FP가 아니다.** 원주석의 Good에는 미미한 부식도 포함돼 이진 녹 부재의 정답이 없다. 그러나 넓게 양성을 출력하는 후보가 양성 recall만으로 성공할 수 있다는 위험을 보여준다. 실제 source shortcut이나 오류 원인을 인과적으로 증명한 것은 아니다. 두 head의 cut도 각각의 기존 CAL에서 고정된 값이라 학습만의 인과 효과로 해석하지 않는다.

v73 후보는 이미 별도 Ostrava TEST 보존 조건을 위반해 제외했다. 이 진단으로 구제하거나 unknown을 음성으로 바꾸지 않는다. 같은 손실 혼합비·가중치·구조·TEST cut 탐색을 반복하지 않는다. 다음 자료 후보는 원저자가 부식과 **배경을 직접 주석**한 사진이며, 원저자 이용조건·표본·좌표·그룹·현재 TEST 중복부터 확인한다. 작은 주석 patch를 전체 정상 사진/전체 binary mask로 확대하지 않는다.
