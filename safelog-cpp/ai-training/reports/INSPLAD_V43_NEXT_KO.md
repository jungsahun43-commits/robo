# v43 다음 후보: 실제 설비의 정상·부식·파손 사진 라벨

MSDD 위치 주석은 오류 때문에 제외한다. 다음 후보는 [원저자 InsPLAD](https://github.com/andreluizbvs/InsPLAD)가 제공한 **지도학습용** cropped asset 분류 자료다. 실제 전력 설비 영상에서 자른 부품의 정상·가시적 부식/파손 등을 분류하는 과제다. 영상별 상태 정답이며 손상 pixel mask가 아니다. 송전 설비의 영상 결과를 다른 기계의 내부 고장이나 전기 안전 판정으로 확대하지 않는다.

## 확인한 출처와 이용조건

[Mendeley V1](https://data.mendeley.com/datasets/5n3fjgvfyz/1), DOI `10.17632/5n3fjgvfyz.1`이 원저자 README의 실제 배포 링크다. 고정 author revision `1b713698d7e97836b41a62dfa3314c20f3acda70`의 LICENSE와 Mendeley V1은 **CC BY-NC 3.0**을 표시한다. 비상업 학술 연구·저자/출처/버전/변경 표시를 유지한다. 옛 프로젝트 페이지에는 NC-SA 4.0이라는 다른 표시가 있으며, 실제 사용하는 Mendeley V1의 조건을 임의로 다른 이름으로 바꾸지 않는다. 논문 DOI는 `10.1080/01431161.2023.2283900`이다. 원저자의 예전 supervised Drive 링크는 확인 시 404였고 접근을 우회하지 않았다.

공개 클라이언트가 사용하는 익명 파일 목록 API에서 원래 배포 ZIP `InsPLAD_Dataset.zip` 6,400,493,732바이트를 확인했다. 배포자 SHA256 `effd039e4b192088b17e9f6237bcd1b83ae1082a7eb5db89a4944dad0f489139`는 아직 전체 파일로 검증하지 않았다. 중앙 목록은 HTTP 206 범위 **460바이트**로 확인했다.

| 하위 ZIP | 원래 바이트 | 선택 여부 |
|---|---:|---|
| InsPLAD-det | 4,361,421,001 | 받지 않음 |
| unsupervised_anomaly_detection | 1,170,967,719 | 받지 않음 |
| supervised_fault_classification | 874,753,167 | 다운로드 후보 |

선택된 하위 ZIP의 outer 압축 payload는 872,637,838바이트, method8(raw deflate), 원래 CRC32는 `47c40d0a`다. 전체 6.4GB를 받지 않고 이 payload만 범위로 읽어 원래 내부 ZIP으로 직접 스트리밍 해제할 수 있다. 별도 압축 복사본을 만들지 않는다. 현재 공간에 맞는 이 방법의 제한·CRC·크기·원본 헤더 확인을 다운로드 전에 코드/정책 r1에 고정했다. 초기 정책은 압축 비율이 큰 중앙 목록에 대한 drain 처리를 실행 전에 보완한 보존본이며 실제 전송에는 r1만 사용한다.

## 다음 실행 순서

1. `fetch_insplad_supervised.py fetch`는 현재 r1 조건으로 하위 ZIP만 받는다. 크기·CRC32·부분 수신 SHA256/내부 ZIP 로컬 SHA256을 확인하고 원래 전체 배포 SHA 검증과 구별한다. 오류가 나면 partial과 수신량을 보존하며 같은 작업을 중복 실행하지 않는다.
2. 압축 항목의 안전 경로·CRC·종류/라벨·원래 TRAIN/VAL/TEST 및 원본 촬영/사진 ID 연결을 **사진 해독/열람 전에** 감사한다. 정상/결함별 평가 수와 크롭별 원본 ID를 확인한다. 동일 원본의 여러 크롭이나 다른 InsPLAD 하위 ZIP의 중복을 새 독립 사진으로 세지 않는다.
3. publisher TEST 및 그 정확/8방향 근접·원래 전체사진/촬영 묶음의 TRAIN을 제외한 뒤 FIT/VAL/CAL을 한 번 고정한다. 기존 보존 TEST와 중복도 검사한다. 원래 TEST를 TRAIN으로 옮기지 않는다. 드론 촬영/부품의 독립성이 미확인인 한계는 기록한다.
4. 픽셀/위치 정답이 아니라 원저자 영상별 상태 라벨만 학습한다. 실제 사진과 조건에 맞는 공통 encoder의 작은 분류 분기 **하나**를 구조/초기값/샘플링/회차/VAL 선택/CAL/채택 기준으로 고정하고 commit/push한 뒤 특징·gradient·optimizer를 실행한다. 지금 학습 조건은 미확정이다.
5. 유형별 원래 평가 사진이 각 라벨 20개 미만이면 그 유형의 20% 목표 통과를 선언하지 않는다. 통과 후보만 새 CPU/GPU·실제 C++·기존 alias/기본 위치 보존을 검사해 반영한다. 기존 v16-r1은 그대로다.

이번 확인에서 InsPLAD 사진 해독·모델 특징·점수·optimizer는 0이다. 하위 ZIP을 받더라도 원본 사진 해독/그룹 감사/학습 완료로 세지 않는다. 연구 과제는 가시적 상태 분류이며 독립 현장 성능이 아니다.
