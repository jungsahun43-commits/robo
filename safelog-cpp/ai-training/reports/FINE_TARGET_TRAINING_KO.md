# v20: 공통 분석부의 세밀한 특징을 쓰는 단일 후보

2026-10-15. 이 문서와 JSON 프로토콜·코드를 먼저 commit한 뒤 새 특징 추출과 실제 학습을 실행한다. v8~v19는 완료됐으며 다시 학습하지 않는다.

## 자료와 정답의 범위

v19-r1 고정 자료를 그대로 재사용한다. FIT는 정상 배경131장과 절차적 변형478개, VAL은 정상33장과 변형129개다. 배경과 KSDD1 모양 자산은 FIT/VAL 사이 분리됐다. 합성 생성기는 재실행하지 않는다. 이 변형들은 조작 위치의 정답이며, 새로 확보한 실제 자연 고장 사진이나 사람이 확인한 결함 라벨이 아니다. 자연 결함 VAL이 없는 한계가 있다. 원래 정상 표면도 부품 전체의 기계·전기 정상 작동을 보증하지 않는다.

## 단일 구조

- 현재 v16의 모든 기존 가중치·buffer·메타데이터를 보존한다. 기존 공통 분석부의 stage3에서 fine24(128×128)를 읽는다. 별도 사전학습 encoder를 추가하거나 기존 forward/return_layers를 바꾸지 않는다.
- low40, 고정 high960→32, 고정 설비 복원 잔차1을128격자로 보간한다. 새 fine24→16 projection을 더한89채널을 새 fusion에 입력한다. 원래 장치별 분석·기본 위치 지도는 그대로 유지한다.
- v19의 VAL 선택 가중치를 초기값으로만 사용한다. 첫73입력은 복사하고 추가16입력 가중치는0으로 시작한다. fine projection은 seed2020의 PyTorch 기본 초기화다. 격자가 달라 초기 출력이 v19와 같다고 주장하지 않는다.
- 새 fine projection과 fusion만 학습한다. backbone, equipment 복원부, high projection과 나머지 분기는 고정한다. fine은 raw FP16 왕복이며 평균·표준편차 정규화를 새로 맞추지 않는다.

## 좌표·캐시 검사

RGB SHA, 행 순서와 ID, 원래512좌표, 절차 mask와 valid를 확인한다. 새로 추출한 low/high를 기존 v19 캐시와 모든 FIT/VAL771입력에서 비교한다. FIT/VAL 복원 잔차도 비교한다. 같은 배치8, TF32 off, FP16 경계를 사용한다. 수치 허용치는 사전에 `torch.allclose(atol=5e-4, rtol=1e-3)`로 고정한다. bit 단위 일치 여부와 최대 차이는 별도로 보고하며, 실패 시 기존 캐시를 몰래 다시 만들지 않고 중단한다.

새 fine만 캐시에 저장하고 기존 coarse 캐시를 읽는다. CAL/TEST는 각 단계가 허용된 뒤 원본 RGB에서 fine을 추출하고 coarse·geometry를 대조한다. TEST 점수는 CAL 파일을 저장한 다음 계산한다.

## 학습·평가 조건

30epoch×64step=예정1,920 optimizer 갱신. 배치8은 유형별 정상2·합성2이며 그룹당 중복 수의 역수로 추출한다. cached fine/low/high/잔차/mask/valid를 함께 H/V 반전한다. 변형 횟수를 새 실제 사진 수로 세지 않는다.

AdamW lr1e-4/wd1e-4, cosine 최소1e-6, gradient clip5, FP32. loss는 valid BCE + softDice +0.5×top32 사진 BCE이며, 양성 가중치는 같은 FIT mask에서만 계산한다. VAL은 유형×정상/합성 네 집단의 평균 loss로 epoch0 및 매 epoch를 평가해 가장 이른 최솟값을 선택한다. 자연 결함 성능을 VAL에서 직접 최적화한 것은 아니다.

정상 CAL30/23장의85% 순서 통계량을 저장한다. 새 점수 단독과 현재 v16 점수와의 max 결합 두 방식만 평가한다. 조건은 사진 라벨별 최소20장, 현재 v16보다 미탐5%p 이상 감소, 오탐 증가5%p 이내이면서20% 이하, 결함 종류 표본10장 이상이면 종류별 미탐 회귀5%p 이내, 선택 epoch>0이다. TEST 수치에 맞춰 임계값·구조·조건을 반복 변경하지 않는다.

통과할 때만 새 전달물의 CPU/GPU·실제 C++ 연결과 기존 위치 PNG 보존을 새로 검사한다. 실패하면 연구 가중치와 결과를 보존하고 현재 v16-r1을 유지한다. 공개 TEST를 반복 활용한 연구이므로 독립 현장 성능으로 설명하지 않는다. 과거 부모 모델의 근접 자료 노출, 물리 촬영 그룹 미검증, 사람 검수 대기 전선 관계 라벨의 한계도 유지한다.
