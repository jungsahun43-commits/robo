# DACL 원본 19종 위치 보조 정답 준비

## 정답의 의미와 범위

기존 `data/facility-auxiliary-training/train.json`에 고정된 **DACL v2 TRAIN 전체 사진 6,225장**에서 원래 19종 폴리곤을 별도 위치 정답으로 만들었다. 원래 19종 사진 태그, 사진·주석 파일, 기존 7종 정답은 수정하지 않았다. **새 독립 사진은 0장**이며, 기존 주석에서 추가 학습 표현을 만든 것이다.

클래스 순서는 `AUX_CLASSES`와 같다. 동일 클래스의 폴리곤은 합집합으로 만들고, 서로 다른 클래스가 겹치면 각각의 이진 마스크에 모두 표시한다. 박락·공동·벌집 모양 결함·콘크리트 침식 등을 하나의 손상으로 합치거나, 한 클래스의 양성을 다른 클래스의 음성으로 바꾸지 않는다.

각 폴리곤을 기존 RGB 준비 사진의 실제 크기로 좌표 변환한 뒤, 기존 7종 생산자와 같은 `BOX 640×640 → 표시값 > 0 → 8×8 내 하나 이상 표시 → 80×80` 순서를 적용했다. 이는 거친 주석 영역의 셀 정답이며, 정밀한 재료 경계나 실제 결함 면적 측정값은 아니다.

## 미확인 처리

전체 사진의 해당 클래스에서만 배포자 주석의 폴리곤 밖·표시되지 않은 클래스 영역을 음성 셀로 취급한다. 이는 주석상 해당 클래스가 표시되지 않았다는 의미이며, 시설이 정상 또는 구조적으로 안전하다는 정답이 아니다. 다른 출처 및 모든 부분 사진은 이 19종 위치 정답에서 미확인으로 유지한다.

범위를 벗어난 좌표, 비정상·퇴화 폴리곤, 사진 태그와 래스터의 충돌이 있으면 **그 클래스 전체의 위치 정답을 미확인**으로 만들고 마스크를 0으로 비운다. 사진 태그는 그대로 남긴다.

- 위치 정답이 미확인인 클래스·사진 사례: **785개**.
- 미확인 위치 클래스가 하나 이상 있는 사진: **740장**. 사진 전체를 제외한 수는 아니다.
- 박락 위치가 미확인인 사진: **17장**. 원래 박락 사진 태그는 유지했다.
- 알려진 음성 사진 태그에는 양성 마스크 셀이 생성되지 않았다.

배포자 사진·주석의 이름과 TRAIN 분리, DACL v2, EXIF 방향을 적용한 원본 사진 크기와 주석 크기의 등록을 확인했다. 준비 전후 **원본 입력 파일 18,676개의 SHA256·크기·mtime**이 같음을 확인했다. 별도 준비 시간은 약 **1.84분**, CPU 작업자는 4개였다. 검증·시험 사진 또는 주석, 모델 예측은 읽지 않았고 학습은 수행하지 않았다.

## 파일과 고정 해시

| 파일 | SHA256 |
|---|---|
| 원래 사진 태그 `data/facility-auxiliary-training/train.json` | `53544bf83e1b32e3a7b8775c5f8348594359bf6e01eade1c8571242e758f4b61` |
| 신규 위치 명세 `data/facility-dense-auxiliary-training/train.json` | `8e83be3501104315a9b7ce941c6acb3b68d94e6c748edc31ed50af5f4fd810a7` |
| 공개 집계 `reports/facility-dense-auxiliary-data-audit.json` | `298983270e97ad03ca07237d96468894424c096a50cdf19d95edfd3b637b6a29` |
| 비공개 입력 보존 기록 `data/facility-dense-auxiliary-training/input-ledger.json` | `a7f8853f8d8e83f6e81f1d3cff68d9764e08e879580158e4de01b26671e0b6e3` |

신규 명세의 각 행은 원래 사진 순서를 유지하고 `image`, `image_sha256`, `mask`, `mask_sha256`, `targets`, `known`, `annotation`, `annotation_sha256`, `source`, `source_sha256` 등을 담는다. 마스크 NPZ는 `masks: uint8(19,80,80)`와 `known: uint8(19,)` 두 배열만 담는다. `known=0`인 클래스의 마스크 0을 음성으로 학습해서는 안 된다. 공개 집계의 `per_label_pixel_cells`는 80×80 셀의 알려진 양성·음성·미확인 수다.

준비 코드는 `scripts/prepare_facility_dense_auxiliary.py`, 집중 검증은 `tests/test_dense_auxiliary_data.py`다. 데이터 검증 **13개가 통과**했으며, 기존 7종 폴리곤 생산자와 같은 래스터 결과도 확인했다. 기존 출력은 덮어쓰지 않는다.

## 출처와 해석의 제한

[DACL toolkit](https://github.com/phiyodr/dacl10k-toolkit), [DACL 원 논문](https://arxiv.org/abs/2309.00460). 사용한 배포 자료는 **CC BY-NC 4.0**이며 원저자 인용과 비상업적 이용 조건을 준수해야 한다. 배포 데이터의 현재 19종 계약을 사용했다. 초기 논문 본문의 18종 설명과 달리 v2에는 `Cavity`가 추가됐다.

`Hollowareas`는 원저자의 타격 검사 결과를 표시한 분필 영역에 해당한다. 이 보조 학습으로 스마트폰 사진만으로 내부 손상을 진단한다고 주장할 수 없다. 위치 정답 준비는 성능 개선의 증거가 아니며, 이후 실제 학습과 기존 검증 기준으로 확인해야 한다.
