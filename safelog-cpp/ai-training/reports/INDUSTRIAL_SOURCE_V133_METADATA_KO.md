# v133 — Indian Footpath 원저자 metadata 선별

v132 최신 재개/Git/보호/host와 다음 문서를 읽었다. 실제 report/script/doc의 정확명칭·저자·논문/자료 DOI/URL 검색은 정상 미일치였고 경로/권한 실패가 아니었다. v8–v132 완료 작업을 재실행하지 않았다.

[Priti Chakurkar/Deepali Vora의 원논문](https://www.nature.com/articles/s41597-025-06207-x)은 Pune 보도의 RGB583·8구역·pixel 손상1/배경0·TRAIN411/VAL85/TEST87을 선언한다. annotation용1500×1000과 model용128×128 설명은 실제 배포 크기 검증이 아니다. 이름·값·수량이 명시돼 있다는 개선된 metadata 근거이며 파일 GT/unknown·역할/물리그룹·전체graph/최소 통과가 아니다. 보도 자료를 산업설비/부식·전체건강 또는 새 보도/중증도 과제로 자동 확대하지 않는다. 원논문 model·dualencoder/가공·중증도·점수를 가져오지 않는다.

[저자 Zenodo V2 record17154852](https://zenodo.org/records/17154852)는 ZIP 약4.5GB, 별도 README/CSV/LICENSE.txt와 배포자 MD5를 표시한다. fullZIP은 예산 밖이라 받지 않는다. 논문이 선언하는 data CC BY4.0과 논문 자체 CC BY-NC-ND4.0은 구별하며 실제 LICENSE 내용·제삼자 권리는 아직 읽지 않았다. 역할은 전부 보호/미확정이며 TEST87 파일 ID는 미검증이다.

웹 텍스트만 읽고 PDF/그림·archive/CSV/README/LICENSE·원사진/mask/annotation/code/model 파일을 열거나 로컬 취득하지 않았다. publisher cookie관련 query redirect에서도 공개 본문을 받았으며 로그인/cookie동의·우회0이다. 웹 traffic bytes는 미측정, 관찰메모는 고정 publisher원문/자료 checksum이 아니다. source pixels/QA/features/모델/gradient/optimizer0이다.

작은 실제 metadata·LICENSE·README 취득은 아래 별도 v134 정책/코드JSON 사전 일반push 뒤에만 한다. archive·이미지·GT·분리·pixel/학습 허가는 아니다. 기존 모든 원형·실패·역할/graph·모델을 보존한다.
