## 출처·라이선스 확인

저자 저장소 확인 리비전은 `80a8f17186fa5e273ccd1442b2c66f2a6b1196b7`이다. GitHub API license는 null이고 저장소 트리에는 별도 LICENSE가 없었다. 저자 제공 약6.45GB ZIP의 HTTP206 마지막4MiB로 파일 목록을 읽고, 정상 TRAIN에 해당하는 개별 파일만 범위 다운로드했다. 내려받은 파일은 로컬 헤더·크기·CRC32·SHA256을 검증했다. 외부 코드는 실행하지 않았다.

압축 파일 안에는 MVTec의 `license.txt`와 `readme.txt`가 있으며 원본 사진의 CC BY-NC-SA4.0 및 MVTec 저작권을 명시한다. **새로 추가한 저자 다각형 주석 자체의 별도 이용 허락 범위는 명시적으로 확인되지 않았다.** 후보 주석은 조사·검수 자료로 분리 보관하며, 신규 지도학습 정답이나 공개 배포 자료로 자동 승인하지 않는다. 사진 출처와 저자 주석 출처를 둘 다 남긴다.

확인한 원본 사진·다각형은 모델의 예측 결과에서 만든 라벨과 구분한다. 저자가 배포했다는 사실만으로 모든 윤곽·관계가 정확하거나 사람 검수가 완료됐다고 단정하지 않는다.

## 24장 선정과 원본 대조

선정 조건은 commit `37fb3c8`에서 다운로드 전에 고정했다. v13의 정상 publisher TRAIN 중 근접 묶음 감사 후 남은 **FIT199장만** 대상으로 `SHA256(loco-relation-review-v14:sourceID)` 순서의 처음24장을 선택했다. TEST 점수·모델 오탐·미탐을 보고 선정하지 않았다.

- 24장 모두 저자 ZIP의 PNG와 기존 로컬 사진의 파일 바이트 SHA256·RGB SHA256·1700×850 크기가 일치한다. 전체 미러 사진의 동등성을 확인한 것은 아니다.
- 24장의 appearance group proxy가 서로 다르다. v13의 정확 RGB·회전/반전 pHash≤2 연결 묶음 감사를 이어받았다. 물리 촬영 그룹이 검증됐다는 뜻은 아니다.
- 클램프 다각형 총4개 사진6장, 6개 사진10장, 10개 사진8장이다. 정상 구성에서 묶음당2·3·5개에 대응하는 후보다. 각 사진에 전선 다각형은 하나씩 있다.
- TEST·VAL·CAL 주석은 **추출·해석·검수에 사용하지 않았다**. ZIP 목록 확인용 범위 응답과 개별 정상 파일 다운로드를 구분한다.
- 부모 모델의 과거 근접 TRAIN 노출은 되돌리지 않았다.

## 검수 화면에서 하는 일

1. 클램프·전선의 저자 윤곽이 사진에 맞는지 확인한다. 오류나 가림이 있으면 ‘판단 불가·수정 필요’에 이유를 남긴다.
2. 클램프별 좌우 묶음을 확인한다. 기본 묶음은 다각형 중심의 2-means 자동 제안이며, 정상 정답으로 사전 승인하지 않는다.
3. 실제 보이는 양쪽 클램프 수·전선 수·색을 입력한다. 값은 빈 상태로 시작한다.
4. 전선과 연결부가 만나는 양 끝점을 사진에서 누르고, 사진 위→아래 순서의 연결된 클램프 번호를 입력한다. 이 번호는 사진상의 관찰 순서이며 물리 부품의 보편적 핀 번호나 모든 배선의 정상 규칙이 아니다. 순서를 확정하기 어려우면 판단 불가로 남긴다.
5. 확인 또는 판단 불가를 기록하고 JSON을 저장한다. 수정하면 기존 확인 상태는 초안으로 돌아가 다시 확인해야 한다.

자동 임시 저장·부분 JSON 저장·불러오기를 제공한다. 원본 사진 ID·사진/주석 SHA·묶음 지문이 맞지 않거나, 중복 사진·NaN·사진 밖 끝점·불완전 확인이 있으면 가져오기를 거부한다. ‘판단 불가’를 정상 라벨로 바꾸지 않는다. **확인한 관찰도 재검수 대기열일 뿐, 학습용 정답으로 자동 승인되지 않는다.**

## 검사와 한계

Python 무결성 검사5개와 Node 검증 검사5개를 통과했다. 실제24장 묶음 메타데이터에 대해 격리된 DOM 이벤트 대역 검사1개로 입력·좌표 변환·임시 저장 복구·편집 시 초안 전환·JSON 저장/불러오기를 검사했다. 이 검사는 시뮬레이션 입력이며 실제 사람 라벨 수로 세지 않았다. 그 JSON을 Python 가져오기까지 연결했으며 학습 정답 생성0·optimizer0·training_ready=false를 확인했다.

브라우저 도구가 `file:` 프로토콜을 보안 정책으로 차단해 실제 브라우저 화면·렌더링·사용자 다운로드 동작은 직접 검사하지 못했다. 우회 서버나 다른 브라우저 자동화로 그 차단을 우회하지 않았다. 이 제한은 도구 접근 제한이며 사용자 PC에서 HTML을 열어 사용하는 방법과는 별개다.

## 다음 지도학습의 진입 조건

24장 관찰의 독립 검수·윤곽 수정과 새 주석의 이용 범위를 확인한 뒤, 검증용 구성 라벨을 FIT와 분리해 확보한다. 그 다음 기존 공통 분석부에 물체·끝점·구성 분기를 추가하는 학습 프로토콜을 먼저 고정한다. 정상 구성 라벨만으로 새 실제 결함 데이터가 생겼다고 설명하지 않는다.

현재 연구 기준은 v13이다. 알려진 공개 TEST의 전선 연결부 미탐39.90%·오탐19.33%이며20% 미탐 목표는 아직 미달이다. 이번 자료 준비에서 성능 수치를 새로 측정하지 않았다. 독립 산업현장 성능이나 설비 내부 고장 판정은 검증되지 않았다.
