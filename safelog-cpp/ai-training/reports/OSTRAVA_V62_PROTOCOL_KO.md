# v62 실제 부식 위치 주석 학습 조건

자료 감사와 고정 FIT QA를 마친 v61 manifest를 그대로 사용한다. FIT 60장은 실제 부식 사진 58장과 주석상 전체 음성 사진 2장이다. VAL/CAL/원래 TEST는 각각 15장이다. 이번 학습은 정상 복원이나 합성 표시 학습이 아니라 **배포자의 실제 부식 마스크 정답**을 사용하는 지도 학습이다. 마스크 L 값 169도 `L>0`으로 양성 처리한다.

## 하나의 추가 분기

원본 전체 RGB를 bicubic 512×512로 변환하고 실제 마스크는 nearest 방식으로 같은 좌표에 변환한다. 별도 인코더 없이 기존 공유 인코더의 fine 24채널·low 40채널·high 960채널을 사용한다. FIT의 공간 특징만으로 각 채널 평균·모표준편차를 계산해 고정한다.

새 high 960→32, fine 24→16 projection과 88채널 융합 판별부를 학습한다. 3×3 convolution, GroupNorm, GELU를 사용하고 마지막 출력층은 0으로 초기화한다. 학습 파라미터는 100,593개다. 기존 v16 및 승인된 3개 InsPLAD 분기의 모든 tensor/buffer/metadata와 기본 출력 계약은 보존한다.

새 코드·JSON·자료 SHA를 commit/push한 뒤만 새로운 특징·gradient를 계산한다. 기존 실패 후보의 학습된 분기를 초기값으로 복사하지 않는다.

## 학습과 선택

- FIT 묶음 균형 복원 추출, 배치 4, 30 epoch×64=실제 optimizer 1,920회, seed 6262.
- AdamW 0.0003, weight decay 0.01, cosine 최소 0.000001, gradient clip 5, FP32, TF32 비활성화.
- 사진별로 존재하는 전경/배경의 BCE 평균을 균형 있게 합하고 soft Dice loss를 더한다. 전체 음성 사진은 배경 BCE만 사용한다.
- VAL의 사진별 손실을 묶음별로 평균해 초기 epoch 0 및 매 완료 epoch와 비교한다. 최초 엄격 최소값을 선택하며, epoch 0이면 CAL/TEST를 새로 평가하지 않고 제외한다.
- 증강·GT 기반 crop·추가 자료/날짜 입력은 없다. 1,920회 추출 반복을 새로운 실제 손상 사진 수로 세지 않는다.

## 보정과 원래 시험

선택 모델의 512 확률 지도를 bilinear 방식으로 원래 2048×2048에 복원해 원래 마스크와 비교한다. 정답을 bilinear로 바꾸지 않는다.

CAL 15장의 native pixel 오탐·미탐 평균을 고정 후보 `0.05,0.10,…,0.95`에서 최소화한다. 동률이면 먼저 나온 낮은 임계값을 선택한다. 19개 수치와 선택값을 저장한 뒤 원래 TEST 15장을 **한 번** 평가한다. TEST 수치에 맞춘 임계값·선택 조건 변경은 하지 않는다.

연구용 위치 판별 기준은 학습 epoch>0, 실제 TEST 양성 5장 이상·묶음 3개 이상, native pixel 오탐·미탐 각각 20% 이하, IoU 50% 이상이다. 통과한 경우에만 새 원본 15장의 CPU/GPU와 저장된 GPU 지도 사이 수치 호환성을 별도로 검사한다. 사전 허용치는 확률 지도 atol/rtol 각 0.002 및 원본 좌표 pixel 판정 차이 0.1% 이하다. 불일치를 보존하며 임계값을 다시 맞추지 않는다.

**원래 TEST에는 정상 전체 사진이 0장이고 양성도 15장이다.** 이 연구 기준을 통과해도 앱 전체 사진의 오탐·미탐 20% 통과를 의미하지 않는다. 기존 InsPLAD·브래킷·튜브 개선이나 다른 장비의 위치 성능도 이번 시험으로 주장하지 않는다. 기본 앱·alias·위치 지도·최신 승인 overlay는 자동 교체하지 않는다. 실제 앱 반영에는 별도 사전 고정된 대상 설비 평가와 패키지 검사가 필요하다.

## 저장과 출처

FP16 특징과 512 정답 캐시는 전체 105장에 대해 400MiB 미만, 다른 새 기록과 delta를 포함해 450MiB 미만으로 계획한다. 원본 ZIP을 유지하고 full parent를 복제하거나 전체 확장하지 않는다. 실제 optimizer 장부, epoch별 기록, 오류 및 부분 가중치를 보존한다.

Matěj Frič, [Zenodo v2](https://zenodo.org/records/11235637), DOI 10.5281/zenodo.11235637, 데이터 CC BY 4.0의 인용·출처·버전·변경 표시를 유지한다. 물리 부품·촬영 현장 독립성은 확인되지 않았고, 주석은 표면 외관이며 부식 깊이·강도나 설비의 전체 정상 작동 정답이 아니다.
