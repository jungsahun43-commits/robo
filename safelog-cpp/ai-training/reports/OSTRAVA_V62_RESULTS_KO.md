# v62 실제 산업 부식 위치 학습 결과

`6e78daf`에 조건·코드·자료 SHA를 먼저 push한 뒤 실제 30 epoch×64=**1,920회 optimizer 업데이트**를 완료했다. 학습 사진은 부식 마스크가 있는 58장과 주석상 전체 음성 2장이다. 공통 인코더와 기존 승인 3개 분기는 고정하고 새 위치 판별부 100,593개 파라미터만 학습했다.

초기 VAL 손실 1.41569에서 12 epoch/768회 가중치의 0.388024로 낮아져 그 가중치를 선택했다. 마지막 epoch의 0.440148 가중치는 선택하지 않았다. CAL 15장으로 고정 후보 임계값 중 0.20을 선택·저장하고 원래 TEST 15장을 한 번 평가했다.

## 원본 2048×2048 좌표의 픽셀 지표

| 지표 | 결과 |
|---|---:|
| 실제 부식 픽셀 미탐 | 491,418/13,226,512 = **3.72%** |
| 주석상 배경 픽셀 오탐 | 4,760,152/49,688,048 = **9.58%** |
| 전체 픽셀 IoU | **70.80%** |
| 전체 픽셀 Dice | 82.91% |
| 사진별 IoU 평균 | 71.68% |

사전 등록한 **자료 내 위치 연구 기준**을 통과했다. 이 값들은 **사진 전체 오탐·미탐률이 아니다.** TEST에는 정상 전체 사진이 없고 양성도 15장으로 20장에 못 미친다. 이 자료만으로 앱의 사진 판별 20% 통과를 선언하지 않았다.

사진별 편차도 크다. test/02·04·08의 배경 픽셀 오탐은 각각 53.45%·47.73%·28.38%이고 test/07의 부식 픽셀 미탐은 51.02%다. 평균만으로 모든 사진의 오차가 20% 이내라고 설명하지 않는다. TEST 내용을 다시 골라 보거나 정답·임계값을 고치지 않았다. 출처 간 또는 현장 간 독립 성능도 확인되지 않았다.

## 별도 장치 수치 비교

원본 15장을 CPU와 새 GPU 입력으로 각각 다시 처리해 저장된 GPU 캐시 지도와 비교했다. 사전 atol/rtol 각 0.002와 pixel 판정 차이 0.1% 조건을 통과했다.

- CPU 최대 512 확률 차이 0.000149399, 원본 좌표 판정 차이 99/62,914,560픽셀.
- 새 GPU 최대 확률 차이 0.000136256, 판정 차이 60/62,914,560픽셀.

모든 픽셀이 완전히 같은 검사는 아니며, APK·Android 속도·새 서버/C++·설치 패키지 검사는 0회다. 이전 장치·C++ 검사 수를 이번 수에 더하지 않았다.

## 보존

연구 delta `runs/industrial-ostrava-rust-mask-v62/trained/final-delta.pt` SHA256:
`26c26bc5739930f153d1553b9b22840f4e83ba925cddeca5f46eee4f9f25a01b`.

기본 v16과 승인 3개 분기의 tensor/buffer/metadata를 정확 비교했고 디스크 delta 복원도 일치했다. 기존 Python 760개 SHA, 보호 파일 329,428개 크기·수정시각, 실제 업데이트 장부와 새 캐시 SHA를 확인했다. 보호 원본 전체 SHA를 모두 다시 계산한 검사는 아니다. 캐시는 전체 105장에 대해 350,974,132바이트이며 첫 FIT 4개의 일반 인코더 비교 입력은 새로운 자연 사진 4장이 아니다.

이 delta는 원래 v16 부모가 필요한 연구 차이본이다. 기본 앱과 기존 승인 overlay는 자동 교체하지 않았다. 기존 브래킷·튜브·InsPLAD 사진 성능을 이번 결과로 개선했다고 주장하지 않는다. 추적한 일부 연구 optimizer 합은 53,200회이며 실패 포함 부분합으로 전체 역사 총량이 아니다.

다음에는 현재 TEST와 분리된 기존 정상 CAL만으로 **사전에 고정한 보강 후보 하나**를 검증한다. 기존 상부 연결고리 부식 판정과 새 실제 부식 증거가 함께 있는 경우를 확인하는 연구이며, 원래 경고를 자동 해제하거나 새 지도를 해당 설비의 검증된 정답 위치로 사용하지 않는다.
