# 4차 보강 계획: 실제 댐 표면 사진

## 출처와 정답

- [DamSegment V1](https://data.mendeley.com/datasets/z5z6gtt5t4/1), DOI 10.17632/z5z6gtt5t4.1, CC BY 4.0. 저자 공개 API의 세 ZIP SHA256을 검증한다.
- [저자 논문](https://doi.org/10.1016/j.dib.2026.112671) 4.4에 따르면 분류 폴더 Crack은 균열 또는 박락의 합성 분류이다. **이 1,000개 파일을 균열 단독 양성으로 사용하지 않는다.**
- 논문 Fig.5/8의 숫자 주석과 표면 형상을 확인했다: 0은 선형 균열, 1은 면적형 박락이다. JSON/YOLO/색상 마스크의 클래스 존재 여부를 교차 확인한다. **다운로드 파일의 RGB 마스크는 빨강=0, 파랑=1이다.** 논문 Fig.5의 예시 팔레트와 실제 파일이 반대이므로 예시 색을 그대로 정답 번호로 쓰지 않는다. E(10) 원본·마스크·JSON의 선형 균열로 매핑을 확인했다.
- Non-Crack은 논문에서 intact concrete로 정의한다. 균열·박락 두 항목의 음성으로만 사용한다. 물기 등 나머지 다섯 항목은 모든 추가 사진에서 -1(미확인)이다.
- 탐지와 분할은 같은 1,500개 패치를 공유한다. 실제 다운로드한 JPG/PNG의 픽셀 중복을 제거하며 파일 수와 고유 패치 수를 구분한다.

## 분리와 실험 조건

- 기존 DACL 학습/검증/시험 7,910개 원본 픽셀과 정확히 겹치는 자료는 제외한다.
- 같은 패치 ID의 다른 확장자와 dHash 64bit 거리 6 이하 사진을 하나의 연결 그룹으로 묶는다. 그룹 ID SHA256로 약 80% 학습/20% 추가 시험에 고정 분리한다.
- 원본 촬영 ID가 공개되지 않으므로 이 방법이 모든 인접 패치의 장면 누수를 없앴다고 주장하지 않는다. 단일 댐 패치 평가이며 독립된 현장/시설 평가가 아니다.
- 기존 학습 6,225장을 모두 유지한다. 1차 best.pt에서 512px, batch12, 최대16epoch, patience5, seed42로 시작한다. 실제 추가 사진 손실 가중치 0.3, 미확인 항목은 손실에서 제외한다.
- 체크포인트는 기존 검증 710장의 macro AP로 고른다. 추가 시험 사진은 최적화·체크포인트 선택에 사용하지 않는다.

## 후보와 교체 기준

새 모델은 균열·박락 두 항목만 적용 후보이다. 다른 항목은 기존 모델을 사용한다.
검증에서 기존 결합 모델보다 오탐률이 증가하지 않고 미탐률이 최소 2%p 감소한 항목만 선택한다.
임계값은 0.05~0.99, 0.01 간격이며 동률은 높은 임계값을 사용한다.
모델·항목·임계값을 별도 후보 프로필로 고정한 후 DACL 시험 975장 및 추가 시험 패치를 평가한다.
**각 평가의 확인 가능한 항목마다 FP와 FN이 증가하지 않고, DACL 시험에서 적어도 하나가 감소해야 기본 모델을 교체한다.**
추가 시험에서 양성/음성이 없는 항목의 비율은 미정으로 보고하며 임의의 0%를 표시하지 않는다.
기준 미달이면 기본 모델 v2를 유지한다. 시험 결과를 보고 임계값을 다시 선택하지 않는다.

## 앱 연결

기존 C++ 앱의 세 API와 일곱 시설 항목을 유지한다. 사진 단위 보조 의견은 위치 없는 box=null이다.
새 모델은 자동 보고서의 안전관리자 검토를 보조하며 시설 안전이나 누수 원인을 확정하지 않는다.
데이터 원본은 Git/모델 전달 ZIP에 넣지 않는다. 출처·변경 내용·사용 조건은 보고서에 남긴다.
