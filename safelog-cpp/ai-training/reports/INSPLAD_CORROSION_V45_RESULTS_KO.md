# 상부 금속 연결고리 부식 분류: 실제 학습 및 연결 검사

## 이번에 완료한 기능

고분자 애자 상부 금속 연결고리를 자른 RGB 사진에서 원저자의 정상/부식 조건을 분류하는 연구 기능을 추가했다. 기존 공통 encoder와 모든 기존 설비 분기의 가중치·버퍼·메타데이터를 보존하고, 같은 encoder의 특징을 읽는 분류부만 학습했다. 한 모델의 추가 분류부를 원본 모델에 묶인 작은 차이 파일로 저장한다.

전력설비의 해당 부품 외관에 한정한다. 일반 금속·컨베이어·내부 고장·전기 건강·부품 전체의 안전을 판정하는 모델로 확대하지 않는다. 결함 위치 정답은 없어 새 위치 지도를 제공하지 않는다. 기존 검정 브래킷/튜브의 미탐이 개선됐다고 측정하지 않았다.

## 자료와 실제 학습

- InsPLAD Mendeley V1, DOI 10.17632/5n3fjgvfyz.1. 원저자 논문 DOI 10.1080/01431161.2023.2283900. 배포본 CC BY-NC 3.0, 비상업 학술 연구·원저자/출처/버전/변경 표시를 유지한다.
- 모든 자산의 원저자 VAL 6,417장을 평가로 예약하고, 프레임·정확 RGB·8방향 pHash 근접 연결을 학습에서 제외했다. 기존 평가 사진 8,995장과 직접 근접 후보는 0개였다.
- FIT 정상506/부식51, 내부 VAL 정상109/부식11, CAL 정상108/부식11, 원래 평가 정상31/부식33장이다. 변형 파일을 독립 원본으로 세지 않았다. 고유 물리 부품 수는 확인되지 않았다.
- 조건/코드는 53f4183에 먼저 commit/push했다. 실제 **30epoch × 64 = optimizer 1,920회**를 수행했고 전체 장부를 보존했다. 새 실제 부식 FIT 사진은 51장이다.
- 같은 encoder의 fine24/low40/high960 특징을 mean/popstd/max 3,072차원으로 읽어 FIT만으로 정규화했다. 새 3072→128→1 분류부 393,473개 파라미터만 AdamW로 학습했다. dense 특징 캐시나 새 encoder는 추가하지 않았다.
- 내부 검증 macro label/group BCE는 초기 0.693147→최저 0.297645였다. **4epoch/256회 시점의 가중치**를 선택했다. 30epoch 전체의 마지막 가중치로 바꿔 평가하지 않았다.
- 정상 CAL108장의 85% 순서 통계량 rank93, cut `0.015575625002384186`을 먼저 저장한 뒤 원래 평가64장을 한 번 평가했다. 이 sigmoid 점수는 고장 확률이 아니다.

## 고정 평가 결과

| 지표 | 결과 |
|---|---:|
| 오탐 | 6 / 정상31 = **19.35%** |
| 미탐 | 0 / 부식33 = **0%** |
| 사진 AUROC | 0.999022 |
| 정상/부식 프레임·근접 연결묶음 | 31 / 33 |

사전의 두 사진 지표 20% 이하 조건은 이 공개 출처의 점 추정치로 통과했다. 독립 사진을 가정한 Wilson 95% 참고 구간은 오탐9.19~36.28%, 미탐0~10.43%다. 이 구간은 같은 물리 부품의 반복 촬영 상관을 보정한 값이 아니다.

**촬영 시기와 라벨이 크게 연관된다.** 원래 평가에서 두 라벨이 모두 있는 날짜는 1개뿐이고, 원래 TRAIN의 제외 후 원본 후보에서는 3개다. 배경·조명·촬영 시기의 단서를 배웠을 가능성을 분리해 입증하지 못했다. 서로 다른 프레임의 같은 부품 가능성도 남아 있다. 현장 미탐0% 보장, 독립 현장 성능, 기존 설비 전체의 오차율로 발표하지 않는다.

## 새 ZIP의 실제 검증과 복구

첫 v46 검사는 CPU/GPU64장과 기존 15개 alias까지 통과했으나, 기존 C++ 실행 파일의 허용 목록에 새 task가 없어 거절됐다. 그 실패 ZIP·로그·기록을 보존했다. 학습이나 임계값을 변경하지 않았다.

`http_ai_safety_analyzer.cpp`의 허용 목록에 `insplad_upper_shackle_rust`를 추가하고, 새 항목의 요청 전달 테스트를 추가했다. 별도 폴더에서 다시 빌드했다. Qt 테스트 함수10개(init/cleanup 포함, 실제 테스트8개)가 모두 통과했다.

수정본 v45-r1 ZIP에서 다음을 새로 수행했다.

- 원본 RGB 평가64장: 새 CPU/새 GPU/기존 캐시 GPU 판정 완전 일치. CPU-GPU 최대 점수차 0.0000234246. 고정 허용오차와 같은 판정 조건을 통과했다.
- CPU 기존15 alias의 classResults·정책 SHA가 원래 부모와 정확히 같았고, 기존 primary/auxiliary PNG 문자열 **24개**가 정확히 같았다.
- 새 부식 alias와 명시적인 equipment_surface/category 경로를 확인했다. 미지원 일반 task·서로 다른 category는 422로 거절됐다.
- 새 C++ 실행 파일에서 KS2·볼스크루·LOCO·검정 브래킷·새 부식 항목 각3개, **이번 수정 ZIP에서 실제15개 작업**을 통과했다. 동일 사진을 조치 전후로 넣으면 해결됐다고 판정하지 않았다. 이전 실패 검사 및 과거 C++ 횟수를 합산하지 않았다.
- ZIP CRC·개별 파일 SHA를 확인했고 검사용 서버를 종료했다. 새 pip 설치나 Android APK 빌드는 검사하지 않았다.
