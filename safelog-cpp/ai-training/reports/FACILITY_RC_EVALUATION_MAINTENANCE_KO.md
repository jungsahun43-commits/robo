# RC 보강 모델의 전체 검증 평가 보완

2026-10-08. 학습을 마친 RC 보강 모델에서 별도 평가 도구의 자료 연결 누락을 확인하고, 세 자료를 모두 포함해 최종 보고를 완성했습니다.

## 무엇이 누락됐나

실제6epoch 학습은 매 epoch DACL·Dam·CODEBRIM의 공개 검증 자료를 모두 평가했습니다. 그런데 이 후보의 `TRAINING.json`에는 이전 별도 평가 도구가 읽는 `additional_validation` 연결 필드가 없었습니다.

그 결과 최초 별도 평가에는 DACL710개와 Dam424개만 포함됐고, 세 자료가 있어야 하는 비교 보고서 생성 단계가 실패했습니다. 학습이나 가중치가 실패한 것이 아니라 학습 후 보고 경로에 CODEBRIM611개를 연결하지 못한 문제였습니다.

## 어떻게 보완했나

새 도구 `scripts/evaluate_rc_positive_complete.py`는 완료된 대조군에 기록된 원래 CODEBRIM VAL 파일과 SHA256을 확인한 뒤, 읽기 시점의 메모리 복사본에만 연결 정보를 넣습니다. 원본 `TRAINING.json`, 가중치, 정답, 동결 소스123개는 수정하지 않았습니다.

이전 두 자료 평가의 선택 결과·작은 손상 감사·공개 집계, 총4개 파일을 로컬 `original-incomplete-two-domain-post-eval` 폴더에 원래 바이트로 보존했습니다. 그 뒤 이미 선언한 grid1 조건으로 전체 평가와 작은 손상 집계를 만들었습니다. 새 학습이나 source-TEST 추론은 없습니다.

| 최종 검증 자료 | 사진·패치 수 |
|---|---:|
| DACL | 710 |
| Dam | 424 |
| CODEBRIM | 611 |
| 합계 | 1,745 |

1,745개는 저장된 검증 사진·패치 행 수입니다. 서로 독립적인 산업 현장 사진1,745장이라는 뜻은 아닙니다.

## 실제 확인한 내용

- 세 자료 각각의 실제 학습 중 저장된7종 확률과 최종 grid1 캐시를 원소 단위로 비교했고 **모든 값이 정확히 같습니다**.
- 선택된6epoch의 원본 미탐·오탐 평가와 최종 전체 선택 결과도 정확히 같습니다.
- 보존한 이전 두 자료 결과의 균열·박락 임계값과 DACL·Dam의 모든 평가값은 최종 결과와 같습니다. 별도의 보완 전 확률 파일 복사본은 없으므로, 확률은 실제 학습 중 보존된 값과의 일치로 확인했습니다.
- 이전4개 집계 파일의 SHA256은 보완 도구가 남긴 보존 해시와 같습니다. 실제 학습 기록과 완료 가중치의 해시도 일치합니다.
- 기존 기술 검증의 집중 코드 테스트26개가 통과했습니다. 연결 정보 보완 도구의 테스트2개는 별도 검사입니다. 이번 확률 대조는 새 코드 테스트 수나 학습량으로 합산하지 않습니다.

최초 백그라운드 실행의 `report: failed` 상태는 당시 실패를 나타내는 과거 기록으로 유지했습니다. 최종 완료 여부는 [전체 비교 집계](facility-rc-positive-study-comparison.json)와 [통과한 기술 검증](facility-rc-positive-study-verification.json)으로 확인합니다. 별도의 성공 상태 파일을 만들어 과거 실패를 덮어쓰지 않았습니다.

확률·선택 epoch·보존 파일 해시 대조는 [학습 후 평가 확인 기록](facility-rc-post-evaluation-review.json)에 집계로 남겼습니다. 개별 사진의 확률이나 정답을 이 공개 기록에 넣지 않았습니다.

## 성능 결론

| 지표 | 기존 저학습률 대조군 | 새 RC 보강 모델 |
|---|---:|---:|
| 균열·박락 최대 미탐률/오탐률 | 22.0207253886% | 22.2222222222% |
| 작은 DACL 손상 미탐 사례 합계 | 70건 | 70건 |
| DACL 노출 철근 AP | 0.7129187558 | 0.7131089393 |

최대 오류는 대조군보다 **0.2015퍼센트포인트 증가**했습니다. 철근 AP의 작은 변화는 순위 지표의 변화이며 오탐률이나 미탐률 감소를 뜻하지 않습니다. 작은 손상 미탐 감소도 확인하지 못했습니다. 연구 후보 기준과 항목별5% 미만 목표는 미달이며 기본 앱 모델은 유지합니다.

이번 신규 모델은 **6epoch, 약16.43분** 학습했습니다. 누적 기록은 완료된 모델 학습236epoch와 이전 중단 실행 기록2epoch를 합한238epoch입니다. 실패한 최초 사전 점검과 통과한 FP32 재점검의 임시 optimizer 업데이트2회는 학습 epoch에 포함하지 않습니다. 그 경위는 [사전 점검 유지보수 기록](FACILITY_RC_PREFLIGHT_MAINTENANCE_KO.md)에 있습니다.

새 자료와 양성 위치 손실을 함께 바꾼 비교입니다. 동일한 공개 VAL을 반복한 연구 결과이며 새로운 산업체 현장 성능이나5% 보장을 입증하지 않습니다.
