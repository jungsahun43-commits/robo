# v40 정상 문맥 복원 학습 결과 — 반영 제외

데이터 감사 v39를 통과한 동일 분리에서, 사전 commit `12e945c` 이후 **30epoch × 64 = 실제 optimizer 1,920회**를 완료했다. 정상 FIT 113장을 원본/H/V/HV로 각각 추출한 452개 입력과 정상 검증 26장을 사용했다. 증강 추출 수를 새 자연 사진 수로 세지 않으며, 실제 이상 FIT 정답은 0개다.

기존 공통 encoder와 모든 기존 분기는 고정했고 새 정상 문맥 복원부만 갱신했다. 정상 검증 MSE는 초기 0.675173 → 0.154567로 감소해 30epoch/1,920회 가중치를 선택했다. 이 손실 감소가 결함 검출 개선을 보증하지 않는다.

정상 CAL 25장의 사전 85% 순서통계량(rank23) 기준 0.280458을 저장한 뒤 원래 TEST 140장을 한 번 평가했다.

| 지표 | 결과 |
|---|---:|
| 사진 오탐 | 3/49 = 6.12% |
| 사진 미탐 | 63/91 = 69.23% |
| AUROC | 0.64745 |
| 새 API/C++/ZIP 검사·출시 | 0 |

오탐·미탐 모두 20% 이하라는 사전 조건을 충족하지 못해 **후보를 제외했다**. 낮은 오탐만 골라 반영하지 않았고 기존 v16-r1 모델/전달물을 유지한다. 검정 브래킷·튜브 전이는 평가하지 않았다. source pixel mask가 없으므로 4×4 복원 지도를 검증된 손상 위치로 표시하지 않는다. 공개 TEST를 본 개발 결과이며 독립 현장 성능이 아니다.

실제 optimizer 장부 1,920줄, 기존 부모 전체 tensor/buffer/metadata 정확 보존, 새 delta 직렬화 후 복원 정확 일치를 확인했다. 기존 Python 701개 SHA와 보호 315,319개 파일의 크기/수정시각을 확인했다. 보호 원본 전체의 내용 SHA를 모두 재계산한 것은 아니다. 런타임 오류는 없었다.

연구 차이본은 부모 모델이 필요하며 단독 앱 모델이 아니다. SHA256 `a3d48600bf17351054278d6e515fe4ebb7850c993ed42529c4220ea0d2c1beb0`, 1,649,401바이트. 마지막 가중치·진행 가중치·모든 로그와 실패한 후보를 보존한다. 추적한 일부 연구의 optimizer 합은 실패 포함 41,680회(이전 39,760+이번 1,920)이며 전체 역사 학습 총량으로 설명하지 않는다.

다음 v41은 같은 자료에서 더 세밀한 지역 특징의 **정상 참조 등록** 후보 하나다. 별도 사전 프로토콜을 고정하며 optimizer는 0회다. v40의 임계값을 변경하거나 TEST 점수가 좋아질 때까지 반복 조정하지 않는다.
