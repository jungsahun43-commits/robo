## 기존 이력과 새 원저자 근거

실제 `ai-training/reports`, `ai-training/scripts`, `safelog-cpp/docs`에서 후보 이름을 먼저 검색했다. CUBIT-Seg는 기존 data 권리/접근 보류 기록이 있어 재조사하지 않았다. 이후 새 정확제목/URL과 확인된 DOI·저자를 검색한 결과는 정상 exit1(미일치)이었다. 다른 자동차/보도 자료의 정확명칭도 이력 검색에 포함됐지만 별도 검토 단계로 세거나 외부 page를 열지 않았다.

[공식 publisher 색인](https://www.sciencedirect.com/science/article/pii/S1093968726031580)과 [Sal Saad Al Deen Taher의 업로드 HTML 본문](https://www.researchgate.net/publication/411644051_A_Two-Level_Semantic_Segmentation_Framework_for_Visual_Corrosion_Pattern_Assessment_in_Steel_Bridges)을 확인했다. 논문은 *A Two-Level Semantic Segmentation Framework for Visual Corrosion Pattern Assessment in Steel Bridges*, Sal Saad Al Deen Taher/Ji Dang, DOI10.1016/j.cacaie.2026.100173, 2026-08-05 online이다. 업로드 날짜와 논문 날짜는 촬영일이나 data revision/checksum이 아니다.

연구는 일본 강교 점검 현장 이미지의 부식 영역과 시각적 부식 유형을 pixel 단위로 주석했다고 설명한다. binary1960과 유형1738은 저자 선언이며, 후자는 앞 collection의 부분집합으로 설명된다. 수량을 더하거나 확보·검증 자연사진/독립부품·고유 TRAIN 수로 세지 않는다. 실제 data/native GT·background/unknown·RGB/좌표·원분리·촬영물리그룹·전graph·최소는 미검증이다. 분류/bbox-only 또는 mask 부재로 오인해 제외하지 않는다.

## 요청형 접근과 보류

공식 색인과 업로드 본문의 Data availability는 **요청하면 자료를 제공**한다고 명시한다. 따라서 취득 전 보류했다. 논문의 CC BY4.0은 논문 조건이며 dataset 고유 이용허가·원사진/제삼자 권리와 구별한다. 공개 release/file 목록·bytes/checksum·작은 익명 선택접근/임시량·실제예산을 확인하거나 data 권한을 얻은 것은 아니다. 요청 안내를 자동연락·동의/PII 대리제출의 승인으로 해석하지 않는다.

저자의 감사·분리·모델 결과를 이번 source의 실제 파일 감사나 SafeLog 성능/새 protocol로 채택하지 않았다. 시각 유형을 실제 부식 메커니즘·잔존내력/전체건강으로 확대하지 않는다. 새 명확한 저자 public data release/권리·접근 근거 없이 같은 논문/업로드 page·검색·PDF/저장소를 반복하지 않는다. 요청형 안내가 모든 익명 접근의 영구 불가나 유효 GT 부재를 증명하는 것은 아니다.
