# 다음 자료 후보: 구조 금속 표면의 실제 위치 주석

v40/v41 모두 제외한 뒤 새 모델 실험을 추가로 돌리지 않았다. 다음은 **실제 TRAIN 손상 위치가 표시된 자료**를 확보할 수 있는지부터 확인한다. 단순히 정상 자료의 학습 회차를 늘리거나 이미 본 TEST 임계값을 반복 변경하지 않는다.

## 원저자 MSDD 후보의 확인 상태

[원저자 논문](https://www.nature.com/articles/s41597-025-04454-6)은 복잡한 금속 부품의 표면 결함 8종과 위치 주석, 다각도 조명 원본 및 혼합 의사색 영상을 설명한다. 입력 방식이 일반 스마트폰 RGB 사진과 다르므로 이 자료의 결과를 곧바로 앱의 현장 성능으로 확대하지 않는다. 논문이나 코드의 라이선스를 데이터 라이선스로 대체하지 않는다.

[데이터 DOI](https://doi.org/10.57760/sciencedb.10794)와 [DataCite 공식 메타데이터](https://api.datacite.org/dois/10.57760/sciencedb.10794)를 직접 확인했다.

- 데이터명: Metal Surface Defect Dataset, V1, Science Data Bank, 2024.
- DOI가 연결한 실제 공개 페이지: `https://www.scidb.cn/detail?dataSetId=3d739ddb4bdc439a9bf7ef550cae48d8`.
- DataCite 데이터 이용조건: **CC BY 4.0**. 다른 기존 자료의 조건은 그대로 유지한다.
- 등록 용량: **9,785,811,363바이트, 1파일**. 현재 C: 여유 약 4.0GB보다 크다. 전체 자료를 내려받거나 기존 자료를 삭제하지 않았다.
- 현재 원본 사진·주석 파일·분리 목록·픽셀 중복·새 특징·학습·optimizer: 모두 미검사/0이다. 받은 것은 DOI 페이지·공식 메타데이터·원저자 코드 저장소 설명의 텍스트뿐이다. 원저자 코드를 실행하지 않았다.

로컬 메타데이터는 `data/industrial-structured-metal-v42-source`에 보존한다. DataCite 응답 SHA256 `f1f8567a293e7100eb0d8d68fbca3e0dbf225c5dd8715cda99bd70ddbf73407c`, DOI 최종 HTML `2bd04e3bca640dd80a9a6510c9a16532bdbcb3cd2570af34c596917528a71453`는 로컬 무결성 값이다.

## 바로 이어갈 확인

1. 원저자 공개 페이지에서 파일 이름·형식·실제 공개 다운로드 방식·체크섬·개별 파일 접근 여부를 확인한다. 로그인·접근 동의·개인정보 제출이 필요하면 자동으로 대신 제출하지 않는다. URL이나 파일 ID를 추측해 자료를 확보하지 않는다.
2. 전체 다운로드는 용량상 실행하지 않는다. 공개적으로 제공된 작은 원본 묶음이나 합법적인 선택 접근이 있으면 **원본/주석의 대응과 이용조건이 유지되는지**부터 확인한다. HTTP range/부분 파일 접근도 실제 지원 여부와 무결성, 임시 저장량을 먼저 확인한다. 그 방식이 가능하다고 아직 주장하지 않는다.
3. 실제 단일 조명 원본과 정확한 주석 좌표가 있는지, 같은 물리 부품의 여러 조명/크롭을 연결할 식별자가 있는지 확인한다. 의사색 영상을 일반 RGB로 표시하거나 여러 조명을 새 독립 부품으로 세지 않는다. 상자 정답을 실제 pixel mask로 바꾸지 않는다.
4. 자료를 확보할 수 있는 경우에만 이미지 열람 전에 원저자 TEST 예약, 물리/촬영 그룹·RGB/8방향 pHash2·기존 TEST 중복 제외, FIT/VAL/CAL 최소조건과 고정 배정 규칙을 선언한다. 본 자료의 TEST나 기존 TEST를 TRAIN으로 옮기지 않는다.
5. 이후 한 공통 encoder의 새 위치 분기 후보 **하나**를 구조·초기값·실제 정답 범위·학습 회차·VAL 선택·CAL·채택 조건으로 고정하고 commit/push한 뒤 학습한다. 아직 이 학습 프로토콜은 미확정이다.

다른 공개 후보도 확인했으나 이번 학습 자료로 사용하지 않았다. [DeepPCB 원저자](https://github.com/tangsanli5201/DeepPCB)는 연구 용도와 인공적으로 추가한 손상도 포함된다고 명시하므로 전체를 자연 결함으로 세지 않는다. [NEU 원저자 페이지](https://faculty.neu.edu.cn/songkc/en/zdylm/263265/)에서 데이터/상자 주석/인용 정보는 확인했지만 이번 확인으로 별도 재배포·이용 라이선스를 확정하지 않았다. 기존 NEU-micro 사용 범위를 이 자료에 자동으로 확대하지 않는다.

기존 앱 모델·역할4 v16-r1 ZIP은 그대로다. v14 관계 24장 사람 검수와 Real-IAD/VISION 접근 동의, SD-saliency 이용범위 등 이전 대기 조건도 유지한다. 이 메타데이터 확인은 모델 성능 개선이나 새 데이터 학습 완료가 아니다.
