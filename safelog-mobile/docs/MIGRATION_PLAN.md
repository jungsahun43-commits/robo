# 이전 현황과 순서

| 단계 | 현황 |
|---|---|
| 1. 브랜치 분석 | 원격 6개 헤드, 변경 구조와 주요 계약, 병합 모의 검사. 분석 범위와 경로는 BRANCH_ANALYSIS 참고. |
| 2. UI | Expo Router 9개 화면과 역할별 접근 적용. QML 화면의 기능·입력·상태를 스마트폰 세로 화면에 배치. |
| 3. 기능 | 시연 인증, 사진 입력, 메모리 작업 흐름, Mock 위험·비교 검토, 사진 포함 보고서 미리보기와 내보내기 구현. 검증 범위는 TEST_REPORT 참고. |
| 4. 설계 | 원본 SQLite 관계와 실제 AI HTTP 계약 확인. DB·사진의 영속화, 운영 인증, AI 배포는 결정 대기. |

1. Android 및 iOS에서 카메라·갤러리 권한, 원본 사진 포맷별 PDF, 공유 취소 및 접근 제어를 장치별로 확인한다.
2. 오프라인과 다중 사용자 요구를 확정하고 SQLite 또는 서버 어댑터, 사진 수명, 데이터 이관을 구현한다.
3. 로그인용 ID와 Profile ID, 자격 증명 이전, 계정 관리 권한을 확정하고 운영 API에 연결한다.
4. AI 모델·프로필·런타임과 현장 데이터 평가 기준을 확정하고 서버 어댑터를 연결한다.
5. 장치 회전·Activity/프로세스 종료 시 사진 선택 복원과 기록 복구를 영속 저장과 함께 구현한다.

시연에는 장치 재시작 이후 기록 복구, 여러 기기 동기화, 계정 발급·비밀번호 변경, Qt의 개발용 이미지 생성, 운영 모델 연결이 포함되지 않는다.
