# 전체 점검 항목과 발표 후보 · 2026-11-19

사진 등록의 **전체 분야**에는 고정 AI 20항목과 기타 분야 직접 검토가 있다. 모델별로 새 가중치를 만든 작업이 아니라 기존 통합 전달본 15항목과 PCB 전달본 5유형을 연결한 것이다. 지원되지 않는 분야는 `manual_other`로 기록하며 AI 요청·가짜 판정을 만들지 않는다.

**아래 오탐·미탐 수치는 연구 평가 기록이다.** 운영 보증·현재 사진 판정·위치 정확도와 구분한다. 입력 범위가 맞는지 점검자가 확인하며 모든 AI 제안은 사람 검토 전의 참고 정보다. 평가가 부족하거나 오류가 큰 항목도 앱에서 숨기지 않고 상태와 범위를 표시한다.

## 발표 후보 5개

**볼스크루 → 시설 균열 → 컨베이어 이물질 → RobustAD PCB → 케이블 외관**.

정상·손상 각 20장 이상이며 양쪽 수치가 있는 항목의 기존 집계를 비교했다. `max(FP/정상, FN/손상)`의 숫자 순위는 볼스크루·시설 균열·컨베이어 이물질·RobustAD PCB·PCB4다. **실제 발표 구성은 사용자의 선택으로 5번째 PCB4를 케이블로 교체**해 서로 다른 대상 5개를 보여준다. 금속판·튜브처럼 오탐이 작아도 미탐이 큰 항목은 오탐만으로 우수하다고 보지 않는다. 기존 집계만 비교했으며 모델·임계값 변경이나 TEST 재추론은 하지 않았다. 조건이 다른 자료의 발표 구성이며 공통 현장 평가 순위가 아니다.

`researchTopTasks`는 기존 집계의 숫자 순위, `demoTasks`는 위 발표 구성을 각각 유지한다. PCB4는 전체 분야에서 계속 제공한다. 케이블의 현재 연구 수치는 오탐 6/58(10.34%), 미탐 7/92(7.61%)이며, [개선 작업은 케이블부터](ERROR_REDUCTION_PLAN.md) 검토한다. 볼스크루·시설 균열·컨베이어의 모델과 기준은 유지한다.
